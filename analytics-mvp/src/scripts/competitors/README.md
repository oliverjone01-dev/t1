# Пилот: данные по конкурентам GG с OZON

Отвечает на вопрос Ивана: «можно ли вытянуть по конкурентам цену / выручку / заказы за прошедший
день по каждому артикулу». Короткий ответ - **частично**, и важно различать факт и оценку.

## Что OZON отдаёт, а что нет

| Поле | Источник | Класс |
|---|---|---|
| Цена, базовая цена | публичная карточка (composer-api) | **[ДАННЫЕ]** |
| Рейтинг, число отзывов | публичная карточка | **[ДАННЫЕ]** |
| Наличие, остаток (если показан) | публичная карточка | **[ДАННЫЕ]** |
| **Заказы за сутки** | НЕ отдаётся ни Seller API, ни публично | **[ГИПОТЕЗА]** - оценка |
| **Выручка за сутки** | НЕ отдаётся | **[ГИПОТЕЗА]** - оценка |

OZON Seller API возвращает только данные твоего кабинета. Продажи чужих SKU не отдаёт нигде.
Кабинетная «Аналитика конкурентов» / «Что продавать» - только UI (Premium Plus), без публичного API.

## Как оцениваются заказы/выручка (метод, не факт)

1. **Дельта отзывов** (основной): `заказы ≈ Δотзывов_за_сутки / доля_выкупа` (допущение выкупа 7%).
   Точность ±50%. Нужен второй снимок через ~24ч.
2. **Дельта остатка** (запас): `продано ≈ остаток_вчера - остаток_сегодня` (если OZON показал остаток;
   не учитывает дозавоз). Точность ±30%.
3. `выручка ≈ заказы_оценка × текущая_цена`.

Это **[ГИПОТЕЗА]**. В отчёты как факт не подавать (Protocol 9).

## Файлы

- `input.json` - 13 артикулов конкурентов из Excel (Стол обеденный, ЛайфМебель / OpenDesign), с привязкой к товару GG.
- `parse.ts` - чистый парсер ответа composer-api (тестируется на фикстуре, без сети).
- `parse.test.ts` - тесты парсера (6 шт).
- `pilot.ts` - оркестратор: скрейпит карточки, считает дельту, пишет снимок + отчёт.

## Запуск

```bash
# Локально (где открыт ozon.ru) или в GitHub Actions:
npx tsx src/scripts/competitors/pilot.ts --out data/competitors
```

Выход: `data/competitors/competitors_YYYY-MM-DD.json` + `report_YYYY-MM-DD.md`.
Workflow: `.github/workflows/competitors-pilot.yml` (ручной запуск; для суточной дельты включить cron).

## Ограничения (честно)

- **Сеть:** в web-контейнере Claude `ozon.ru` закрыт политикой (403) - живой прогон только из Actions/локально.
- **Анти-бот:** IP дата-центров (включая GitHub Actions) OZON часто режет. Если 0 карточек - нужен
  **резидентный прокси** (через undici ProxyAgent, следующая итерация) или **платный API**
  (MPSTATS / SalesFinder / Sellmonitor), который уже отдаёт оценку выручки/заказов.
- **Остаток** OZON показывает не всегда -> оценка по отзывам надёжнее как дефолт.
- **Первый прогон** = baseline без оценок (нужна пара снимков 24ч).

## Следующий шаг (на выбор Ивана)

- **A.** Платный сервис с API (быстро, оценка готова, ~5-15 тыс ₽/мес) - подключить вместо скрейпинга.
- **B.** Свой скрейпер + резидентный прокси (дешевле в API, дороже в поддержке, риск ToS).
- **C.** Только цена (надёжно, без оценок продаж) - если выручка конкурента не критична для решения.
