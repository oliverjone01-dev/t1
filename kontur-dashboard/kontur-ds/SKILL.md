# Контур DS 1.5

Дизайн-система рабочих интерфейсов, где работают с цифрами: дашборды, трекеры, отчёты,
панели управления, внутренние инструменты. Выросла из дашборда «Контур» (SEO, GEO и Директ
по проектам GENGROUP) и проверена на нём: 52 экрана, две темы, живые данные.

- 1.3: продуктовый вид вместо шаблонного. Плитки одной панелью, класс цифры точкой, нейтральные
  врезки, почти чёрная основная кнопка, палитра команд Cmd+K, стеклянные подсказки.
- 1.4: переключатель плотности, липкие шапки таблиц, плавные переходы между экранами,
  микроанимации и анимации Rive, почти чёрная основная кнопка в shadcn.
- 1.5: страница настройки вида `templates/nastroyki.html`: логотип и дескриптор, шрифт, цвета
  кнопок и акцента, плавные или острые графики, палитра серий, форма, глубина, раскладка, движение.

Работает от складного телефона до монитора, в светлой и тёмной теме.

**HARD RULE:** никаких длинных и средних тире (U+2014, U+2013) ни в интерфейсе, ни в коде, ни в
комментариях, ни в ответе. Только дефис или перестроить фразу.

## Когда применять

- Дашборд, отчёт, трекер, админка, калькулятор, внутренний инструмент
- Любой экран, где главное это цифры, их динамика и решения по ним
- Артефакт Claude, страница на GitHub Pages, локальный HTML, React, Vue, shadcn/ui
- Любое устройство: телефон, планшет, ноутбук, монитор; мышь и палец

## Когда НЕ применять

- Лендинги, КП, презентации, каталоги, соцсети: там гайды брендов (gengroup-brand,
  valonti-brand, turbium-webdis-v1)
- В проекте уже есть своя дизайн-система: применять её, Контур DS только закрывает пробелы

## Порядок работы

1. **Подключить пакет.** В `<head>`:
   `<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`,
   шрифт `https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&display=swap`,
   затем `tokens.css`, `kit.css`, ApexCharts с cdnjs, `brand.js`, `icons.js`, `kit.js`, `charts.js`,
   по желанию `motion.riv.js`. В артефакте Claude внешние файлы блокируются: содержимое
   вставляется внутрь страницы (`python3 tools/build_pages.py` собирает шаблон в один файл).
   Проект на shadcn/ui или Tailwind v4: после `tokens.css` подключить `tokens/shadcn.css`.
2. **Каркас из `templates/starter.html`.** Меню `KS.shell.init({ sidebar, backdrop, menu })`,
   фильтры шапки в `.ks-topbar-tools`, палитра команд `KS.cmdk.button()` + `KS.cmdk.set([...])`,
   сегмент `KS.seg.wire(el)`, кнопки плотности и темы в шапке. Вид под бренд проекта: открыть
   `templates/nastroyki.html`, настроить, «Код для проекта» положить в `kit/brand.js`.
3. **Данные в конверт.** Каждая цифра `KS.F(v, k, s, at, n)` до того, как попадёт на экран.
4. **Экран по композиции** из раздела «Экран».
5. **Графики только пресетами** `KS.charts.*` или по правилам раздела «Графики».
6. **Навигация через переход:** `KS.navWire(nav, v => KS.vt(() => { VIEW = v; render(); scrollTo(0, 0); }))`.
   После каждой отрисовки экрана `KS.ticker.run(корень)`.
7. **Проверить сторожем:** `python3 kontur-ds/tools/check_ds.py страница.html --live` (живой
   контраст каждого текста в браузере, обе темы, 1280 и 390, нужен Playwright). Второе мнение:
   `npx impeccable detect страница.html`. Пакета нет: пройти чек-лист в конце вручную.
8. **Посмотреть глазами** обе темы на 390, 768 и 1440, обе плотности; на телефоне открыть меню
   и панель деталей.

## Пять правил

1. **Деньги первыми.** На каждом экране строка про рубли. Цифры нет: строка говорит почему.
2. **Цифра в конверте.** Значение, класс ДАННЫЕ, ГИПОТЕЗА или ДЕМО, источник, дата. Выгрузки нет:
   `v:null` и ДЕМО. Правдоподобное число вместо прочерка запрещено.
3. **Сравнение важнее абсолюта.** Каждая плитка с дельтой за период. Первый экран отвечает,
   стало лучше или хуже.
4. **Цвет вычислен.** Контраст и различимость палитры считаются скриптом, а не на глаз.
5. **Провал виден.** Разрыв в ряду, скачок, совпавшие выгрузки выводятся на экран, не подчищаются.
   Так же с движением: индикатор загрузки только при настоящей загрузке.

## Токены

Менять значения можно только в `tokens/tokens.css`, затем `python3 tools/export_tokens.py`, затем
сторож. Каждая пара «текст на поверхности» проверена по WCAG, палитра графиков проверена
валидатором dataviz в обеих темах. Три состояния темы: `data-theme="dark"`, `data-theme="light"`,
без атрибута по `prefers-color-scheme`; класс `.dark` на корне работает как `data-theme="dark"`.
Тема ставится на любой контейнер, вложенный блок заново берёт `color: var(--text)`.

`--grid`, `--axis`, `--neutral-bar`, `--track`, стекло `--glass-bg/--glass-border/--glass-shadow`,
тени `--sh-card` (с множителем `--depth`), `--sh-hover`, `--sh-pop`, `--sh-drawer`.

- **Текст четырьмя ступенями, прозрачность на тексте запрещена.** `opacity-55` на светлой
  карточке даёт 2,26:1 при норме 4,5:1.
- **Палитра интерфейса не равна палитре графиков.** Синий #5D87FF и голубой #49BEFF неразличимы
  (ΔE 14,4 при пороге 15). Графики красятся только `--cat-1..5`.
- **Нейтрали почти без синевы.** Сине-серый slate читался как тема по умолчанию.
- **Стекло** `.ks-glass` только у слоёв поверх контента: подсказка, палитра команд, уведомление,
  подсказка графика. Карточки с цифрами стеклянными не бывают.

### Шрифт, размеры, радиусы, движение

- Шрифт: на Mac и iPhone системный SF, у остальных Golos Text. SF нельзя вкладывать файлом
  (лицензия Apple только для макетов). DM Sans не брать: нет табличных цифр. Цифры в столбик
  шрифтом интерфейса с `tabular-nums`, моноширинный только для кода.
- Шкала: `--fs-micro` 11 (источник, оси), `--fs-caption` 12, `--fs-badge` 12, `--fs-small` 12,5,
  `--fs-body` 13, `--fs-base` 14, `--fs-h2` 16, `--fs-h1` 22 (19 на телефоне),
  `--fs-hero` `clamp(24px, 20.7px + 0.85vw, 30px)` полужирный 600, трекинг -0,025em.
  Пол 11 пикселей для любого функционального текста.
- Отступы шагом 4: 2, 4, 6, 8, 10, 12, 14, 16, 20, 24, 32, 40.
- Радиусы по ролям: `--r-field` 6 для всего, что нажимают и заполняют, `--r-box` 12 для всего,
  что содержит, `--r-md` 8 для пункта меню и подсказки. Один радиус на всём это признак шаблона.
- Движение: `--ease-out` на вход, `--ease-in` на выход, `--ease-std` остальное; 160, 250, 300,
  420, 520 мс. Пружин и отскоков нет. Анимируются только `transform`, `opacity`,
  `grid-template-rows`, `clip-path`, `stroke-dashoffset`. Бесконечная анимация только у вращения
  загрузки и мерцания заглушки. «Меньше движения» обнуляет длительности и выключает переходы.

### Плотность (1.4)

`data-density="compact"` на корне или контейнере, `KS.density.set('compact' | 'comfortable')`,
`KS.density.toggle()`, событие `ks:density`. Просторно это вид по умолчанию, `data-density="comfortable"`
возвращает его внутри компактной страницы. Выбор запоминается и ставится до первой отрисовки.

| Токен | Просторно | Компактно |
|---|---|---|
| `--pad-box` / `--pad-box-lg` | 16 / 20 | 12 / 14 |
| `--gap-stack` / `--gap-stack-lg` | 16 / 20 | 12 / 14 |
| `--cell-y` / `--cell-x` / `--cell-head-y` | 9 / 12 / 8 | 5 / 10 / 6 |
| `--ctl-h` / `--ctl-h-sm` / `--field-h` / `--select-h` | 32 / 26 / 34 / 30 | 28 / 24 / 30 / 28 |
| `--nav-y` / `--topbar-h` / `--content-pad` | 7 / 58 / 24 | 5 / 52 / 20 |
| `--fs-hero` | 24-30 | 22-26 |

Свои отступы карточек и строк брать из этих токенов, иначе они не сожмутся. Цели пальца
(`--tap` 44, `--tap-sm` 36) плотность не трогает никогда.

## Компоненты

Все функции кита возвращают строку HTML; классы с префиксом `ks-`.

- **Шапка экрана** `KS.head({ title, sub, src, badges, prio, lead })`: `h1.ks-h1`, бейджи строчными,
  значок «?» `.ks-help` с подсказкой (правила чтения экрана там, а не отдельной врезкой), одна фраза,
  на какой вопрос экран отвечает, источник, строка про деньги `.ks-lead` на мягкой подложке. Строка
  про деньги обязательна.
- **Плитки** `KS.tile({ label, f, slot, icon, delta, drill, spark })` в ряду `.ks-grid-kpi`: одна
  панель с волосяными разделителями, не четыре карточки. Подпись 12 с иконкой 14 сверху, класс
  цифры точкой, число 24-30, дельта чипом и спарклайн, источник и дата одной строкой. **Квадрата с
  иконкой нет.** Четыре состояния: данные, гипотеза, демо («нет»), одна точка. `drill` даёт стрелку
  у подписи, подложку и отлив под курсором, без подъёма.
- **Дельта** `KS.delta(dyn, goodUp)`: цвет по смыслу, а не по знаку; для позиции, CPL, отказов
  меньше значит лучше (`goodUp=false`). Одна точка значит «сравнивать не с чем», а не ноль.
- **Класс цифры** `KS.kind(k)` точкой и словом: «данные» тихие, «гипотеза» и «демо» цветные.
  **Статус** в таблицах `KS.status(text, tone, hint)` точкой и словом. **Бейдж** `KS.badge(text,
  tone, hint)` строчными, только в шапке экрана и карточки. Пояснения через `data-tip`, не `title`.
- **Карточка** `KS.card({ title, sub, body, actions, table, drill })`. У каждого графика
  таблица-двойник: кнопка «таблица» в шапке карточки.
- **Таблица** `KS.table(cols, rows, { foot, interactive, stack })`: числа вправо `.is-num`, пустое
  прочерком, заголовки тихие. От четырёх колонок на контейнере уже 520 строки становятся карточками.
  **Шапка липкая (1.4):** держится под шапкой страницы, в панели деталей и в `.ks-table-wrap--scroll`
  (`--table-max-h`, по умолчанию 440). `KS.tables` снимает прокрутку вбок у таблиц, которые влезли
  (класс `is-fit`), иначе шапка держалась бы только за свою обёртку. Под прилипшей шапкой тень.
- **Полосы** `KS.bars(items, slot)`: один ряд, один цвет.
- **Врезка** `KS.note(title, body, tone)`: нейтральная карточка, тон у значка; цветной фон и
  `role="alert"` только у crit. Цветной полосы сбоку нет. Не больше двух врезок на экран.
- **Вердикт** `KS.verdict(series, fields, days, label)`: главная строка экрана «Стало лучше /
  Стало хуже / Разнонаправленно», сетка метрика, было и стало с датами, дельта, отрезком раньше.
- **Следующий шаг** `KS.action({ what, who, when, crit })`: без исполнителя и даты не рисуется.
- **Кнопки** `.ks-btn--primary` одна на экран и почти чёрная, `--secondary`, `--ghost`, `--sm`,
  `--icon` с `aria-label`. **Сегмент** `.ks-seg` с `aria-pressed`: строить один раз, дальше только
  переключать атрибут, `KS.seg.wire(el)` двигает плашку через `clip-path`. **Поле** `.ks-field >
  .ks-input` с табличными цифрами, фокус границей и мягким кольцом.
- **Панель деталей** `KS.drawer.register(key, provider)`, `data-drill="key"`: справа 560, на
  телефоне во весь экран. Четыре блока: из чего сложилась цифра, как менялась, откуда взята, что
  делать. Esc, клик мимо, крестик; фокус возвращается. Один уровень.
- **Меню** `KS.nav(tree, active)` + `KS.navWire(nav, onGo)`: два уровня, аккордеон, бейдж группы
  функцией. **Подложка выбранного пункта переезжает (1.4)** через `KS.navhl`, подключается сама;
  меню можно перерисовывать через `innerHTML`.
- **Палитра команд** `KS.cmdk.set([{ group, label, hint, icon, keywords, run }])`, кнопка
  `KS.cmdk.button('Поиск')`, Cmd+K или Ctrl+K: все экраны, проекты, периоды, главные детали,
  действия (тема, плотность, ссылка).
- **Подсказка** `data-tip` (мышь через 300 мс и фокус, стекло, `\n` для переноса), **уведомление**
  `KS.toast(text, tone)` (2,8 секунды, галочка рисуется), **загрузка** `KS.skeleton(lines, height)`
  (не путать с ДЕМО), **клавиша** `.ks-kbd`, **спарклайн** `KS.spark(ряд)` (пропуск пунктиром),
  **переход числа** `KS.ticker.run(корень)` (только при обновлении, без счёта от нуля).
- **Тема** `KS.theme.init()`, `KS.theme.toggle()` (1.4: кросс-фейд 220 мс), `KS.theme.icon()`.
  Хост сам ставит `data-theme`, кит его не перебивает. **Маршрут** `KS.route`: `#проект.экран.период.показатель`,
  разделитель точка. Порядок старта: `KS.route.parse()`, потом `KS.theme.init()`, потом отрисовка.

### Переходы между экранами `KS.vt` (1.4)

`KS.vt(update, { types })` на View Transitions API. Шапка страницы и меню в переходе не участвуют,
плавно меняется только `.ks-view`: старое гаснет за 120 мс, новое проявляется за 200 мс, блоки
внутри поднимаются по очереди. Прокрутили дальше 64 пикселей: старый снимок не показывается.
Тема и плотность: кросс-фейд всей страницы за 220 мс. Анимации нет и обновление сразу, если
браузер без поддержки, «меньше движения», вкладка скрыта, открыто меню на телефоне, панель деталей
или палитра команд. Быстрые повторные клики не копятся. Поддержка: Chrome и Edge 111+, Safari 18+,
Firefox 144+ (Firefox ESR 140 без анимации). Морф плитки в панель и круговое раскрытие темы не
делать: это эффекты лендинга.

### Микроанимации `KS.motion` и Rive `KS.rive` (1.4)

- `KS.motion.sync(state, size)` и `KS.motion.setSync(el, state)`: индикатор синхронизации idle,
  loading, done, error. **Только при настоящей загрузке.** Вшитые данные не «синхронизируются».
- `KS.motion.check(size)`: круг и галочка прорисовкой, уже стоит в `KS.toast`.
- `KS.motion.emptyArt()`: пустой график, линия с разрывом пунктиром, уже стоит в пустых графиках.
- `KS.rive.enable()` после подключения `kit/motion.riv.js`: подгружает рантайм
  `@rive-app/canvas-single@2.43.0` с cdn.jsdelivr.net (около 2,8 МБ один раз, WASM внутри JS) и
  ставит холст Rive поверх родной картинки у `data-rive="sync|success|empty"`. Цвета из токенов через
  View Model (`ink`, `muted`, `accent`, `ok`, `crit`), у `sync` число `state` 0..3. Нет сети, песочница
  запрещает WASM, «меньше движения»: остаются родные анимации, ничего не ломается.
- Новая анимация Rive: официальный Rive CLI (`curl -fsSL https://releases.rive.app/cli/install.sh | sh`),
  исходник на RML, типы и свойства только через `rive docs` и `rive schema`, без скриптов Luau
  (неподписанные скрипты веб-рантайм отвергает), проверка кадров в веб-рантайме, затем
  `node rive/bundle.mjs`. Не логиниться, не делать `rive push` и `--publish` без владельца.
  Официальный выпуск без водяного знака идёт через тариф Rive Cadet.

### Настройки вида `KS.prefs` (1.5)

- Страница `templates/nastroyki.html`: логотип (PNG, SVG, JPG, WebP; знак 28 в квадрате или
  целиком до 176 в ширину, дескриптор под ним; в тёмной теме как есть, инверсия или свой файл,
  тёмный логотип инвертируется сам), название и дескриптор, масштаб шрифта 90-115% и разрядка,
  акцент (шесть готовых и свой), основная кнопка (почти чёрная, цвет акцента, свой), выбранное в
  переключателе и в меню (нейтрально или в тон), линии острые или плавные, толщина, палитра серий
  (Контур, синий первым, свои с проверкой), скругление, тени, рамки, стекло шапки, ширина,
  плотность, тема и меню по умолчанию, анимации полные, сдержанные, без. Живой предпросмотр в
  обеих темах; сама страница в виде Контура, в её меню меняются только логотип и подпись.
- Порядок важности: сохранённое в браузере (`localStorage 'ks-prefs'`), затем `kit/brand.js`
  (`window.KS_BRAND`), затем вид Контура; выбор человека кнопками темы и плотности важнее. Чтобы
  вид получили все, код со страницы («Код для проекта») кладётся в `kit/brand.js`. Перенос между
  компьютерами: файл `kontur-vid.json`.
- API: `KS.prefs.get()`, `.save(p)`, `.reset()`, `.code(p)`, `.css(p, scope)`, событие `ks:prefs`.
- Кит цвета не считает: страница вычисляет готовые значения в `prefs.vars` (`base`, `light`,
  `dark`, `compact`, `comfortable`), кит вставляет их в `<style id="ks-prefs-style">` с проверкой имён,
  значений и картинок (`data:image/...;base64` только). Hex в ките не появляется.
- Свой цвет подправляется по OKLCH до нормы (текст 4,5, управление 3) в обеих темах, отчёт говорит,
  что изменено. Сплошной плашки переключателя нет: во время движения белый текст на дорожке 1,3:1.
- Анимации: `data-motion="calm"` (только отклик на наведение и нажатие, без переходов, прорисовки
  графиков и Rive), `data-motion="off"` (длительности 0). «Меньше движения» в системе важнее.
- Свои карточки с рамкой переводить на `var(--card-border, var(--border))`, иначе «только тень» их
  не затронет.

## Графики

| Задача | Форма |
|---|---|
| один ряд по времени | линия, подпись только на последней точке |
| два-три ряда одной природы | линии с легендой; логарифм, если различаются на порядки |
| ряды разной величины | индекс: каждый ряд к 100 на старте периода. **Двух осей Y нет никогда** |
| сравнение категорий | горизонтальные полосы, одна серия, число за торцом |
| выделить одного | столбцы: наш `--cat-3`, остальные `--neutral-bar` |
| доля целого | пончик до пяти долей, проценты в легенде, итог в центре |
| матрица | тепловая карта на `--seq-1..5`, классы в легенде |

Правила: одна серия без легенды, две и больше с легендой; цвета `--cat` в фиксированном порядке,
максимум пять; сетка только горизонтальная; точки при наведении, перекрестие, стеклянная подсказка;
по умолчанию `curve:'straight'`, плавные только `monotoneCubic` (настройка вида или
`data-curve="smooth"`), обычный `smooth` запрещён, он перелетает значения; толщина `data-line-w` 1-3; ряд из трёх и меньше точек с маркерами; ось с полями 18% размаха; пустой ряд не
отдаётся в ApexCharts, вместо него пустая область с текстом; подписи дат повёрнуты на 38°, не
больше шести; hex в коде графиков запрещён, цвета читаются из переменных контейнера. Телефон:
высота 84%, четыре подписи, даты без года. После замены экрана через `innerHTML` вызывать
`KS.charts.prune()`, несколько отрисовок в кадре сводить в одну.

## Экран

Сверху вниз: шапка со строкой про деньги; вердикт, если экран про динамику; четыре плитки с
дельтами; два графика рядом, у каждого таблица-двойник; врезки, что значат цифры и где аномалии;
следующий шаг с исполнителем и датой; «Метод и его границы» отдельным экраном или внизу.
Период выбирается один раз в шапке и действует на все экраны. Каркас: меню 248 (свёрнутое 72),
шапка 58, поле 24 и 16 на узком; до 1024 пикселей меню уезжает за край.

## Адаптивность

Каркас меняется по ширине окна, сетки внутри по ширине своего контейнера.

| Окно | Что меняется |
|---|---|
| до 340 | плитки по одной, когда контейнер уже 300 |
| 340-639 | меню за краем по кнопке; фильтры шапки лентой вбок; заголовок 19; панель во весь экран; таблицы от 4 колонок карточками; графики ниже |
| 640-1023 | меню за краем; плитки по 2, по 4 от контейнера 680; графики парами от 720 |
| 1024-1279 | меню у края 248, кнопка сворачивает в полосу 72 |
| от 1280 | графики тройками от контейнера 1080, ширина до 1480 |

Касание: кнопки, пункты меню, значки 44, мелкие 36, поля 16 (иначе iPhone увеличивает страницу).
Наведение только в `@media (hover:hover)`. Безопасные зоны `env(safe-area-inset-*)`, высота `100dvh`,
открытые меню и панель блокируют прокрутку. Дорожки сетки `minmax(0,1fr)`, широкие таблицы и код
в своём контейнере с прокруткой. Прокрутки страницы вбок нет нигде: строка с прокруткой внутри
флекс-колонки получает `min-width:0` на себе и на родителе; `html{overflow-x:clip}` только
страховка (на корне clip работает как hidden, и scrollIntoView всё равно утащит страницу), источник
переполнения чинить по месту.

## Среды

- **Артефакт Claude.** Токены, стили и скрипты кита внутрь страницы. Разрешены Google Fonts и
  cdnjs (ApexCharts); Rive грузится с jsdelivr, но WASM может быть запрещён песочницей: тогда
  работают родные анимации. `window.print()` не работает: кнопку «Печать» не ставить. До
  `location.hash` доходят только буквы, цифры и `. _ ~ -`. Хост сам ставит `data-theme`.
- **Pages и локальный файл.** Файлы ссылками, печать работает (липкая шапка на печати обычная).
- **Tailwind v3.** Пресет `tokens/tailwind.preset.js`, цвета ссылаются на переменные.
- **shadcn/ui и Tailwind v4.** `tokens/shadcn.css` после `tokens.css`. Имена shadcn указывают на
  токены Контура. Утилиты `bg-primary` и `text-primary-foreground` ведут на `--action`: основная
  кнопка shadcn почти чёрная, как у кита; синий `--primary` остаётся акцентом, в Tailwind это
  `bg-primary-blue`. Вернуть синюю основную кнопку: `data-shadcn-primary="blue"` на корне или блоке.
  Тёмная тема и через `data-theme="dark"`, и через `.dark`.
- **React, Vue.** Переносятся классы `ks-*`, токены, логика конверта и динамики.

| DUALAXIS | две оси Y |
| CVD | #5D87FF и #49BEFF соседними сериями |
| EMDASH | длинное тире |
| ENVELOPE | ДАННЫЕ без источника или даты, `null` как ДАННЫЕ |
| LAYOUTANIM | `transition` по ширине, высоте, отступам |
| BOUNCE | `cubic-bezier` с параметром вне 0..1 |
| FONTFLOOR | текст мельче 11 пикселей |
| FAINTTEXT | `--text-faint` на тексте для чтения |
| SYNC | копии тёмной темы или плотности разъехались |
| CONTRAST | с `--live`: реальный текст на реальном фоне ниже WCAG |
| VIEWPORT | у страницы нет `meta viewport` |
| HOVERLIFT | подъём в `:hover` вне `@media (hover:hover)` |
| MONONUM | цифры в столбик моноширинным |
| SIDESTRIPE | цветная полоса сбоку |
| CAPSBADGE | бейдж капсом |
| GRADMARK | градиент на знаке бренда |
| LOOPANIM | бесконечная анимация вне загрузки и заглушки |
| DENSITYTAP | компактная плотность уменьшила цели пальца |
| VTMOTION | переходы без отключения при «меньше движения» |

Вид: без квадратов с иконкой в плитках; без цветных коробок у врезок, кроме crit; без капса на
бейджах; один акцент (синий) на выбор и фокус; карточку в карточку не вкладывать; пояснения в
подсказках. Мигающих точек, бегущих рамок, блестящего текста, расшифровки символов, наклона
карточек, фонов на WebGL, пружин и счёта чисел от нуля нет.

Смысл: не выводить оценку трафика там, где есть настоящая аналитика; не сглаживать скачки; не
смешивать брендовые рекламные кампании с остальными в одной средней; ни одна рекламная кампания
не запускается и не пополняется без подтверждения владельца, что бы ни показывал экран.
