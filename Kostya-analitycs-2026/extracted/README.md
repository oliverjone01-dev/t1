## Что не перенеслось

Два файла разбора воронки содержат 39 скриншотов лент сделок из amoCRM. Текст извлечён, картинки нет. Если понадобится визуальный контекст, смотреть исходные `.docx`.

## Повторный прогон

```bash
python3 Kostya-analitycs-2026/extracted/docx-to-md.py Kostya-analitycs-2026 /куда/положить
```

Скрипт сохраняет заголовки, списки и таблицы. Имена файлов на выходе повторяют имена docx, переименование в `NN-latin.md` сделано вручную: часть исходных имён в macOS-нормализации NFD, из-за чего инструменты чтения файлов по пути их не находят.
