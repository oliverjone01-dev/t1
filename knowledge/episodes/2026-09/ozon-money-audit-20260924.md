## 2. Сентябрь: врут обе таблицы, в разные стороны

| | по артикулам | по заказам |
|---|---|---|
| на странице, 1-21.09 | −1 476 913 | +2 813 858 |
| механизм | СС за 201 шт по дате доставки, выручка только за 89 заказов сентября: выручка 110-114 августовских заказов, доставленных в сентябре, не попадает ни в один месяц (шов `FIN_CUT`, build-katya.ts ~1928-1946) | 71 заказ в пути (77 шт, выручка 6 933 669) посчитан с «К выплате» = 100 % выручки: OZON начисляет сборы при доставке |
| оценка после исправления (ФЕНИКС) | около +1,06…+1,19 млн [ДАННЫЕ, до поправок на доставку] | около +0,86 млн [ГИПОТЕЗА: доля сборов доставленных 51 %] |

Оба механизма подтверждены тремя проверками независимо, разложение разницы 4 290 771 совпало до рубля (2 719 450 летящие заказы + 1 524 766 СС без выручки + 46 555 остаток).

**Поправка к первому отчёту автора.** Число +94 408 («только доставленные заказы») не соответствует ни одному базису: оно выбрасывает летящие заказы целиком вместе с их будущей прибылью и не включает 112 штук, заказанных в августе. На обоих базисах после исправления сентябрь в плюсе.

## 3. Забытые и неверно взятые расходы

- **Наша доставка за сентябрь 65 740 ₽** при обычных 590-720 тыс. в месяц: ведомости перевозчика за сентябрь нет, счёт есть у 23 из 89 заказов. Обе таблицы. [ДАННЫЕ]
- **«Гибкий график выплат»** с 08.09 не попадает: кабинетные сборы берутся из accrual-ряда, где этой статьи нет. По документу за июль −220 521 ₽. [ДАННЫЕ по июлю, потеря за сентябрь ГИПОТЕЗА]
- **Доставка от покупателя** в таблице по артикулам взята из API по дате заказа: июль 599 576 против 904 867 по документу, −305 291 ₽ дохода в закрытом месяце. [ДАННЫЕ]
- По заказам: СС вернувшихся штук не снимается (72 649 июль, 34 817 август), логистика отменённых заказов выброшена (26-37 тыс. в месяц). [РОМАН]
- **База налога.** «Налоги 15 % от К выплате» не совпадает ни с одним режимом. Для июля разброс вариантов базы (≈264 тыс. … 1,32 млн) больше чистой прибыли месяца. Катя 23.09: «на Озон позже переделаю базу для налога» (`knowledge/semantic/ym-rates-adm-tax.md:49-51`). HITL: Иван.
