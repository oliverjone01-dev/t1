# GG-MarkPlan 2026

Отдельный внутренний сайт GENGROUP - **единый маркетинговый план 2026** по 5 брендам
(GENGLASS, VALONTI, GENTERO, Metal-GM, GLASS-MEMORY), приоритет GENGLASS.

Не дашборд аналитики и не SEO-хаб. Это слой **планирования**: цели года → инициативы
по кварталам → каналы → бюджеты и KPI, с явным разделением `[ДАННЫЕ]` и `[ГИПОТЕЗА]`
(Protocol 9) и гейтом ФЕНИКСА (Step 12.5) перед фиксацией цифр как факта.

Владелец домена задачи: **marco** (CMO, контент- и канальная стратегия).
Цифры и источники: **data** (Protocol 9). Финансовая вменяемость бюджетов и ROMI:
**roman** (CFO). Гейт перед публикацией плана как решения: **feniks** (Step 12.5).

## Зачем это отдельный проект, а не папка в аналитике

- **Другой горизонт.** Аналитика (`analytics-mvp/`) отвечает на вопрос «что было вчера»
  (P&L, воронка OZON по дням). MarkPlan отвечает «что делаем в 2026 и зачем» - кварталы,
  ставки, последовательность. Разные циклы: план меряется кварталами, аналитика - днями.
- **Другая аудитория.** Аналитика - для коммерческого блока. MarkPlan - для CMO, владельцев
  брендов и ФЕНИКСА: где ставки, чем обоснованы, кто и когда проверит первый сигнал.
- **Свой раздел на сайте.** Публикуется изолированной статикой в `/markplan/` на общем
  GitHub Pages GENGROUP (см. `deploy-pages.yml`), не мешаясь в аналитику. Переезд на
  отдельный домен - позже, сменой базового URL, без переписывания.

## Дисциплина Protocol 9 (встроена в продукт)

Планирование - главный источник розовых очков, поэтому правила зашиты в интерфейс:

- Каждая цифра в плане несёт метку **`[ДАННЫЕ]`** (со ссылкой на источник) или
  **`[ГИПОТЕЗА]`** (со списком допущений). Немаркированных чисел в плане не бывает.
- Сид-данные этого репозитория - **скелет-заглушка** (`status: skeleton`). Это каркас
  разделов, а не утверждённый план. Баннер в шапке предупреждает об этом явно.
- Инициатива не переходит в статус `committed`, пока не пройдёт триаду ДАТА → ФЕНИКС → МАРКО
  и не получит владельца и дату первого сигнала (Q5 Reality Audit).
- Бюджет >200K на чистой гипотезе, ROMI >50x без unit-эк, диапазон оценки шире 2x -
  блокируются на входе (Hard Rules CLAUDE.md §5), инициатива помечается флагом.

## Что внутри (модули)

| Модуль | Статус | Что делает |
|---|---|---|
| **План года** | скелет | Цели 2026 по холдингу и по каждому бренду, статус ставок |
| **Кварталы (Q1-Q4)** | скелет | Инициативы по кварталам: владелец, статус, ICE, метка P9 |
| **Каналы** | скелет | Микс каналов на бренд (Директ, SEO/GEO, SMM, МП, PR), связь с инициативами |
| **Бюджет и KPI** | скелет | Плановые бюджеты и целевые KPI - только как `[ГИПОТЕЗА]` до гейта ROMAN + ФЕНИКС |
| **Гейты** | план | Лог прохождения Step 12.5 по каждой committed-инициативе |

## Структура папки

```

  README.md            # этот файл - charter проекта
  ROADMAP.md           # этапы сборки, Kill Criteria
  DECISIONS.md         # решения автономной сборки MarkPlan v0.1
  BACKLOG.md           # что дальше, по приоритету
  public/              # приложение (статический SPA, без сборки)

    app.js             # рендер разделов из data/plan-2026.json
    data/
      plan-2026.json   # СКЕЛЕТ плана (заглушка, не утверждённый план)
```

## Локальный просмотр

Сборки нет - чистая статика. Любой статик-сервер из `public/`:

```bash
cd GG-markplan-2026/public && python3 -m http.server 8080
# открыть http://localhost:8080
```
