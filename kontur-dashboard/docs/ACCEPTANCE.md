# Критерии приёмки

Порог ФЕНИКСА для этого проекта поднят с 8,0 до 9,5. Ниже то, что проверяется.

## Автоматически, на каждой сборке

- [ ] `python3 tools/check_dash.py` зелёный
- [ ] `python3 tools/tamper.py` ловит 18 из 18
- [ ] `python3 tools/snapshot.py --check` без разрывов и без просрочки
- [ ] `node tools/smoke.mjs`: ноль ошибок консоли, ноль пустых графиков,
      ноль экранов тоньше 700 знаков, ноль горизонтальных прокруток на 390 пикселях
- [ ] палитра проходит валидатор в обеих темах

## Руками, перед показом собственнику

- [ ] На первом экране виден ответ на вопрос «стало лучше или хуже», а не только цифры
- [ ] Каждая цифра несёт класс, источник и дату; демо-значения не притворяются данными
- [ ] Ни одной цифры выручки, выведенной из неподтверждённых коэффициентов
- [ ] Открытые вопросы видны, а не спрятаны в переписке
- [ ] Страница собственнику печатается на один лист и читается за три минуты
- [ ] Обе темы просмотрены глазами, а не только тестом

## Что считается провалом независимо от балла

1. Правдоподобное число вместо `null` там, где выгрузки нет.
2. Цифра выручки, посчитанная по неподтверждённым коэффициентам и поданная как факт.
3. Две оси Y на одном графике.
4. Длинное тире в любом тексте.
5. Запуск или пополнение рекламной кампании без подтверждения Ивана.
