## 3. Решения и почему
- Блок «за выбранный период»: только деньги, баллы не вычитаются, минусы не отсекаются (Катя; Иваном
  не подтверждено) - должен сходиться с закрывающими документами.
- Фиолетовым - только оценки сборов по заказам в пути, и только в двух аналитиках по дате заказа
  (вариант А Кати). Блок начислений не трогать: там только точные данные.
- Ведомость: ОТМЕНЕН не считается; две суммы в ячейке складываются; FALSE + число рядом = наш расход.
- «Товары» не трогать. OZON из этой ветки не трогать. Только `npm run ym:build`, не общий build.
- Мерж только по команде Кати. По ФЕНИКСУ ничего не дорабатывать без её вопроса/согласия.
