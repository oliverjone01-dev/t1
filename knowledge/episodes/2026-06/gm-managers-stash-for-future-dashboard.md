## Что зафиксировать для будущего GM-дашборда

### CRM-стэк
GM в Bitrix24 (как и весь стэк после миграции). Воронка не категория 49, отдельная воронка GM. Проверить ID при подключении.

### Поля под GM-специфику
Помимо общих (Дата решения клиента, Дата следующего контакта, Причина отказа), для ритуальной ниши имеют значение:
- Тип персонализации (фото / гравировка / цвет печати)
- Срок до даты (привязка к дате 9/40 дней или годовщине)
- Согласование цветопробы (этап, который Виктория пропустила)

### Шаблоны общения
GM-сегмент эмоционально чувствительный (Костя зафиксировал это явно). В будущем GM-дашборде нужен отдельный блок «качество тона ответа», возможно интеграция с humanizer-ru на ответах менеджеров.

### Архитектура
- Отдельный ростер `gmUsers`
- Отдельный PIPE для GM-воронки
- Возможно отдельный шаблон вместо `rop-command.template.html`
- Те же три роли (РОП GM, менеджер, директор)

### Текущее состояние
В `analytics-mvp/src/scripts/b24/build-rop.ts:26-30` уже есть фильтр исключения GM из основного дашборда:
- Виктория Преснякова
- Денис Белов
- Юлия Мавлина
- Системный пользователь MGM
- любой с `dir = 'glass-memory'`

Этот фильтр служит маркером границы. Для GM-дашборда заведём отдельный fetch-скрипт `fetch-gm.ts` с обратным фильтром (только GM).
