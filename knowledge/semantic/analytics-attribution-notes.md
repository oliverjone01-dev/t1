Обновлено: 2026-07-10, источник - Дмитрий (владелец кабинета Директа).

1. **Царь-цель**: Метрика 487033158 «CRM | Все лиды» (плюс 487033859 «Качественные»). Механика: лид попадает в CRM → автовыгрузка в Google Sheets по API → проброс в Метрику по client_id (офлайн-конверсии).
2. **Известная дыра атрибуции**: виджет-мессенджер yourgood «MAX» на сайте НЕ пробрасывает client_id. Обращения через него частые → лиды из MAX не долетают до царь-цели. Следствие: все CPL/CR по целям Метрики ЗАВЫШЕНЫ по стоимости (реальных лидов больше), сравнение каналов может искажаться, если доля MAX-обращений в каналах разная. Вопрос в работе у Дмитрия; при анализе всегда делать оговорку.
