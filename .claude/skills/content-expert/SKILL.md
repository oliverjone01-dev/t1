# Content-Expert - Long-form for Website (8 templates + SEO + Schema)

## Purpose

Создаёт контент для сайтов GENGROUP (genglass.ru, valonti.com, gentero.ru), который **измеримо превосходит** лучшие РФ D2C-бренды (Miralls, Dantone Home, Askona) по трём осям:

1. **Expert depth** - конкретика производства, ТУ ДомГласс, spec-сравнения
2. **Conversion mechanics** - inline CTAs, калькуляторы, gated elements
3. **SEO architecture** - cluster, Schema, title formulas, AI Citation

**Complementarity:** content-factory обслуживает КП/scripts/emails/social. content-expert обслуживает website articles. Brand voice load - через skill `brand`. Production facts load - через skill `encyclopedia` или `brand/references/product-facts.md`. Конкуренты - через `competitor-intel`.

## Part 1: Anti-patterns (NEVER) + Best practices (ALWAYS)

### NEVER (catalogued failures from miralls.ru 55 статей × 1581 продуктов audit)

1. **Historical water openers.** «Первые зеркала создавались в глубокой древности...» BANNED. Первое предложение = прямой ответ на запрос.
2. **Generic encyclopedia text.** «Какие бывают зеркала» с нулём production data. Каждая статья ОБЯЗАНА содержать ≥5 specific numbers from GENGROUP production.
3. **Fake year updates.** Замена «2022» на «2026» в title без изменения контента. Дата должна соответствовать актуальности.
4. **Dead-end articles.** Текст заканчивается без CTA/калькулятора/квиза/формы. ОБЯЗАТЕЛЬНО ≥2 inline conversion elements.
5. **Copywriter clichés.** «квинтэссенция дизайнерской мысли», «великолепно проявив себя», «завораживающий контраст». См. Part 4 blocklist.
6. **Zero video references.** В нише visual products статья без видео/анимации = неполная.
7. **7-field forms.** Max 3 поля (имя + телефон + опционально комментарий).
8. **Duplicate H1.** Один H1 per page.
9. **No Schema.org.** Каждый product = Product schema, каждый FAQ = FAQPage, каждая статья = Article.
10. **Flat chronological blog.** Без категорий и тегов = SEO suicide. Адаптировать паттерн Dantone (Part 8).

### ALWAYS (Dantone Home + world best practices)

1. **Named experts.** «По данным конструктора GENGLASS Максима К.», «дизайнер проекта рекомендует...». Никогда анонимный авторитет.
2. **Project-based content.** Привязка продуктов к реальным проектам/локациям (паттерн Dantone «Атмосфера ностальгии: интерьер в старом фонде»).
3. **Category-tagged blog.** Теги: room (ванная/гостиная/офис), product type (перегородки/столы), style (лофт/минимализм), audience (B2C/дизайнер/B2B).
4. **Inline product widgets.** После каждого 3-го экрана текста - product reference с фото, ценой, ссылкой «Рассчитать».
5. **Production transparency.** «Стальная рама проходит 7-этапную обработку: раскрой → сварка бесшовная TIG → зачистка → грунт → порошковая окраска RAL → контроль → упаковка».
6. **Comparison tables.** Для «как выбрать» статей - таблица spec, не проза.
7. **Progressive disclosure.** Короткий ответ first (для snippet), потом detailed.

## Part 2: 8 Content Types

### Type 1 - Expert Guide («Как выбрать...»)

**Intent:** informational-commercial. **Length:** 2000-4000 слов.

```
TITLE: [Действие] + [Объект] + [Контекст] + [Год если релевантно]
Example: "Как выбрать стеклянную перегородку для квартиры: 7 критериев от производителя"

H1: = TITLE (один)
LEAD (50-80 слов): прямой ответ на запрос. Без истории.
H2: Быстрый чек-лист - 5-7 пунктов одним экраном, каждый = критерий + число
H2: [Критерий 1] подробно - 300-500 слов, ≥3 числа, фото или схема
    INLINE CTA: "Рассчитайте стоимость [продукт] под ваш размер →"
H2: [Критерий 2] подробно (аналогично)
H2: Сравнительная таблица - 4-6 вариантов × 5-7 параметров. Числа, не прилагательные.
H2: Частые ошибки при выборе - 3-5 ошибок с конкретными последствиями
H2: FAQ - 5-7 вопросов, Schema-ready
FOOTER CTA: форма или ссылка на калькулятор/квиз
```

### Type 2 - Top-N Product Showcase («Топ-10...»)

**Intent:** commercial. **Length:** 2500-4000 слов.

```
TITLE: "Топ [N] [категория] [год]: рейтинг от производителя с ценами"
LEAD: критерии отбора (продажи за 6 мес, отзывы, выбор дизайнеров)
КАЖДАЯ ПОЗИЦИЯ:
  H2: [Номер]. [Название модели]
  Фото в интерьере (не на белом фоне)
  Spec table: 5-7 параметров (размеры, материал, вес, цвета, цена от X ₽)
  Для кого: 1-2 предложения с конкретной комнатой/стилем
  Мнение эксперта: 1 именная цитата
  Ссылка на карточку товара
ИТОГ: сводная таблица всех N моделей × 5 ключевых параметров
CTA: "Не нашли свой вариант? Закажите расчёт под ваши размеры →"
```

### Type 3 - Technical Deep Dive («Почему / Как работает...»)

**Intent:** informational + AEO. **Length:** 1500-3000 слов.

```
TITLE: "[Технический вопрос]: объясняет производитель"
Example: "Закалённое vs обычное стекло для мебели: разница в цифрах"
LEAD: 2-3 предложения короткого ответа - для сниппета
BODY: H2 разделы с числами из производства (температура закалки 650°C, толщина 4/6/8мм)
  Сравнительная таблица (характеристика | обычное | закалённое | triplex)
  Фото из реального производства GENGROUP (не сток)
  Упоминание стандартов (ГОСТ, AGC, ТУ ДомГласс)
INLINE CTA после каждого H2-блока
FAQ: 3-5 технических вопросов
```

### Type 4 - Project Case Study («Кейс: ...»)

**Intent:** commercial-transactional. **Length:** 800-1500 слов.

```
TITLE: "[Тип объекта] в [Локация]: [продукт] в проекте [дизайнер/студия]"
Example: "Лофт-перегородки в апартаментах ЖК Сити: проект для AFY Development"
HERO: фото до/после или финальный интерьер
БРИФ: задача → решение → результат (3 абзаца × 2-3 предложения)
SPEC: таблица (продукт, размеры, материалы, цвет RAL, сроки)
ПРОЦЕСС: 4-5 фото с этапами (замер → производство → доставка → монтаж)
ОТЗЫВ: именная цитата клиента/дизайнера
CTA: "Обсудить ваш проект с менеджером →"
```

### Type 5 - Comparison («X vs Y»)

**Intent:** commercial. **Length:** 1500-2500 слов.

```
TITLE: "[X] или [Y]: что выбрать для [контекст]"
LEAD: краткий ответ «если X - берите A, если Y - берите B» (для сниппета)
H2: В чём разница - таблица 8-10 параметров
H2: Когда лучше [X] - 3-5 сценариев с конкретикой
H2: Когда лучше [Y] - 3-5 сценариев
H2: Сколько стоит - ценовое сравнение с диапазонами ₽
H2: Что выбирают наши клиенты - статистика % по заказам если есть
FAQ: 3-5 вопросов
CTA: "Получите расчёт обоих вариантов за 30 минут →"
```

### Type 6 - Trend / Market Insight

**Intent:** informational + AEO. **Length:** 1500-2500 слов.

```
TITLE: "Тренды [ниша] [год]: что выбирают дизайнеры"
LEAD: 3-5 трендов одним списком (для сниппета)
КАЖДЫЙ ТРЕНД:
  H2: [Тренд N]: [название]
  Почему это тренд (данные рынка, статистика запросов, мнение)
  Как реализуется у GENGROUP (конкретные продукты)
  Фото/визуализация
  Ценовой диапазон
CTA: "Хотите быть в тренде? Закажите консультацию дизайнера →"
```

### Type 7 - FAQ Hub

**Intent:** informational + featured snippets. **Length:** 2000-4000 слов (20-30 вопросов).

```
TITLE: "Частые вопросы о [категория]: ответы производителя"
ОБЯЗАТЕЛЬНО: FAQPage Schema разметка
КАЖДЫЙ ВОПРОС:
  H3: [Вопрос как его задаёт клиент - из реальных заявок CRM]
  Ответ: 2-5 предложений. Первое = прямой ответ. Далее уточнение.
  Если применимо: ссылка на товар или калькулятор
ГРУППИРОВКА H2: Про материалы / Про цены / Про доставку / Про монтаж / Про уход
```

### Type 8 - Category Page SEO-text

**Intent:** commercial (нижний текст каталога). **Length:** 500-1000 слов.

```
Абзац 1: что найдёте в категории + для кого (2-3 предложения)
Абзац 2: ключевые отличия нашей продукции (3-4 факта с числами)
Абзац 3: как выбрать - ссылки на гайды и FAQ
Абзац 4: процесс заказа (кратко)
Абзац 5: доставка и монтаж (кратко + ссылка)
ПЕРЕЛИНКОВКА: 5-8 внутренних ссылок на подкатегории/товары/статьи
```

## Part 3: SEO Engine

### Title formula

```
[Действие/Вопрос] + [Объект] + [Контекст/Модификатор] + [Год если коммерческий]
```

- **Max:** 60 символов для Яндекс, 55 для Google
- **Запрещено:** начинать с бренда. Бренд в конце через ` | GENGLASS` или вообще без

### Meta description formula

```
[Прямой ответ на запрос, 1 предложение]. [Ценностное предложение]. [CTA].
```

- **Длина:** 140-160 символов
- **Запрещено:** копировать первый абзац статьи

### H-structure rules

- H1: один, = title или расширенная версия
- H2: основные разделы (7-12 штук для длинной статьи)
- H3: подразделы внутри H2
- H4+: крайне редко
- Каждый H2 содержит ключевое слово или синоним, но **естественно**

### Internal linking

- Каждая статья ссылается на: 2-3 товара, 1-2 смежные статьи, 1 категорию, 1 сервисную страницу
- Якорный текст = осмысленная фраза, не «тут» и не голый URL
- Обратная перелинковка: при создании новой статьи указать, какие существующие должны ссылаться на неё

### Cluster architecture

Каждый кластер = 1 pillar + 3-7 satellite:

```
PILLAR: "Стеклянные перегородки: полный гайд от производителя"
├── SAT: "Стеклянная vs алюминиевая перегородка: сравнение"
├── SAT: "Топ-5 перегородок для квартиры-студии"
├── SAT: "Сколько стоит стеклянная перегородка: калькулятор"
├── SAT: "Монтаж стеклянной перегородки: пошагово с фото"
└── SAT: "FAQ: 20 вопросов о стеклянных перегородках"
```

Все satellites ссылаются на pillar. Pillar ссылается на все satellites.

## Part 5: Conversion elements

### Inline CTA types (каждые 600-800 слов)

1. **Калькулятор:** «→ Рассчитайте стоимость [продукт] под ваш размер» + ссылка
2. **Квиз:** «Не уверены, что подойдёт? Ответьте на 3 вопроса - подберём вариант →»
3. **Консультация:** «Задайте вопрос конструктору GENGLASS - ответим за 30 минут →»
4. **Товарный виджет:** фото + название + «от X ₽» + кнопка «Подробнее»
5. **Скачивание:** «Скачайте каталог [категория] в PDF →» (лид-магнит за контакт)

### Social proof elements (≥1 на статью)

- Цитата клиента с именем и проектом
- Число реализованных заказов (27 000+ [ДАННЫЕ: agents/data.md c=1.0])
- Упоминание партнёров (Mercury Hotel, AFY Development, SMINEX, SPACE 1)
- Участие в ТВ-проектах и выставках (МосБилд, Неделя Дизайна)

## Part 9: Video content guidelines

### Why video critical

- В нише visual products видео даёт 12x больше engagement чем text+фото `[ГИПОТЕЗА: VividWorks/Zolak benchmark, requires verification]`
- Miralls = 0 видео на сайте - их главная слабость
- Dantone Home использует видео-закулисья и интервью

### 5 типов video для сайта

| Тип | Длительность | Содержание | Размещение |
|---|---|---|---|
| A. Продуктовое | 30-60 сек | Loop без звука + субтитры, продукт в интерьере → крупный план → human interaction | Каждая карточка товара (автоплей, muted) |
| B. Производственный процесс | 2-3 мин | Таймлапс + закадровый голос, 7 этапов от раскроя до упаковки | Страница «О компании» + Type 3 Technical Deep Dive |
| C. Монтаж | 1-2 мин | Пошаговая инструкция с нумерацией | Карточки товаров + FAQ + YouTube/VK Video |
| D. Кейс клиента | 1-3 мин | До/после + интервью | Type 4 Project Case Study + раздел «Проекты» |
| E. Сравнение/тест | 2-4 мин | Split-screen, закалённое vs обычное (тест ударом) | Type 5 Comparison + Type 3 Technical |

### Video placeholder pattern

Если видео ещё не снято - агент вставляет заглушку:
```
[📹 ВИДЕО: Производство закалки стекла GENGROUP - снять к DD.MM.YYYY]
```

Если есть - embed-код VK Video / YouTube + Schema VideoObject (см. Part 8.6).

## Part 11: Quality gates (Pre-Delivery checklist)

Before ANY content unit is delivered, проверь:

- [ ] **H1 единственный** (нет дублей)
- [ ] **Title ≤60 символов** (содержит ключ + модификатор)
- [ ] **Meta description 140-160 символов** (не копия lead)
- [ ] **Lead = прямой ответ** (нет исторических вступлений)
- [ ] **Числовая плотность ≥3 на H2-блок**
- [ ] **Anti-Slop passed** (ни одной фразы из Part 4 + humanizer-ru)
- [ ] **Inline CTA ≥2** (минимум калькулятор + консультация)
- [ ] **Внутренние ссылки ≥5** (товары + статьи + категории)
- [ ] **Факты verified** (все числа из Part 7 / encyclopedia / brand refs)
- [ ] **Тон = бренд** (GENGLASS ≠ GLASS-MEMORY ≠ VALONTI)
- [ ] **Нет водных абзацев** (первые 100 слов = мясо)
- [ ] **FAQ присутствует** (если статья >1500 слов, Schema-ready)

### Scoring (для FENIX)

| Критерий | Вес |
|---|---|
| Экспертная глубина (конкретика, числа, ТУ, сравнения) | 25% |
| SEO-архитектура (title, H-structure, перелинковка, кластер) | 20% |
| Конверсионность (CTA, формы, калькуляторы) | 25% |
| Anti-Slop (отсутствие воды, клише, generic) | 15% |
| Бренд-консистентность (тон, аудитория, фрейм) | 15% |

**Порог:** ≥8.0 = доставка. <8.0 = доработка с конкретным ТЗ от ФЕНИКСА (см. skill `phoenix-eval`).
