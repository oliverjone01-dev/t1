## Обязательные сценарии

Модель считается посчитанной только когда есть три сценария:

1. **База** - на фактических данных последних 90 дней.
2. **Downside** - худший сценарий, оптимистичная оценка × 0.3 (Q4 Reality Audit).
3. **Что должно быть верно** - явный список допущений, при провале любого из
   которых модель рассыпается.

## Правила

- Каждая цифра: `[ДАННЫЕ]` с путём к файлу или `[ГИПОТЕЗА]` с допущениями.
- `fixtures/` - референс, в расчёты не подаётся.
- ROMI >50x без сходящейся юнит-экономики - блок.
- Диапазон оценки шире 2x - помечать `[ШИРОКИЙ ДИАПАЗОН - НЕПРОВЕРЕНО]`.
