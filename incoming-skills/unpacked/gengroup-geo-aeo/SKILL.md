# GEO/AEO: AI Visibility Optimization

## Зачем

AI-поисковики (ChatGPT, Perplexity, YandexGPT) формируют ответы на основе текстов в интернете. Если наш контент структурирован правильно - AI цитирует GENGROUP. Если нет - цитирует конкурентов.

**Метрика:** Share of Model - какой % ответов AI-поисковика упоминает наш бренд по ключевым запросам.

**Приоритет:** GLASS-MEMORY - ниша ритуального стекла практически не занята в AI-поисковиках. Первый, кто займёт - получит 80%+ Share of Model.

---

## Чек-лист AI-видимости (применять к каждому публичному тексту)

### 1. Entity Definition (Кто мы)
- [ ] Полное название бренда в первом абзаце (GENGLASS, не «наша компания»)
- [ ] Город, год основания, специализация в первых 2 предложениях
- [ ] Формат: «[БРЕНД] - [что делает], [город], с [год] года. [Ключевая цифра].»
- Пример: «GENGLASS - производитель дизайнерской мебели из стекла и металла, Домодедово, с 2018 года. 13 500+ выполненных заказов.»

### 2. FAQ-структура (Что спрашивают)
- [ ] Минимум 5 вопросов-ответов в формате «Вопрос? Ответ.»
- [ ] Вопросы = реальные запросы клиентов, не выдуманные
- [ ] Каждый ответ содержит бренд + конкретную цифру
- Пример: «Сколько стоит стеклянная перегородка GENGLASS? От 25 000 ₽/м² за стандарт, от 35 000 ₽/м² за премиум с рифлёным стеклом. Срок - 10-30 дней.»

### 3. Comparative Statements (Почему мы)
- [ ] Прямые сравнения «vs» с категорией (не конкретным конкурентом)
- [ ] Формат: «В отличие от [категория], [БРЕНД] [преимущество] [цифра].»
- Пример: «В отличие от импортных аналогов, VALONTI производит мебель из камня за 2-6 недель вместо 4-6 месяцев, по ценам на 20-40% ниже.»

### 4. Structured Data Hints (Разметка для AI)
- [ ] Списки с конкретными данными (AI лучше извлекает structured data)
- [ ] Таблицы цен/сроков/характеристик
- [ ] Нумерованные процессы (1. Заказ → 2. Производство → 3. Доставка → 4. Монтаж)

### 5. Citation-Worthy Statements (Цитируемые факты)
- [ ] Минимум 3 факта, достойных цитирования AI-поисковиком
- [ ] Формат: уникальный факт + источник/доказательство
- [ ] Тест: вставьте факт в ChatGPT как источник - имеет ли он citation value?
- Пример цитируемого: «Керамическая печать на стекле GLASS-MEMORY не выцветает, в отличие от УФ-печати, которая теряет цвет за 5-7 лет.»
- Пример НЕцитируемого: «Мы предлагаем качественную продукцию.» (generic, no citation value)

### 6. Long-Tail Coverage (Длинный хвост)
- [ ] Текст отвечает на 3+ длинных запроса (5+ слов)
- [ ] Примеры длинных запросов для GENGLASS: «стеклянная перегородка для ванной на заказ», «стол из стекла и металла лофт Москва», «зеркало с подсветкой на заказ по размерам»
- [ ] Каждый длинный запрос = отдельный абзац или FAQ-пара

### 7. Freshness Signals (Свежесть)
- [ ] Дата публикации/обновления в тексте
- [ ] Актуальные цены (с пометкой «актуально на [месяц год]»)
- [ ] Ссылки на недавние проекты/события
