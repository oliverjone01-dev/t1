# Контур: дашборд SEO, GEO и Директ

Один интерфейс по нескольким проектам холдинга. Сейчас GENGLASS и GLASS-MEMORY.
Отвечает на два вопроса: сколько это в деньгах и стало ли лучше с прошлого раза.

Публикуется на `/kontur/` через `deploy-pages.yml`.

## Быстрый старт

```bash
cd kontur-dashboard
python3 tools/snapshot.py      # записать точку съёма в дневной ряд
python3 tools/build_data.py    # собрать data/kontur.json из выгрузок
python3 src/build.py           # собрать public/index.html
python3 tools/check_dash.py    # сторож
node   tools/smoke.mjs         # дымовой тест по всем экранам
```

`public/index.html` самодостаточен: открывается с диска, без сервера и без сети,
кроме трёх разрешённых CDN.

## Что внутри

- 52 экрана в 14 разделах, два проекта, светлая и тёмная тема
- Раздел «Деньги»: мост от показов до выручки с явными допущениями
- Раздел «Динамика»: сравнение периодов, вердикт «стало лучше или хуже», журнал съёмов
- Дневной ряд позиций, который накапливаем сами: у сводки домена в keys.so
  ретроспективы нет, пропущенная точка не восстанавливается
- У каждой цифры класс, источник и дата съёма по Протоколу 9
- Сторож с тестом на подмену: 18 намеренно испорченных версий, ловит все 18
- Данные на выгрузку от 19.09.2026, ряд из 66 точек с 10.07

## Данные

Дашборд ничего не собирает сам. Он читает выгрузки соседнего проекта
`gg-seo-geo-monster/data/` и свой дневной ряд `data/history/positions.ndjson`.
Сбор живёт в `.github/workflows/keyso-collect.yml`, фиксация точки в
`.github/workflows/kontur-snapshot.yml`.

## Главное правило

Выгрузки нет, значит стоит прочерк и класс ДЕМО. Правдоподобное число вместо
прочерка запрещено: рядом с настоящими цифрами заглушка перестаёт читаться как
заглушка, и через неделю никто уже не помнит, какая из них какая.
