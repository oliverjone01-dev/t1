# GENGLASS План-Радар - калькулятор выполнения плана ОП (Опт и Розница)

Одностраничный самодостаточный инструмент (`index.html`, без внешних зависимостей)
для отдела продаж GENGLASS. Дизайн - Fluxora (тёмная схема, Inter, bento-grid,
синий акцент). Открывается локально двойным кликом (полный HTML-документ,
`lang="ru"`, charset до заголовка).

## Что внутри

1. **Трекер месяца** - план, факт на дату (факт = поступившие оплаты, определение
   зафиксировать с РОПом), рабочие дни. Считает: % выполнения, отклонение от
   графика, темп в день, прогноз на конец месяца, требуемую дневную выручку.
   Финал месяца с дефицитом показывается красным «план не закрыт».
2. **Конструктор покрытия** - из чего складывается план: розничный вход
   (воронка платной рекламы: бюджет → CPL → квал → win-rate → чек), дизайнеры,
   комплектовщики, опт (новинки, дилеры), потолок производства ([НЕТ ДАННЫХ] -
   слайдер с красным флагом при превышении) и два разовых резерва пайплайна.
   Показывает покрытие плана, дефицит/запас, run-rate без резервов и требуемый
   win-rate для закрытия гэпа через воронку.
3. **Данные и допущения (Protocol 9)** - каждая цифра помечена [ДАННЫЕ] /
   [ГИПОТЕЗА] / [НЕТ ДАННЫХ], с датой снимка и источником; блок «кто и когда
   проверяет первый сигнал» (Борис - 1С, ДАТА - сверка фильтров, Роман - маржа).

## Источники цифр

- Аудит пайплайна Bitrix, направление Лофт, штамп 09.08.2026 (545 решённых
  сделок): win-rate 9%, чек 268к, CPL 3 160 ₽, цикл 46 дней, «КП отправлено»
  39/11,9 млн и «Долгострой» 32/21,5 млн (выборки «без касания») - [ДАННЫЕ].
- Снимок rop.json от 07.08.2026 (`.claude/skills/kostya-ai`): в стадиях 207 КП
  и 103 долгостроя - расхождение фильтров с аудитом указано прямо в инструменте,
  сверка за ДАТОЙ.
- `GG-markplan-2026/plan-motivaciya-prioritety.md` (черновик Богдана и прикидка
  Романа, 10-12.07.2026): цель 15 млн/мес (розница + опт, без маркетплейсов),
  вилки источников 3,0 / 11,5 / 19,0 млн - [ГИПОТЕЗА], перевод цели в план
  заблокирован до выгрузки baseline из 1С (Дыра №1).

## Ограничения (проговорены в самом инструменте)

- Scope: конверсии - направление Лофт, план - вся розница + опт. Перенос -
  допущение.
- Лаг цикла 46 дней: формула соединяет бюджет и выручку одного месяца,
  реальная касса от сегодняшних лидов - через ~1,5 месяца.
- Резервы пайплайна - разовые и верхняя граница: популяции пересекаются,
  суммы стадий с дефектами D07/D12, средний чек долгостроя 672к против 268к
  не объяснён.
- Трекер линейный по рабочим дням: конец месяца в закрытиях обычно гуще.
- Выручка ≠ прибыль: цель ведётся в паре с полом по марже (цифра - у Романа).
