# План-Радар v2 - исходник (не деплоится)

Исходник простой версии калькулятора плана с данными по менеджерам.
На GitHub Pages уходит ТОЛЬКО запечатанная копия
(`genglass-plan-calculator/v2/index.html`): payload зашифрован
AES-256-GCM по механике академии (`.claude/skills/kostya-ai/scripts/seal.mjs`,
шаблон `gate.html`) - решение Ивана от 08.08.2026 о публикации контуров
с персональными данными только запечатанными.

Пересборка после правок исходника:

    node gg-plan-radar-v2-src/build-sealed.mjs "<пароль>"

Пароль выдаёт Иван / РОП. Смена пароля = пересборка.

## Принятая цена решения (та же, что у академии)

Репозиторий публичный: фамилии менеджеров и их рабочие метрики в ЭТОМ
исходнике читаются кем угодно прямо на GitHub - печать закрывает только
страницу на Pages, это не анонимизация. Пароль печати конечной стойкости:
файл лежит публично, подбор идёт офлайн (для пароля академии цена названа:
порядка двадцати минут на одной видеокарте). Опубликованный файл не
отзывается. Всё это - цена, принятая Иваном 08.08.2026
(`gg-sales-academy/README.md`), здесь она только повторена.

Контроль рассинхрона: `genglass-plan-calculator/v2/BUILD.txt` хранит sha256
payload; воркфлоу деплоя сверяет фамилии ростера по всей папке перед
публикацией.
