# Разбивка заказов карточек по моделям, 26.10.2026

Запрос Ивана: визуально показать, какие модели дали заказы внутри каждой группы на вкладке «Тесты».
Это детализация действующей метрики, не изменение определения заказов, порогов или источников.

- Единица: заказано штук без status=cancelled (не число отправлений).
- Период: 15.10..min(последний полный день заказов по действующему правилу, 28.10).
- День: t + 3 часа (Москва), без t поле d; обрывок после максимального исходного d исключается.
- Группы: plan_card_groups_1510.json; withdrawn исключены из карточек, сохранены в магазине.
- Источник количества: orders_daily.ndjson, тот же проход и фильтры, что основной график.
- Модель: sku_taxonomy.json по SKU. Offer из замороженного состава для карточек. Не угадываем цвет по коду.
- Нет модели: явно подписанный артикул, его количество не теряется. Нет периода данных: неизвестно, не 0.
- Доля: количество модели / количество группы. Ранжирование по количеству; внутри раскрытия SKU с количеством.
- Инвариант: сумма моделей = существующая сумма карточки; сумма SKU = модель; аналогично всему магазину.
- Старые графики, цели, суммы и решения не меняются. Новые данные по API не нужны.

## Уточнение Ивана 26.10: компактная составная полоса
Выбран вариант «Составная полоса». Полные названия моделей и штуки видны сразу на цветных плашках; процентов в подписях нет. Тонкие сегменты над плашками сохраняют точные доли без минимальной ширины, включая модель с 1 шт.; полные названия на плашках переносятся, не обрезаются. Нажатие открывает SKU одной модели, повторное закрывает. Изменяется только представление, период/состав/суммы прежние.
