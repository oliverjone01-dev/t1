КОНТЕНТ-СТРАТЕГИЯ · РУБРИКАТОРЫ + КАНАЛЫ + YOUTUBE

Что снимаем, где публикуем и зачем каждая рубрика.

Каждый формат имеет задачу, у каждой рубрики - свой KPI-сигнал. Видео-ресурс дорогой, поэтому решение по YouTube принято заранее, а не «когда-нибудь».

РЕШЕНИЕ

YouTube/RuTube: один канал, а не два слабых

При «двух руках» два видеоканала = оба слабые. Длинное видео - дорогой ресурс. Решение принято, ниже - выбранная ветка и отложенная.

✓ Выбрано · делаем сейчас

Один канал на базе GENGLASS

Ведём YouTube/RuTube под GENGLASS как базу длинного видео. Из него режем вертикальные нарезки под Instagram / VK / TG.

VALONTI подсвечиваем ВНУТРИ этой базы (рубрика про кастом, мастеров, материалы) - отдельный канал не открываем.

Почему: GENGLASS массовее, быстрее набирает базу и окупает съёмочный цикл, кормит нарезки всех каналов. VALONTI-контент внутри = демонстрация производственной мощи группы (якорь доверия).

○ Отложено · по триггеру

Отдельный канал VALONTI

Откроем при выполнении любого условия (порог - ГИПОТЕЗА, заполняет команда):

- GENGLASS-канал стабильно набрал базу за 6+ месяцев;
- накоплено достаточно VALONTI-кейсов под отдельную сетку;
- запущен закрытый клуб VALONTI, которому нужен закрытый видеоформат.

До этого VALONTI B2D не нуждается в широком охвате YouTube - его аудитория идёт через Pinterest/Instagram pull и нетворк.

ВИДЫ КОНТЕНТА

Общий пул форматов

Reels / вертикаль

Нарезки из длинного, до/после, монтаж, скорость, эффект.

Карусели

«Как выбрать», разбор материала, сравнение, гайды - под сохранение.

Stories

FAQ, backstage, опросы, статусы, оперативка.

Длинное видео

Только GENGLASS-база: процесс, производство, обзоры, мастера.

Ситуатив / спецзаказы

Нестандартные реализации с колёс - топливо VALONTI-кейсов.

Pinterest-пины

Статичная эстетика интерьеров. Pull-канал, особенно для B2D.
