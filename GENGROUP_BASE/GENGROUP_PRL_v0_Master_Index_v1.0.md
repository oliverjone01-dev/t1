*01 · MANIFESTO*

# Зачем эта библиотека

GENGROUP это вертикально интегрированный производственный холдинг: 16 000 м² в Домодедово, 5 брендов, 60+ единиц оборудования, 27 000+ заказов за 8 лет. Технические знания группы накоплены, но рассыпаны по презентациям, ТУ, регламентам, скриптам ОП, чатам в Telegram. Один процесс описан в трёх местах с тремя разными цифрами.

Production Reference Library решает эту задачу. Это каноническая база знаний с одним источником правды по каждому параметру. Открыл нужный том - получил ответ. Параметр изменился - правка вносится в одно место и распространяется по библиотеке через версионирование.

#### Пять принципов

Один источник правды. - Ни одна цифра не существует в двух разных местах с разными значениями. При конфликте - canonical всегда побеждает.

Самодостаточность томов. - Каждый том можно открыть и работать. Перекрёстные ссылки даны, но не обязательны для понимания.

Машиночитаемость. - Все таблицы дублируются в XLSX Data Pack. Калькуляторы, AI-чат, SpiderBot работают с данными напрямую, не парсят DOCX.

Family identity. - Единый визуальный код по всей библиотеке. Чёрный фон, gold #C8A951, Inter. Тома различаются акцентами, но узнаются как семья.

Семантическое версионирование. - v1.0 - первая публикация. v1.1 - правки без структурных изменений. v2.0 - реструктуризация. Каждый артефакт несёт свою версию.

Если параметр процесса не описан в библиотеке - его официально не существует. Любой ответ ОП клиенту, любая страница сайта, любой слайд презентации проверяются по библиотеке.

# Стандарты качества

Каждый том библиотеки проходит цикл из четырёх обязательных этапов до публикации.

#### Цикл выпуска тома

Сбор и верификация. Все цифры подтверждаются в первоисточнике (ТУ, паспорт станка, регламент, ГОСТ). Цитирование из устаревших документов запрещено.

СПАРТАК-консилиум. Минимум 6 агентов проходят независимую дискуссию по содержанию, структуре, аудитории.

ФЕНИКС-аудит. Жёсткий циничный разбор. Минимальный порог принятия 9.9/10. Что ниже - возвращается в работу.

Финальная вёрстка и валидация. DOCX проходит конвертацию в PDF, ручную проверку рендера, валидацию через scripts/office/validate.py.

#### Что запрещено

Em dash («—»). Только дефис «-» или перестроение фразы.

Восклицательные знаки в основном тексте.

Слова «уникальный», «инновационный», «современный», «качественный» как самостоятельные характеристики.

Цитирование устаревших ТУ, прайс-листов, регламентов без ревизии.

Упоминание партнёрских торговых марок и юридических лиц поставщиков сырья / комплектующих в публичных артефактах.

Канцеляризмы, AI-buzzwords, формулы в духе «не просто, а».

*06 · VERSIONING*

# Семантическое версионирование

Каждый артефакт библиотеки несёт собственную версию по схеме MAJOR.MINOR. Версии независимы между томами: Том 2 может быть в v1.4, в то время как Том 7 в v1.0.

#### Правила инкремента

v1.0 → v1.1 - Правки без изменения структуры. Уточнение цифр, добавление параметра, исправление опечатки.

v1.x → v2.0 - Структурные изменения. Переразбиение разделов, переименование секций, изменение формата спец-карточек, перенос темы между томами.

v2.0+ - Major-релиз сопровождается changelog в разделе 10 каждого тома и обязательной нотификацией всех owners.

#### Триггеры новой версии

Изменения в действующих ТУ группы или обновление редакции.

Ввод нового оборудования или вывод существующего.

Изменение допусков, лимитов, габаритов в результате модернизации.

Запуск или закрытие продуктовой линейки.

Изменения нормативной базы (ГОСТ, ТР ТС).

Структурные изменения по итогам пользовательской обратной связи.

*08 · GLOSSARY*

# Глоссарий ключевых терминов

Расширенный глоссарий с детальными определениями, ссылками на ГОСТ и примерами применения - в Томе 8. Ниже базовый набор терминов, используемых сквозно по всей библиотеке.

| Закалка | Термообработка стекла нагреванием до 600-700 °C с последующим резким охлаждением. Делает стекло в 5 раз прочнее обычного и термостойким. После закалки механическая обработка невозможна. |
| --- | --- |
| Триплекс (многослойное стекло) | Конструкция из 2+ листов стекла, склеенных полимерной плёнкой EVA (0.38 мм) или ПВБ (Стратобель). При разбивании осколки удерживаются плёнкой. |
| Кромка карандаш | Радиусная обработка кромки с минимальным внутренним радиусом 52 мм. Используется для стеклянных столешниц и полок. |
| Кромка Евро | Прямая обработка кромки с фасками. Без полировки доступна с Rmin = 6 мм (4-10 мм) или 13 мм (12-19 мм). С полировкой - Rmin = 52 мм. |
| Фацет | Скос края стекла под углом до 60°. Ширина 5-50 мм в зависимости от толщины. Декоративный элемент зеркал и стеклянных дверей. |
| Гласслак | Технология окраски стекла после закалки. Используется когда нужна закалка перед окрашиванием. Расход 400 г/м² при ручном нанесении. |
| Стемалит | Технология окраски стекла до закалки с обжиговой эмалью. Краска впекается при закалке. Валковое нанесение 200 г/м² для крупных партий от 70 м². |
| Керамическая фотопечать | Цифровая печать керамическими красками с разрешением 300-1440 dpi. После печати требуется термообработка в печи закаливания. Печать наносится на тыльную сторону. В отличие от УФ-печати, не выцветает. |
| RAL | Международный каталог цветов лакокрасочных покрытий. Стандарт для покраски металлоконструкций и стекла. Группа работает по полной палитре RAL. |
| TIG-сварка | Аргонодуговая сварка неплавящимся электродом. Даёт чистый видимый шов без брызг. Используется на изделиях с высоким требованием к эстетике. |
| MIG / MAG-сварка | Полуавтоматическая сварка плавящимся электродом в среде защитного газа. Производительная, для серийных конструктивных швов. |
| TiN-покрытие | Декоративное покрытие нитридом титана методом PVD-напыления. Золотой глянцевый цвет, срок службы 20+ лет. Применяется на нержавеющей стали. |
| Полный цикл | Производство изделия от резки исходного материала до упаковки готового продукта внутри одного цеха. Минимум 2 операции цикла, минимальный заказ от 50 000 ₽. |
| OEM / White Label | Производство под чужим брендом с соблюдением NDA. Заказчик продаёт продукт под своим именем, мы фиксированы как невидимый исполнитель. Минимум 100 000 ₽/мес. |
| NO-GO | Список заказов, которые группа не принимает. Чистая лазерная резка как единственная операция, B2C-мелочь, демпинг, тяжёлые металлоконструкции, операции стоимостью менее 50K. |
| Видимый металл | Часть металлического изделия, которая остаётся открытой в финальном интерьере. Зона ответственности с повышенными требованиями к качеству шва, покрытия и геометрии. |
| Допуск (tolerance) | Максимально допустимое отклонение фактического размера от номинального. По длине / ширине, диагоналям, толщине, плоскостности, положению отверстий. См. Том 6. |
