# ROADMAP - GG-SEO/GEO Монстр

Путь от скелета до боевого сайта на отдельном URL. Даты - целевые, не обещания.
Каждый этап закрывается замером, а не ощущением «готово».

## Этап 0 - Скелет (сделано)

- [x] Charter проекта (`README.md`)
- [x] Хаб-лендинг с витриной модулей и статусом (`public/index.html`)
- [x] Структура папок и sample-данные (`data/*.sample.json`)

## Этап 1 - Наполнение хаба живыми данными (цель: 2 недели)

- [ ] `data/clusters.json` - реальная карта кластеров pillar/satellite (владелец: semyon)
- [ ] `data/citations.json` - baseline замер: цитирует ли ChatGPT/Perplexity/YandexGPT
      бренд по 20 целевым запросам (владелец: semyon + data, каждая цифра с датой)
- [ ] Хаб читает JSON, а не хардкод в HTML
- [ ] feniks Step 12.5 на baseline-замер (нельзя показывать непроверенные цифры)

## Этап 2 - Content Forge UI (цель: +3 недели)

- [ ] Форма: кластер ключей → вызов промпта (`../SEO_PIPELINE_content_forge_prompt.md`)
- [ ] Level 1 авто-checks (Entity Definition, ≥3 числа на H2, Anti-Slop, em dash)
- [ ] Предпросмотр 6 блоков + экспорт Schema.org JSON-LD

## Этап 3 - Публичный деплой (цель: после этапов 1-2)

- [ ] Зафиксировать домен (кандидаты: `seo.gengroup.*` / `geo.genglass.ru`)
- [ ] HITL-гейт Ивана (Protocol 6: публичная коммуникация)
- [ ] feniks финальный аудит перед первым публичным деплоем
- [ ] Деплой статики, проверка Schema.org через validator.schema.org

## Kill Criteria (авто-stop, Protocol 6)

- feniks score < 5.0/10 на любом артефакте хаба
- Показ цифры цитируемости/позиции без источника и даты (Protocol 9 hard rule)
- Прямая команда Ивана «СТОП»
