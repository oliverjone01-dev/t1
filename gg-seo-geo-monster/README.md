# GG-SEO/GEO Монстр

Отдельный продукт GENGROUP: движок органической и AI-видимости для 5 брендов
(GENGLASS, VALONTI, GENTERO, Metal-GM, GLASS-MEMORY). Разворачивается как
самостоятельный сайт на отдельном URL по готовности.

Владелец домена задачи: **semyon** (SEO/AEO/GEO). Гейт перед публикацией -
**feniks** (Step 12.5). Данные по цифрам - **data** (Protocol 9).

## Зачем это отдельный проект, а не папка в аналитике

- **Другая аудитория.** Аналитика (`analytics-mvp/`) - для коммерческого блока
  (P&L, воронка OZON). Этот проект - для контент- и SEO-команды: кластеры,
  публикации, цитируемость в AI-поиске.
- **Другой домен по готовности.** Хаб выезжает на отдельный поддомен
  (кандидат: `seo.gengroup.*` или `geo.genglass.ru`), а не как раздел
  существующего сайта. Отсюда изолированная сборка и деплой.
- **Другой цикл.** SEO меряется неделями и месяцами, аналитика МП - днями.

## Что внутри (модули)

| Модуль | Статус | Что делает |
|---|---|---|
| **Content Forge** | есть промпт, нет UI | Кластер ключей → статья (6 блоков: META, текст, промпты картинок, Schema.org, GEO-чеклист, перелинковка). Источник: `../SEO_PIPELINE_content_forge_prompt.md` |
| **GEO/AEO Checklist Engine** | скилл готов | 7-точечная проверка цитируемости в ChatGPT / Perplexity / YandexGPT / Gemini. Источник: скилл `geo-aeo` |
| **AI Citation Tracker** | план | Замер: цитирует ли AI-поиск бренд по целевым запросам. Baseline → динамика |
| **Schema.org Generator** | план | Article + FAQPage + Product + BreadcrumbList JSON-LD под вставку в `<head>` |
| **Keyword Clusters** | план | Карта кластеров pillar/satellite с перелинковкой |
| **Rank Monitor** | план | ТОП Яндекс / Google по кластерам, без розовых очков (реальные позиции) |

## Структура папки

```
gg-seo-geo-monster/
  README.md            # этот файл - charter проекта
  ROADMAP.md           # этапы до боевого сайта, с датами и Kill Criteria
  public/              # статический сайт (то, что выезжает на отдельный URL)
    index.html         # хаб-лендинг: витрина модулей + статус
    assets/            # css/js/img (пока inline в index.html)
  data/                # источники хаба (клетки, замеры цитируемости) - JSON
    clusters.sample.json
    citations.sample.json
```

## Как запустить локально

Статика без сборки. Любой статический сервер из папки `public/`:

```bash
cd gg-seo-geo-monster/public
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой на отдельный URL (по готовности)

Пока не разворачивать в бой. Кандидаты на хостинг статики: тот же контур,
что и остальные хабы GENGROUP. Перед первым публичным деплоем - обязательный
Step 12.5 (feniks) и решение Ивана по HITL (публичная коммуникация, Protocol 6).
Домен фиксируется в `ROADMAP.md` после подтверждения.

## Границы (чего проект НЕ делает)

- Не публикует контент сам - это делает контент-конвейер (n8n Content Forge)
  после ревью. Хаб только показывает состояние и даёт инструменты.
- Не заменяет `analytics-mvp/` - там деньги и продажи, здесь видимость.
- Цифры цитируемости и позиций подаются как замеры с датой и источником,
  а не как прогноз. Прогноз без источника = блок (Protocol 9).
