Автоматизация сообщений в чаты команды GG

Единая панель, из которой команда собирает, расписывает и выгружает автосообщения в рабочие чаты - напоминания о планёрках, KPI-сводки, уведомления о деплоях, кризис-алерты. Панель генерирует готовый конфиг для планировщика (GitHub Actions cron / n8n / бот Bitrix24) - отправку делает планировщик по расписанию, панель ничего не шлёт сама и не хранит секретов.

Как это работает

1
Выбираешь шаблон и каналВ «Конструкторе» берёшь готовый шаблон, подставляешь переменные, видишь превью как в чате.
2
Ставишь расписаниеCron-выражение или разовая отправка. Панель показывает расшифровку «человеческим языком».
3
Выгружаешь конфигПолучаешь JSON-правило + готовый payload для Telegram Bot API или входящего вебхука Bitrix24 (imbot.message.add).
4
Планировщик отправляетКонфиг подхватывает cron GitHub Actions / n8n / бот - строго по расписанию, без ручных действий.

Границы (честно)

  • Панель - генератор конфигов и превью, а не сервер отправки. Токены бота и вебхуки живут в секретах планировщика, не в браузере.
  • Всё, что ты настроил, лежит в localStorage этого браузера - можно выгрузить в JSON и закоммитить в ветку как источник правды.
  • Реальную рассылку в чаты запускает планировщик - это отдельный HITL-шаг: правило проверяет человек перед включением.

Всё, что собрано в «Конструкторе». Это и есть источник правды для планировщика - выгрузи одним файлом и закоммить в ветку.

        

          
          
        

        

      


      
      

        
Каналы

        
Чаты команды

        
Куда бот может слать. ID чата и учётные данные подставляет планировщик из своих секретов - здесь только адресный справочник.

        

          
КаналПлатформаНазначениеСекрет планировщика

          
        

        
Секреты (токен Telegram-бота, входящий вебхук Bitrix24) задаются в настройках репозитория / n8n, не в этой панели.

      


      
      

        
Подключение

        
Как включить отправку

        
Панель уже готова. Чтобы правила реально уходили в чаты - подключи любой из планировщиков ниже.


        
Вариант A · GitHub Actions cron

        

          
Выгрузи schedule.json из вкладки «Расписание», закоммить в ветку, добавь воркфлоу с таким шагом. Секреты - в Settings → Secrets.

          
.github/workflows/gg-msg-cron.yml

        


        
Вариант B · Telegram Bot API

        

          
    
            
  • Создай бота у @BotFather, добавь его в рабочий чат, дай право писать.
    • 
            
  • Токен положи в секрет TG_BOT_TOKEN, ID чата - в chatId канала.
    • 
            
  • Payload из «Конструктора» уже в формате sendMessage (parse_mode: HTML).
    • 
          

        


        
Вариант C · Bitrix24 чат-бот

        

          
    
            
  • Используй входящий вебхук портала (B24_WEBHOOK_URL, уже есть в секретах репозитория).
    • 
            
  • Метод imbot.message.add или im.message.add с DIALOG_ID нужного чата.
    • 
            
  • Панель отдаёт payload и под этот формат - переключается по каналу назначения.
    • 
          

        

        
Перед включением боевой рассылки правило проходит проверку человеком - HITL-гейт (Protocol 6). Панель ничего не публикует сама.
