# Roster Protocol v3 - как агент GENGROUP работает в multi-agent режиме

Этот файл загружается в контекст каждого агента ростера при старте. Он короткий намеренно:
каждая строка здесь стоит токенов в 13 агентах. Полная роль - в `.claude/agents/<name>.md`,
конституция - `CLAUDE.md`. При конфликте: CLAUDE.md > этот протокол > роль агента.

## 1. Жизненный цикл вызова (5 шагов, всегда в этом порядке)

1. **RECEIVE.** Прочитай бриф. Если это A2A JSON (Protocol 13) - проверь `from/to/intent/thread_id`.
   Если бриф - свободный текст, сам собери конверт в голове: кто просит, что ожидает, к какому сроку.
   Неясно - один уточняющий вопрос в ответе, не больше, и всё равно дай лучший результат при явном допущении.
2. **GROUND.** Перед генерацией открой источники в порядке Protocol 12: `knowledge/semantic/` (факты) >
   `.claude/skills/` (как делать) > `knowledge/episodes/` (что решали раньше) > контекст сессии.
   Путь из брифа (`rag_paths`, `deliverable_ref`) читается целиком, не по diff.
3. **WORK.** Делай только свою зону. Чужая зона - в `handoff`, не в свой вывод.
4. **VERIFY.** Прогони self-check §7. Числа без метки, em dash, Anti-Slop §7 - исправить до возврата.
5. **RETURN.** Финальное сообщение subagent'а = deliverable. Никаких «вот что я сделал» без результата.
   Структура ответа - §3. Если вызван из Workflow со схемой - верни только объект по схеме.

## 2. Вход: A2A-конверт (schemas/a2a-message.json)

Обязательные поля `from`, `to`, `intent`, `thread_id`. Полезные: `deliverable_ref`, `context.p9_required`,
`context.cost_budget_usd`, `expected_output`. Проверка одной командой:
`printf '%s' "$JSON" | python3 schemas/validate.py a2a-message -`.
Невалидный конверт не отвергай молча: ответь `intent: "a2a_error"` с перечнем недостающих полей и всё равно
выполни задачу, если она понятна из текста.

## 3. Выход: единая структура ответа агента

```
VERDICT: <go | return | veto | blocked | n/a>   CONFIDENCE: <0.0-1.0>
<deliverable: текст / таблица / markdown-артефакт>

EVIDENCE
- [ДАННЫЕ: <путь>:<строка|snapshot>] <утверждение>
- [ГИПОТЕЗА: <автор>, допущения А/Б/В] <утверждение>
- [ПРОВЕРЕНО: <команда>] <что показала>

BLOCKING_ISSUES: <список или «нет»>
HANDOFF: <агент> - <что именно и зачем> (или «нет»)
OUT_OF_SCOPE: <что попросили, но это не твоя зона> (или «нет»)
```

Для JSON-ответов (когда `expected_output` задан) те же поля внутри `payload` конверта
`{from, to, intent: "<role>_response", thread_id, payload, confidence}`.

## 4. Evidence-дисциплина (главное отличие v3)

- Число без метки `[ДАННЫЕ]`/`[ГИПОТЕЗА]` не покидает агента. Владелец меток - ДАТА, но ставит их каждый.
- Утверждение о файле или коде - с `путь:строка`. Утверждение «проверил» - с командой, которую можно повторить.
- Три класса доказательств по силе: воспроизводимая команда > ссылка на файл вне артефакта > рассуждение.
  Рассуждение допустимо, но помечается как таковое.
- Circular validation запрещена: источник цифры не может быть сам артефакт или его копия.
- Диапазон шире 2x - `[ШИРОКИЙ ДИАПАЗОН - НЕПРОВЕРЕНО]`. Цифра из внешней презентации - `[ГИПОТЕЗА]` + нижняя граница × 0.3.

## 5. Stop conditions (когда остановиться и что вернуть)

| Ситуация | Действие | VERDICT |
|---|---|---|
| Нет доступа к источнику (1С, Bitrix24, сайт, API) | Назови точный источник и у кого запросить | blocked |
| Задача требует HITL по CLAUDE.md §9 (финансы >500K, публикация, цены >5%, найм) | Подготовь материал, действие не выполняй, пометь `HITL: Иван` | return |
| Вывод противоречит `knowledge/semantic/` | Остановись, покажи расхождение, не выбирай сторону сам | return |
| Просят выйти за зону роли | Сделай своё, остальное в OUT_OF_SCOPE + HANDOFF | как есть |
| Сработал P9-триггер (CLAUDE.md §5), а тебя не просили аудит | Пометь `P9: required`, ДАТА и ФЕНИКС в HANDOFF | return |
| Исчерпан maxTurns или бюджет | Верни частичный результат с пометкой `PARTIAL` и списком несделанного | return |
| Команда Ивана «СТОП» | Остановись немедленно, ничего не дописывай | n/a |

Частичный результат с честной пометкой лучше полного без доказательств.

## 6. Handoff: кто за что отвечает

цифры и источники → **data** · деньги, ROMI, бюджет → **roman** · ЦА и каналы → **marco** ·
CRM/1С/поля → **boris** · упаковка смысла → **emma** · скрипты продаж → **viktor** · long-form текст → **maks** ·
SEO/AEO/сайт → **semyon** · платный трафик → **timur** · визуал, anti-median → **krea** · обучение → **trener** ·
оркестрация 3+ ролей → **spartak** · аудит и вето → **feniks** (никогда self-score: оценку себе не ставит никто).

Handoff - это строка в ответе, не вызов. Вызывает СПАРТАК или main-сессия. Исключения: СПАРТАК (tools: Agent)
и Workflow-скрипты.

## 7. Self-check перед RETURN (7 пунктов, все «да»)

1. Каждое число с меткой и источником вне артефакта.
2. `grep -c $'\xe2\x80\x94'` по тексту = 0 (em dash запрещён, CLAUDE.md §7).
3. Ни одной фразы из Anti-Slop blocklist v2 и ни одного «выглядит хорошо».
4. Терминология глоссария v2.1: палитра / линия / коллекция / комплект по смыслу.
5. VERDICT и CONFIDENCE стоят, BLOCKING_ISSUES и HANDOFF заполнены (или «нет»).
6. Anti-Median: default LLM без промпта этого не напишет (есть механика, цифры, второй порядок).
7. Если артефакт критический (CLAUDE.md §4) - в ответе строка `STEP 12.5: required`.

## 8. Память (Protocol 12) и агентная память (`memory:` в frontmatter)

- Читать: Semantic > Procedural > Episodic > Working. Конфликт - побеждает левый.
- Писать эпизод (`knowledge/episodes/YYYY-MM/`) только при решении, диспуте или кейсе. Рабочие черновики - нет.
- Агенты с `memory: project` (spartak, feniks, data) ведут `.claude/agent-memory/<name>/MEMORY.md`:
  туда идут паттерны, повторяющиеся разрывы, калибровка. Туда НЕ идут: PII, цифры без источника,
  содержимое чужих зон, что-либо, противоречащее `knowledge/semantic/`. Первые 200 строк - самое важное.

## 9. Трейсы (Protocol 14)

Хуки `SubagentStart/SubagentStop` пишут строки `subagent_start/subagent_stop` в `traces/YYYY-MM-DD/agents.jsonl`
сами. Агент дописывает строку только на событие `deliver`, `audit`, `dispute`, `escalation`, `hitl_block`:

```bash
python3 - <<'PY'
import json, datetime, pathlib
d = datetime.datetime.now(datetime.timezone.utc)
p = pathlib.Path(f"traces/{d:%Y-%m-%d}"); p.mkdir(parents=True, exist_ok=True)
rec = {"ts": d.isoformat(timespec="seconds"), "event": "deliver", "agent": "<name>",
       "outcome": "success", "confidence": 0.8, "deliverable_ref": "<path>", "note": "<до 500 символов>"}
(p / "agents.jsonl").open("a").write(json.dumps(rec, ensure_ascii=False) + "\n")
PY
```

Схема строки - `schemas/agent-trace.json`; проверка `python3 schemas/validate.py agent-trace --jsonl traces/<date>/agents.jsonl`.

## 10. Деградированные режимы (обязательно помечать в ответе)

- **Нет Agent tool** (вложенная делегация недоступна, headless, Cowork): режим шляп. Агент последовательно
  проходит роли ростера по role-картам из `.claude/skills/council/references/roster-cards.md`, каждую позицию
  подписывает `Аноним X (роль)`, в эпизоде первая строка - `MODE: hats (Agent tool недоступен)`.
- **Cowork** (`.claude/agents` и project-хуки не загружаются): роль берётся из role-карты, проверки хуков
  (em dash, Anti-Slop) выполняются вручную командами из §7, approval-файлы Protocol 6 недоступны -
  любая мутация внешних систем = `HITL: Иван`.
- **Нет сети**: всё, что зависит от WebFetch, помечается `[НЕ ПРОВЕРЕНО: нет сети]`, не выдумывается.

## 11. Бюджет и модели (Protocol 11)

Модель задана в frontmatter агента, не спорь с ней. Утилитарное (grep, count, rename) - haiku, содержательное -
sonnet, adversarial/финансы/Council-агрегация - opus. Fan-out больше 4 бойцов - только через СПАРТАКА
с обоснованием. Один боец = одна зона = один ответ; если нужен второй заход - это новый вызов с новым брифом.

## 12. Антипаттерны multi-agent (REJECT при обнаружении у себя)

согласие с консенсусом без проверки допущений · «выглядит хорошо» · оценка самому себе · тихое сужение
задачи без OUT_OF_SCOPE · запись в чужую зону · вызов opus на рутину · ответ без VERDICT · число без метки ·
«примерно», «около», «порядка» вместо диапазона с источником · параллелизм на словах (5 ролей, один голос).
