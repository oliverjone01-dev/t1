# Планирование, происхождение задач и сессия — 10.11.2026

Контракт пользователя: переименовать plan → «Развитие», delegate → «Сделать позже»; сохранять вход при переходах; дата постановки из источника/момента создания, только чтение на сайте; общий диапазон по пересечению start–due, удобный выбор и сдвиг недели/месяца; статусы реестра со счётчиками; зелёное «Готово» в Sheets; отделы и фото команды из Bitrix24.

Реализация и приёмка:
- Даты: существующая N (индекс 13), без вставки столбцов и изменения служебных Q:V. Старые N не перезаписываются. ISO, московское время сообщения, дата Sheets и ручная дата читаются. Новая задача сайта получает timestamp при сохранении. Проверить round-trip, пустую историю, независимое слияние и неизменяемость в редакторе.
- Период: включительно по пересечению [start || due, due || start], создание не участвует; неизвестный рабочий период не придумывается. Проверить охватывающие интервалы, границы, отдельную дату, отсутствие дат, переход года и високосный месяц.
- Сессия: восстановление действующего разрешения между страницами/вкладками, сохранение локальных правок при истечении токена, явный выход очищает сохранённую связь. Google GIS выдаёт ограниченный по времени access token: продление только по пользовательскому действию, без новых scopes/backend. Не обещать бессрочный Google grant.
- UI: общий popover выбора двух дат, быстрые периоды и сдвиги, синхронизация календаря, счётчики до выбора статуса, отделы по подтверждённому справочнику. Клавиатура, Escape, узкая/широкая ширина и обе темы.
- Внешние изменения: только N3 и правила «Готово» в двух задачных вкладках; остальные значения, формулы и проверки не менять.
- Четыре чужих изменённых Telegram-файла сохранить побайтово; сборки Telegram выполнять в изолированной временной копии принятой базы.

Проверки и результат будут дополнены после реализации.
