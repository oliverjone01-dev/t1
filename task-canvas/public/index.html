БЫСТРЫЙ СТАРТ

Место определяет действие

  1. Приоритеты. Четыре квадрата «важно × срочно». Входящие остаются без приоритета до вашего решения.
  2. Команда. Перенесите карточку в дорожку человека, чтобы назначить его ответственным. Добавьте дорожку кнопкой «+ Ответственный».
  3. Сроки. Перенос задаёт дату: сегодня, конец этой или следующей недели. В «Позже» — понедельник через неделю. Точную дату меняйте в деталях.
  4. Навигация. Колесо / трекпад перемещают обзор; Ctrl/Cmd + колесо — зум под курсором. Пробел + мышь — рука. F — вся доска.
  5. Карточка. Двойной клик или Enter — детали. Перетаскивание — размещение по сетке. В деталях можно менять все рабочие поля.
  6. Сохранение. Локальная копия — сразу; в Google — после подтверждённой синхронизации. Экспорт JSON — копия всей доски с позициями. Ctrl/Cmd+Z — отмена последнего изменения.

Подключите Google и выберите таблицу «ЕМО - Раюшкин 2026». Доска синхронизирует первую вкладку примерно каждые 20 секунд и после ваших правок. После перезагрузки страницы вход может потребоваться повторно. Правки без сети остаются на устройстве до подключения. Одновременные изменения одного поля требуют выбора версии; таблица не предоставляет блокировку от строго одновременной ручной правки. Экспорт сохраняет резервную копию.
