# knowledge/reflexion - Protocol 15 (Reflexion, CC-19)

Ежемесячные ретро multi-agent системы. Один файл на месяц: `YYYY-MM.md`. Создаётся skill'ом `/reflexion`
(`.claude/skills/reflexion/SKILL.md`), синтез - СПАРТАК, гейт - ФЕНИКС, меры утверждает Иван.

Вход: `traces/YYYY-MM-DD/agents.jsonl` (Protocol 14, агрегация `trace-summary.py`), эпизоды месяца,
агентная память (`.claude/agent-memory/*/MEMORY.md`).

Правило: правки `calibration-anchors.md` и `CLAUDE.md` по итогам рефлексии - только после решения Ивана.
Файла за месяц нет = CC-19 не запускался = критерий «≥1 reflexion-driven update/мес» не выполнен.
