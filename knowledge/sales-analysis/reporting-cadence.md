# Периодичность отчётов: день / неделя / месяц

Принцип: разная частота ловит разное. Дневной отчёт про деньги сегодня, недельный про развитие менеджера, месячный про управление отделом. Смешивать нельзя, иначе картина врёт: наказывать за один плохой день несправедливо, а ждать месяц, чтобы не потерять горящую сделку, поздно.

## Ежедневно - оперативка «деньги сегодня» (детерминированно, без ИИ/API)
Короткий список действий на сегодня, без оценок навыков. Считается из снимка правилами, API не трогает.
- новые «КП без дожима» (отправили КП, касания нет);
- просроченные дела на сегодня;
- горящие тёплые сделки без касания (крупный чек, тишина);
- «клиент написал - ответа нет».
Куда: чат отдела / дашборд. Цель: не потерять деньги сегодня. Оценок навыков здесь НЕТ - один день не тренд.

## Еженедельно - коучинг менеджера (ИИ-разбор)
Профиль менеджера с разбором навыков и закрытым циклом обучения.
- навыки по 6 критериям + принципы GG (следующий шаг, боль, 3D-виз, промежуточное да);
- соответствие скрипту, КП-без-дожима %, размытые сроки, слепые зоны;
- блок рекомендаций «над чем поработать»;
- ПРОВЕРКА выполнения рекомендаций прошлой недели (дельта по каждой метрике: стало/было).
Цель: развитие. Почему неделя, а не день: поведение меняется за неделю, дневной шум по навыкам нечестен и демотивирует.

## Ежемесячно - управление отделом (синтез + тренды)
Картина по отделу для решений Ивана и РОПа.
- системные дефекты (что воспроизводится у большинства - это процесс, а не человек);
- тренды по менеджерам: кто прогрессирует, кто застыл (дельта индекса и ключевых метрик за месяц);
- конверсия и цикл по типу клиента (B2C / дизайнер / B2B / дилер) и по ассортименту;
- эффект обучения: сдвинулись ли сквозные метрики (обещания с датой, КП-без-дожима, отработка возражений).
Цель: где чинить процесс, кого учить, кого в PIP (последнее - через sales-director + Иван). Почему месяц: достаточно данных, шум выходных и отпусков усреднён - самая честная картина.

## Как это ложится на правило «API только в дашборде»
- Ежедневная оперативка - детерминированная, без ИИ, работает сама.
- Недельный и месячный ИИ-разбор - сейчас строю я (baseline, в сессии, без API), дальше по клику в дашборде или через нового бота «Константин».
- Персональные оценки сотрудников - HITL: перед рассылкой людям апрув Ивана (Protocol 6).
