# Аварийный адрес GG и переключатель владельца

Основной адрес: https://dash.genglas.ru/
Аварийный адрес: https://201.51.7.251:8443/
Настройки восстановления: https://201.51.7.251:8443/_access/recovery/

- Оба входа обслуживают /srv/gg/www/current и одни базы данных. Переноса или дублирования данных нет.
- Прежний Basic Auth сохранён. Domglass продолжает использовать отдельный файл паролей.
- Переключатель в корневой админке видит только yanchoglov; сервер также проверяет владельца, CSRF и точный Origin.
- Единственное состояние: /srv/gg/routing/mode.json (без секретов). Изменяется атомарно сервисом gg-access-api.
- Обычные страницы и данные доступны на выбранном входе. После входа другой адрес перенаправляет на выбранный.
- /_access/recovery/ доступен только владельцу при любом режиме; /_access/api/ сохраняет собственные проверки прав.
- /healthz не содержит данных. Закрытый audit bridge сохраняет штатную отдельную авторизацию.
- TLS на IP обслуживается только на порту 8443. Обработчики 443 других проектов не меняются.
- Сертификат IP выдан отдельным Certbot (/opt/gg-emergency-certbot), конфигурация /etc/gg/ip-acme-production.
- gg-ip-certificate-renew.timer проверяет продление дважды в сутки и перезагружает nginx только после nginx -t.

## Отчёты
- Штатные Node-процессы gg-job используют tools/report-links-preload.mjs.
- Перед обычной отправкой ссылки на собственные дашборды и известные GitHub Pages-дашборды приводятся к выбранному адресу.
- CRM-ссылки, получатели, ключи, тексты показателей и расписания не меняются.
- Данные берутся из обычных файлов /srv/gg/data и локальных сервисов VPS, а не из публичного домена.
- Для shell-сводки адрес передаётся через GG_REPORT_DOMAIN.
- Ранее отправленные сообщения не редактируются.
- Тесты используют искусственные данные и подменённый fetch: сетевых вызовов Telegram/OpenAI нет.

## Сохранение снимков
gg-job коммитит только папку своей ветки. gg_data_commit проверяет и коммитит только указанный scope. Это исключает попадание закрытых служебных предпросмотров и чужих staged-изменений в коммит снимка. Права закрытых папок не ослабляются.
