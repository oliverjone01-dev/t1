04Что это значит для GENGLASS (простыми словами)

  • Главное слово рынка «межкомнатные перегородки» (28 227 показов в месяц) занято не нами. Его держит маленький специализированный loftcase.ru, а не крупный alfaporta.ru или union.ru. Это значит: побеждает точность страницы под запрос, а не размер каталога.
  • Мы платим за рекламу перегородок 133 109 ₽ за последние 30 дней (данные Директа, обновлено на 14.07.2026 - цифра выросла с 117 668 ₽ по прошлому замеру 10.07.2026) при почти нулевой бесплатной поддержке по головным словам этого рынка.

  • union.ru тратит на рекламу больше всех в выборке - ≈1 147 652 ₽/мес, в 6 раз больше alfaporta.ru. Если Иван рассматривает расширение рекламного бюджета на перегородки, это ориентир, с кем реально конкурировать за клик, не только за позицию в органике.

05Ограничения данных (честно)

Единственный домен без данных в этом срезе - punycode-цель окна-хауз.рф (11-я в конфиге мониторинга), которая вернула честный HTTP 404 «Домен не найден» от keys.so, а не техническую задержку - система теперь добирает такие ответы автоматически (ретрай + еженедельный контроль по понедельникам), но 404 - это не 202, повторный сбор его не исправит без проверки самого домена в конфиге.

  • «Балл видимости» (vis) - внутренняя шкала keys.so, не откалиброванная напрямую против рекламных кабинетов или Яндекс.Вебмастера - использовать для сравнения между доменами внутри одного среза, не как абсолютную метрику.
  • Рекламный бюджет (adcost.average) для alfaporta.ru, union.ru, loftkrel.ru - расчётная оценка инструмента keys.so, не факт из чужого рекламного кабинета - к нему нужно относиться как к ориентиру, не как к точной цифре.

06Глоссарий (для нечитающих SEO-жаргон)

  • it1 / it3 / it5 / it10 / it50 - сколько запросов сайта попадает на позиции 1 / в топ-3 / топ-5 / топ-10 / топ-50 Яндекса. Чем больше it10 при том же it50 - тем эффективнее сайт «дожимает» свои ключи до первой страницы.
  • Балл видимости (vis) - внутренний индекс keys.so: сколько трафика теоретически получает сайт по всем своим позициям вместе, с поправкой на частотность запросов.
  • ws (частота Wordstat) - сколько раз в месяц люди в Яндексе ищут именно эту фразу.
  • Балл видимости в ИИ (aiAnswersCnt) - число ответов Яндекс.Алисы, где упоминается домен - предвестник AI Citation Rate, который считается отдельно (см. report-genglass.html §06).
  • Код 202 - технический ответ сервера keys.so «отчёт готовится» на момент первого запроса, не «домена не существует» и не «данные нулевые». Дозабор всех 7 доменов выполнен вручную 14.07.2026; отдельно мониторить это больше не нужно - система теперь добирает такие ответы автоматически (ретрай + еженедельный контроль по понедельникам).
  • HTTP 404 «Домен не найден» - другой ответ, чем код 202: keys.so по существу не знает такого домена в своей базе. Повторный сбор его не решает - нужна проверка самого домена (опечатка, отсутствие сайта, домен вне базы msk).
  • DR (Domain Rating) - условный рейтинг силы ссылочного профиля домена по внутренней шкале инструмента.
