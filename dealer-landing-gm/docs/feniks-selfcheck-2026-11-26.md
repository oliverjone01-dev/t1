Не проверено: реальный iPhone и Safari; правило «медленная сеть → только постер» (эмуляция DevTools не меняет `navigator.connection`); поведение с программами чтения с экрана для видеоблоков.

Итерация 2 (по аудиту ФЕНИКСА, return 6.1): убраны анимации фона и переднего плана первого экрана, постеры и фотокопии грузятся лениво, фотокопии ужаты до 98–198 КБ. Замер теми же пробами (локально, HTTP/1.1): компьютер Fast 4G LCP 1,09 с против 0,93 с в main, стартовый вес 2,93 МБ против 2,84 МБ; телефон Slow 4G LCP 2,99 с против 2,93 с, вес 1,76 МБ против 1,68 МБ `[ДАННЫЕ: out/lcp.jsonl]`. Кнопка заявки на телефоне скрывается при фокусе с клавиатуры, у кнопки паузы убран aria-pressed, селектор `styles.css:637` учитывает h3.
