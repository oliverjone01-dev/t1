## 2026-10-26 — отдельный доступ Домгласс

- Рабочий адрес: `https://dash.genglas.ru/gg-dg/`. Собственный логин и каталог публикации. Общий API и пользовательский файл ГГ не используются.
- Прежние адреса GitHub Pages удалены без перенаправления; CRM-снимки собираются на VPS каждые 15 минут. Код, спецификация и история разработки остаются в Git.
- Убраны скорость по этапам, причины отказов в сделках и ранее перечисленные внутренние блоки. Убраны внешние переходы к CRM и другим дашбордам; идентификаторы в таблицах остаются текстом.
- Основная воронка расположена вертикально. Блоки денег идут в порядке: в работе, выиграно, упущено. Переключатель сделок/продаж расположен рядом с количеством/суммой.
- Предоплата — сумма по умолчанию. Если прошлое значение отсутствует или равно нулю, динамика показывает нейтральные 0% с пояснением. При ненулевой базе используется рассчитанное изменение; предыдущий интервал равен выбранному по длительности.
- Календарь: вход, остаток в работе, выход с предоплатой/отказом, производство, отгрузка, завершение. Удалены отдельные строки КП, решения и долгостроя.
- Проверки охватывают границы календаря, первые входы в этапы, изоляцию источника, ссылки и авторизацию. Сырые CRM-тексты и рабочие ключи в Git не добавляются.
