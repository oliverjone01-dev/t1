# SETUP - GEO-monster

Единственный ручной шаг владельца - секреты. Всё остальное собирается и деплоится само.

## Адрес

После мерджа в `main`: `https://<username>.github.io/t1/seo/`
Пароль по умолчанию: `genmonster2026` (смени секретом, шаг 2). Это защита от случайных
глаз, не криптография - подробнее в README.

## Шаг 1. Четыре секрета

Repo → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Что это | Где взять |
|---|---|---|
| `KEYSO_TOKEN` | REST API ключ keys.so | Кабинет keys.so → «Данные и подписка» → «Активировать REST API». **Уже добавлен владельцем 10.07.2026** |
| `YM_TOKEN` | OAuth-токен Яндекс.Метрики | oauth.yandex.ru: создать приложение с доступом к Метрике → получить debug-токен по ссылке `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>` |
| `YD_TOKEN` | OAuth-токен Яндекс.Директа | Так же, приложение с доступом к Директу. Если кабинет агентский - добавь ещё секрет `YD_LOGIN` (логин кабинета) |
| `HUB_PASS` | Пароль входа в хаб | Придумай свой. При деплое хэш подменится автоматически |

Плюс заполни счётчики Метрики в `config/projects.json` (`metrika_counter` вместо
PLACEHOLDER) - номер счётчика виден в кабинете Метрики, это не секрет.

## Шаг 2. Запуск сбора данных

Actions → «GEO-monster harvest» → Run workflow. Дальше он ходит сам каждую ночь
(03:00 МСК). Что делает: keys.so (видимость, ключи, конкуренты) + Метрика (трафик,
фразы, страницы) + Директ (расход, запросы) → JSON в `gg-seo-geo-monster/data/` →
автопередеплой сайта.

Без секретов сайт полностью рабочий на DEMO-данных (жёлтые бейджи DEMO на виджетах).

## Дисциплина лимитов keys.so

Тариф Профессиональный: 3000 доменов/фраз в сутки. Harvest: кэш 24 часа (не
перезапрашивает собранное сегодня), счётчик расхода в `data/meta.json`, автостоп на
80% лимита.

## ВАЖНО: публичность данных (прочитай до включения секретов)

Репозиторий и GitHub Pages **публичны**. Пароль хаба закрывает только интерфейс:
файлы `data/*.json` читаются по прямому URL любым, кто знает адрес, и лежат в
истории git. После включения harvest туда попадут: видимость/ключи по keys.so,
агрегаты трафика Метрики и **расход Директа** (суммы за 30 дней, без персональных
данных - гард в workflow это проверяет).

Если публичность SEO-агрегатов и расхода рекламы неприемлема - варианты до запуска:
сделать репозиторий приватным (Pages останется работать), или отключить сбор Директа
(не добавлять `YD_TOKEN`). Решение за владельцем.

## Без API-тарифа keys.so

Модуль «Семантика» принимает CSV-выгрузки keys.so (экспорт «фразы домена»):
кнопка импорта прямо в модуле. Хаб полноценен и без API.
