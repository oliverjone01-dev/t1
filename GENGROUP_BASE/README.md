## Зачем Markdown

- **Git** - версионирование, diff между правками, история изменений
- **Вики / Confluence / Notion** - прямой импорт без потери структуры
- **AI / RAG** - чистый текст для индексации, чанкинга, эмбеддингов
- **Чат-боты** - база знаний для AI-ассистента группы
- **Лёгкость** - открывается в любом редакторе, читается без приложений
