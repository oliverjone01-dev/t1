# TURBIUM - визуал анимации первого экрана

Отдельный проект в общем монорепозитории. Внешний клиент, не бренд GENGROUP:
бренд-токены холдинга сюда не переносятся. Из корня берём дисциплину: anti-slop,
запрет em dash, ФЕНИКС (Step 12.5) перед сдачей клиенту.

TURBIUM - сервис для компаний на Битрикс24/amoCRM: связывает обращения, сделки и
оплаты и показывает, где теряются заказы. Задача проекта - образ 3D-сцены первого
экрана сайта вместо забракованной версии v5.2.

## Структура
| Файл | Что внутри |
|---|---|
| `brief.md` | Что известно, что забраковано, что открыто |
| `prompts/method.md` | Сюжет из 6 состояний, цвет как смысл, три направления, порядок генерации |
| `prompts/storyboard.json` | Источник промтов: палитра, запреты, 3 направления × 6 кадров + движение |
| `prompts/storyboards.md` | Готовые промты для копирования в ChatGPT (собраны из JSON) |
| `scripts/generate.py` | Собирает промты, пишет `storyboards.md`, генерирует через API |
| `out/` | Результаты генерации (не коммитятся) |

## Команды
```bash
python3 turbium/scripts/generate.py --md turbium/prompts/storyboards.md   # пересобрать промты
python3 turbium/scripts/generate.py --kind sheet --dry-run                # 3 листа-раскадровки
OPENAI_API_KEY=... python3 turbium/scripts/generate.py --kind sheet       # сгенерировать листы
OPENAI_API_KEY=... python3 turbium/scripts/generate.py --direction c-swarm --kind frames --chain
```
Модель: `gpt-image-2`, меняется через `OPENAI_IMAGE_MODEL` или `--model`.
