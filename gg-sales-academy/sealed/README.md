# Кабинеты и сводка штаба, запечатанные

Здесь лежат готовые к публикации файлы контуров 2 и 3: десять личных кабинетов
менеджеров и сводка отдела для РОПа и Ивана. Каждый файл это гейт плюс
зашифрованный payload: PBKDF2-HMAC-SHA256 на 600 000 итераций, соль своя на файл,
AES-256-GCM. Без пароля в файле нет читаемого текста, включая просмотр исходника.

Собирает `.claude/skills/kostya-ai/scripts/build-platform.mjs`. Пароли в git не
попадают: они лежат в `PASSWORDS.local.json` рядом с папкой сборки и у Ивана.

`deploy-pages.yml` раскладывает эту папку в `/academy/`. Имя файла человека не
называет: `k-6db68255a4.html` вместо `lakomova-tatyana.html`. Список «кто под каким
адресом» существует внутри `rop-summary.html`, то есть только под паролем сводки.

## Принятый риск

Решение Ивана от 08.08.2026, принято после того, как цена была названа и повторена.

Пароль кабинетов собирается из словаря на 24 слова: три слова плюс число от 100 до
999. Это 12 441 600 вариантов, 23,6 бита. Словарь лежит открытым текстом в
`build-platform.mjs` в этом же публичном репозитории, поэтому подбор идёт по
известному алфавиту и известному формату.

Замер: PBKDF2 на 600 000 итераций даёт 3,6 кандидата в секунду на одном ядре,
полный перебор одним ядром 40 суток. На одной игровой видеокарте это порядка
10 000 кандидатов в секунду, то есть около 20 минут (оценка по публичным
бенчмаркам hashcat, своего замера на GPU нет).

Следствие, записанное здесь, чтобы его не пришлось вспоминать: имена сотрудников,
цитаты клиентской переписки и суммы сделок в этих файлах считаются вскрываемыми.
Опубликованный файл нельзя отозвать: он уходит в кэш поисковиков и в архивы.

Длиннее пароль этого не чинит. Чтобы получить 60 бит на словаре из 24 слов, нужно
одиннадцать слов, а пароль обязан диктоваться по телефону. Публичная статика и
диктуемый пароль несовместимы по арифметике.

Потолок схемы, если решение когда-нибудь пересмотрят: HTTP Basic Auth на хостинге
под контролем холдинга, логин на человека, отзыв доступа и журнал открытий. Шесть
строк конфига nginx, без бэкенда и без базы.

## Единый пароль портала

Решение Ивана от 09.08.2026: пароль один на кабинеты, сводку и библиотеку,
введённый один раз, он запоминается на вкладку (sessionStorage) и открывает
остальные страницы без повторного ввода.

Цена, названная до принятия: с единым паролем любой сотрудник отдела открывает
сводку штаба и кабинет коллеги. Разделение по людям с этого момента держится на
дисциплине раздачи ссылок, а не на паролях. Прежняя модель «у сводки отдельный
пароль» отменена этим решением.

## Пересборка

```bash
node .claude/skills/kostya-ai/scripts/build-platform.mjs <папка-страниц> gg-sales-academy/sealed --shared
```

Пересборка не меняет уже выданный пароль: файл паролей читается перед генерацией.
Сборка падает, если plaintext просочился мимо шифрования, это остановка, а не
предупреждение.
