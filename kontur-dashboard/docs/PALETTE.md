# Палитра

Проверена скриптом `tools/validate_palette.mjs` из скилла dataviz. Не на глаз:
цветовая часть вычислима, поэтому она вычислена.

## Поверхности

| Роль | Светлая | Тёмная |
|---|---|---|
| Фон страницы | `#F4F6FA` | `#0A0C0E` |
| Карточка | `#FFFFFF` | `#101317` |
| Поднятый слой | `#F4F6FA` | `#161A1F` |
| Граница | `#E7EAF0` | `#232830` |
| Заголовок | `#2A3547` | `#E7EAEF` |
| Текст | `#5A6A85` | `#949BA6` |
| Приглушённый | `#8B94A5` | `#697180` |

Тёмная тема графитовая: цветность поверхностей 0,005-0,025 по OKLCH, светлота
фона 0,153. Холодный оттенок оставлен как намёк, а не как синева.

Контраст на карточке `#101317`: заголовок 15,44 к 1, текст 6,65 к 1,
приглушённый 3,79 к 1.

## Категориальные цвета графиков

Фиксированный порядок слотов, никогда по кругу: **пурпурный, бирюзовый, синий,
янтарный, голубой**.

| Слот | Светлая | Тёмная |
|---|---|---|
| 1 | `#7B3BC4` | `#8A5FE9` |
| 2 | `#00806A` | `#00AD81` |
| 3 | `#3561C9` | `#5D8AFF` |
| 4 | `#A87400` | `#CE7F00` |
| 5 | `#0F7CB8` | `#009EEC` |

Обе прошли все пять проверок без послаблений: светлотная полоса, порог цветности,
различимость соседних пар при дальтонизме, порог для обычного зрения, контраст
к поверхности не ниже 3 к 1.

Порядок слотов подобран так, чтобы синий и голубой не оказались соседними: их
пара проваливает порог обычного зрения. Проверена и круговая смежность, чтобы
порядок годился для пончиков, где первый сектор соседствует с последним.

## Последовательная шкала

Один тон, светлее к темнее. Для тепловых карт и всего, что кодирует величину.

- светлая: `#96B2EB`, `#6F93E0`, `#4A71CB`, `#2E52AB`, `#1C3D82`
- тёмная: `#33507F`, `#3E6BC0`, `#5081E4`, `#6E96FF`, `#A6C0FF`

## Расходящаяся пара

Тёплый и холодный полюс плюс нейтральная середина.

- тёмная: `#C57E14` против `#5D8AFF`, середина `#64748B`

## Запрещено

- Пара `#5D87FF` и `#49BEFF` соседними сериями. При обычном зрении ΔE 14,4 при
  пороге 15, при тританопии 5,2. Проверяется сторожем.
- Любой цвет в графиках, которого нет в этом файле. Проверяется сторожем.
- Раскраска номинальных категорий по величине: длина полосы уже несёт величину,
  цвет тратится впустую и проваливает проверки по построению.
- Две оси Y на одном графике.

## Как перепроверить

```
node tools/validate_palette.mjs "#8A5FE9,#00AD81,#5D8AFF,#CE7F00,#009EEC" --mode dark --surface "#101317"
node tools/validate_palette.mjs "#7B3BC4,#00806A,#3561C9,#A87400,#0F7CB8" --mode light --surface "#FFFFFF"
```
