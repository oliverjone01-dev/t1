# Channel-Specific Content Rules

## Telegram
- Max 4096 символов (оптимально 500-1500)
- Первые 2 строки = hook (видны в превью канала, решают - откроют ли)
- Форматирование: **bold**, _italic_, `code`, [ссылки](url) - HTML-теги
- Нет H1-H6 заголовков, нет markdown headers
- Inline-кнопки через бот (SpiderBot)
- CTA: ссылка на бот, сайт или форму
- Emoji: допустимо 1-2 штуки, не в каждом абзаце
- Визуал: 1 фото или карусель (до 10 фото)
- Лучшее время: Пн-Пт 10:00-12:00, 18:00-20:00 MSK
- Антипаттерн: стена текста без абзацев, emoji-буллеты

## VK (ВКонтакте)
- Max 15 000 символов (оптимально 1000-3000)
- Карусели (до 10 фото с описаниями)
- Кнопки-действия (Позвонить, Написать, Перейти)
- Хэштеги: 3-5 штук, в конце поста
- Формат хэштегов: #GENGLASS #лофтмебель #стеклометалл #перегородки #МоsквА
- Визуал: фото производства, готовых проектов, process shots
- Репосты в тематические сообщества (дизайн интерьера, лофт)
- Антипаттерн: текст без визуала, пост-простыня, кликбейт

## Яндекс.Дзен
- Длина: 500-2000 слов (длинные статьи индексируются лучше)
- SEO-заголовок: содержит ключевой запрос, без кликбейта
- Структура: вступление (2-3 предложения) -> основная часть с подзаголовками -> заключение с CTA
- Фото: минимум 3 на статью, подписи под каждым
- Антипаттерн: копипаст с сайта (Дзен штрафует за дубли), рекламный тон
- Лучший контент: «Как выбрать», «Ошибки при», «Разбор проекта», «Сравнение»

## Email (SendPulse / Unisender)
- Тема: до 50 символов, без КАПСА, без «!!!»
- Прехедер: 80-100 символов, дополняет тему
- Тело: 200-400 слов максимум для B2C, до 600 для B2B
- CTA: одна главная кнопка, один запасной текстовый линк
- Визуал: 1-3 фото, не больше (вес письма <100KB)
- Персонализация: имя в теме или первом предложении
- Антипаттерн: письмо-лонгрид, 5 разных CTA, нет unsubscribe

## OZON / Wildberries (карточки товаров)
- Заголовок: ключевой запрос + бренд + характеристика (до 120 символов)
- Описание: 1000-2000 символов, структурировано абзацами
- Буллеты: 5-7 ключевых характеристик с цифрами
- Rich-контент (OZON): баннеры с текстом, сравнительные таблицы
- Фото: минимум 7, белый фон + интерьерные + детали + размеры
- Инфографика: размеры, материалы, комплектация на фото
- Антипаттерн: копипаст описания с сайта, фото без инфографики
- Ответственный: Наташа Скриптун
