## Известные слабые места (для аудитора)
- Наша доставленная выручка по дате доставки выше revAll Маркета на 5-19% по месяцам; причина не разобрана, ДРР блока 5 из-за этого выше нашего на 1 п.п. за квартал.
- Ставка буста по SKU восстановлена из списаний по доставленным заказам, а не из кабинета.
- Маржа 2.4 взята из разноски страницы «Деньги» по дате проводки; буст деньгами и «Скидка за лояльность» из реестра; деньги вне SKU по акту; инварианты разноски проверены там, здесь только суммирование.
- Правило оплаты буста деньгами или баллами из данных не выводится (З7); пока ответа поддержки нет, денежный эффект П5 - широкий диапазон.
- Контроля внутри модели KONUX нет: соседи 5-1 изменились сами (3-3 показы ×5,4 при 0 единиц, 1-3 единицы 10 -> 0); ставки соседей из кабинета нет.

- Воронка только за 07.09-12.10, заказы за июль-сентябрь: окна разные, сопоставление качественное.
- Эффект П2 опирается на допущение, что CTR варианта определяется карточкой; альтернатива (объединённая карточка) не проверена.
