04Анти-таргеты: что сознательно не берём

  • «Стекло для перегородок» / «стекла для перегородок» (ivegroup поз.1 7 117, peregorodki-glass поз.8 7 109) - B2B-интент «купить материал», не «купить готовую перегородку». GENGLASS продаёт готовые изделия, не сырьё. Не берём без отдельного решения о выходе в B2B-поставку стекла.
  • Голое «перегородка» (union.ru) - dr=35 у union против 17 у нас, бюджет ~1.1 млн ₽/мес ГИПОТЕЗА. Прямая атака на это слово - не Pareto-ход, а трата ресурса без реалистичного срока (Protocol 9: бюджет на чистой гипотезе догнать за один цикл - блок). Строим кластер вокруг него через Т1, не штурмуем само слово.
  • DIY-контент кластер kelman-stroi («как сделать дверь книжку своими руками», «мягкие панели своими руками») - аудитория не покупает готовое изделие, а делает сама. Не наш клиент, не наш контент-формат.
  • Дверная семантика alfaporta/union («двери со стеклом», «межкомнатные раздвижные двери», ws в десятки тысяч) - не наш товар (GENGLASS не производит межкомнатные двери), даже при огромном объёме показов.
  • Остекление веранд/фасадов/беседок (glasstroy) - строительная услуга, не мебельное изделие. Смотрим только на пересечение по T2-кластеру, остальной каталог glasstroy - не наша ниша.

09Глоссарий

  • it10 / it3 / it1 - число ключевых фраз домена в топ-10 / топ-3 / топ-1 выдачи Яндекса по данным keys.so.
  • vis (видимость) - внутренняя шкала keys.so, оценивающая совокупный вес позиций домена; не конвертируется в рубли и не сопоставима напрямую между доменами разного масштаба каталога.
  • dr - показатель авторитетности домена по шкале keys.so (аналог domain rating), выше - сильнее ссылочный/ трастовый профиль.
  • ws / wsk - частотность ключевой фразы в месяц (Wordstat-based) и её взвешенная версия с поправкой на конкурентные слова в запросе.
  • adkeyscnt / adscnt - число рекламных ключевых фраз и уникальных текстов объявлений у домена.
  • adcost.average - оценка keys.so среднемесячного рекламного бюджета; не факт кабинета, проверено расхождением в 8 раз на нашем собственном домене (см. §08).
  • aiAnswersCnt - число тестовых ответов ИИ (используемых keys.so эталонов), где встретился домен; предвестник цитируемости, не итоговый Citation Rate.
  • common_ad_keywords / ad_competitors - число рекламных фраз, по которым домен конкурента совпадает с активными ad-фразами genglass.ru - прямой признак столкновения в аукционе, а не рыночная оценка.
  • T-код - номер задачи из plan-genglass.html (Т1-Т14): тип страницы, точный урл, целевые запросы, владельцы, мера успеха.
