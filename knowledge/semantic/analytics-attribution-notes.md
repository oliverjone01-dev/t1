# Атрибуция лидов GENGLASS: постоянные факты (для любой аналитики)

Обновлено: 2026-07-16, источник - Дмитрий (владелец кабинета Директа).

1. **Царь-цель**: Метрика 487033158 «CRM | Все лиды» (плюс 487033859 «Качественные»). Механика: лид попадает в CRM → автовыгрузка в Google Sheets по API → проброс в Метрику по client_id как ОФЛАЙН-конверсия.

2. **СЛЕПАЯ ЗОНА: онлайн-чат = Битрикс24 Открытая линия, канал MAX.** Подтверждено 2026-07-16. Корень: MAX - ВНЕШНИЙ мессенджер, клиент уходит с сайта в приложение MAX, где браузерной сессии и Метрика-client_id УЖЕ НЕТ. Открытая линия создаёт лид в CRM, но у него нет ни client_id, ни yclid → офлайн-выгрузка не матчится с визитом → лид не доходит до царь-цели 487033158. Это тот же класс проблемы, что WhatsApp/Telegram-каналы. Следствия:
   - Все CPL по цели 487033158 ЗАВЫШЕНЫ (реальных лидов больше).
   - Сравнение каналов/кампаний искажается, если доля MAX-обращений в них разная (важно для эксперимента Поиск vs ТГ - вердикт 24.07 может быть смещён).
   - Оптимизация Директа по этой цели недоучитывает messenger-конверсии по кампаниям/ключам.

3. **Путь фикса (2 уровня, независимы):**
   - **Быстро (client-side, для оптимизации Директа):** JS-цель Метрики на КЛИК по кнопке «написать в MAX» на сайте - `ym(104369223,'reachGoal','max_click')`. Клик происходит НА сайте, client_id родной. Директ сразу видит messenger-интент по кампаниям/ключам. Минус - это клик, не подтверждённая заявка, поэтому ОТДЕЛЬНАЯ цель, не мешать с 487033158.
   - **Правильно (сквозная атрибуция через deep-link):** при клике по кнопке MAX снять из URL посадочной `yclid` (и/или Метрика client_id) и вшить в диплинк как start-параметр диалога MAX → Открытая линия Битрикс сохраняет его в карточку лида → офлайн-выгрузка по **yclid** матчится с точным кликом Директа (yclid надёжнее client_id для Директа). ВЕРИФИЦИРОВАТЬ: поддерживает ли коннектор MAX в Битрикс24 start-параметры диалога (у Telegram-коннектора есть; для MAX - молодой канал, проверить в настройках Открытой линии). Если нет - остаётся уровень 1 (JS-цель на клик) как сигнал для Директа.
   - Битрикс24 умеет отдавать офлайн-конверсии в Метрику/Директ нативно (приложение/API); ключ матчинга - yclid или ym client_id. Весь вопрос в том, чтобы этот ключ ДОШЁЛ до карточки лида из MAX.

4. **Квантификация слепой зоны:** в Битрикс24 посчитать долю лидов с источником «Открытая линия / MAX» за период vs всего → процент недоучёта. До закрытия - все «видимые» CPL держать с пометкой «реальный ниже на долю MAX».

5. Кабинет Директа e-20085264: разметка utm_source=yandex. Источник utm_source=abdm - P0 (не кабинет).
