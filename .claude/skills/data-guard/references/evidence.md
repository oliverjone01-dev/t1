# Доказательства для заявлений

Закрывает К5, К10, К11. Идея взята у obra/superpowers (verification-before-completion): **никаких заявлений о готовности без свежего доказательства**. Пять шагов перед любым «готово»: определить, что доказывает утверждение, запустить проверку, прочитать вывод целиком, сверить с утверждением, только потом заявить.

## Утверждение -> доказательство

| Утверждение | Требуемое доказательство | Чего недостаточно |
|---|---|---|
| «Сошлось», «сверено», «совпадает» | Две цифры, два источника разных семейств (банк / документы / API / кабинет), разница и её причина | Совпадение с тем же файлом или API против кабинета; «примерно» |
| «Расхождения нет» | Построчная сверка по ключу: число строк, совпавших и нет | Совпадение итога |
| «Исправлено» | Тест или проверка, которые падали до правки и проходят после; перечислены все места, где живёт логика | «Пересобрал, выглядит нормально» |
| «API не отдаёт», «данных нет», «такого отчёта нет» | Запрос, ответ, дата проверки, ссылка на спеку | Одна неудачная попытка, догадка по названию |
| «Нет намеренно», «так задумано» | Запись в спеке или решении заказчика | Собственная память о прошлой сессии |
| «Готово к слиянию» | CI зелёный на текущем коммите, `go` ФЕНИКСА после последнего коммита | `go` на предыдущий коммит, «правки мелкие» |
| «Эффект X%» | n, окно (выбрано до данных), контроль живой, метод теста | Разница средних на одной неделе |
| «Причина в Y» | Проверка, которая исключает альтернативы | Первая правдоподобная гипотеза |
| «Покрытие 100%» | Доля SKU и оборота с данными, список непокрытого | «Все основные есть» |

## Красные флаги в собственном тексте

Если в черновике ответа есть эти слова, остановись и найди доказательство или замени на «не проверено»:
- «точно», «никогда», «всегда», «гарантированно», «полностью»;
- «должно работать», «скорее всего», «наверное» рядом со словом «готово»;
- «как и раньше», «по построению» без проверки;
- доверие отчёту субагента без проверки его вывода.

## Формат заявления о сверке

```
Сверка <метрика>, <период>:
- <источник A, семейство>: <число>
- <источник B, семейство>: <число>
- Разница: <число> (<процент>). Причина: <список строк или сдвиг дат>.
- Покрытие: <доля>. Непокрыто: <что и почему>.
```
