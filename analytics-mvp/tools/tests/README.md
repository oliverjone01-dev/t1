# tools/tests — исходники для будущей вкладки «Тесты» (OZON)

A/B-тесты по рекламе OZON (ставка/соинвест). Вкладка ещё НЕ построена — макет согласовывается.

- `tests.json` — определения тестов (гипотезы, тест/контроль группы SKU, старт→замер, правила, метрики).
- `tests_campaigns.psv` — лог кампаний по SKU (показы, соинвест, ставка рекоменд→финальная, старт, контроль).
- `ads_campaign_history_2026-06-13.psv` — полный лог действий по рекламным кампаниям кабинета.
- `katya-tests-mock.html` — макет вкладки (открыть в браузере), дизайн НЕ утверждён.
- `gen_tests_mock.py` — генератор макета из данных (`python3 tools/tests/gen_tests_mock.py`, пишет в /tmp).
