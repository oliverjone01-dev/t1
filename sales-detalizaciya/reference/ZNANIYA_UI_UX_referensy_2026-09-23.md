Дата: 23.09.2026
Собрал: СПАРТАК по итогам работы над Контур DS 1.1-1.5
Для кого: Иван и любые будущие проекты GENGROUP: дашборды, админки, трекеры, внутренние инструменты, а с оговорками лендинги и витрины

## 0. Главное в двенадцати пунктах

1. **Шаблонным интерфейс делают не отсутствие эффектов, а их избыток и одинаковость.** Цвет на каждом элементе, рамка на каждом блоке, квадрат с иконкой на каждой плитке, капс на каждой плашке, один радиус на всём.
2. **Витрины компонентов (Kokonut UI, React Bits, Magic UI) сделаны для лендингов.** В рабочий интерфейс годится меньше трети их находок, и брать нужно приём, а не компонент целиком.
3. **Цвет это сигнал, а не декор.** Нейтральная основа, один акцент на выбор и фокус, статусные цвета только для статуса.
4. **Основная кнопка почти чёрная (в тёмной теме почти белая), синий только акцент.** Так делают Linear и Vercel, и так интерфейс сразу выглядит взрослее.
5. **Контраст считают скриптом, а не на глаз.** Мелкий текст не ниже 4,5:1, прозрачность на тексте запрещена, реальный контраст меряют в браузере.
6. **Палитра графиков не равна палитре интерфейса.** Её проверяют на различимость, в том числе при дальтонизме, в обеих темах.
7. **Движение отвечает на действие человека и не живёт само.** Анимируются только transform, opacity, grid-template-rows, clip-path, stroke-dashoffset. Пружин нет, «меньше движения» уважается всегда.
8. **Числа набираются шрифтом интерфейса с табличными цифрами.** Моноширинный шрифт нужен только для кода.
9. **Каждое число отвечает на вопрос «стало лучше или хуже»:** дельта, тренд, источник и дата рядом с самой цифрой.
10. **Пустое, загрузка и нет данных это три разных состояния.** Правдоподобное число вместо прочерка запрещено.
11. **Проверки автоматизированы:** сторож из 23 правил, тест на 31 подмену, живой контраст в браузере, второе мнение детектора Impeccable.
12. **Для лендингов правила мягче**, но и там эффекты должны работать на смысл и иметь запасной вариант при «меньше движения».

## 1. Как отличить продуктовый интерфейс от AI slop

Признаки собраны из статей о признаках AI-дизайна, детектора Impeccable, эталонов (Linear, Stripe, Vercel, PostHog, Raycast) и из собственной диагностики Контура 1.2.

| Признак шаблона | Почему выдаёт | Как сделать правильно |
|---|---|---|
| Тонированный квадрат с иконкой на каждой карточке | главный узнаваемый признак сгенерированного дашборда | подпись сверху, иконка 14 пикселей серым у подписи или без неё |
| Капс-плашка на каждом элементе | кричит, всё одинаково важно | точка и слово для статуса; бейдж строчными 12/500 и только в шапке |
| Всё в карточке с рамкой | нет иерархии | плитки одной панелью с волосяными разделителями, главное главной строкой |
| Один радиус на всём | выдаёт генератор | роли радиусов: поле 6, коробка 12, пункт меню 8 |
| Синяя основная кнопка и сине-серые нейтрали slate | тема по умолчанию Tailwind | нейтрали почти без синевы, кнопка почти чёрная |
| Цветная полоса сбоку у врезки или карточки | признак номер один у Impeccable | тон у значка, фон только у критичного |
| Градиентный квадрат-логотип | подпись шаблона | сплошной знак цветом текста |
| Фиолетово-синий градиент в герое | самый частый AI-лендинг | фон из материала предмета, фото продукта |
| Кремовый фон с засечками и терракотой, чёрный с кислотным акцентом | «дизайнерские» клише генераторов | палитра из мира предмета |
| Inter или Space Grotesk «на всякий случай» | безопасный выбор генератора | шрифт под задачу: для кириллицы и цифр Golos Text, на Apple системный SF |
| Эмодзи как иконки разделов | дешево и неровно | один набор контурных иконок (Lucide) |
| Бегущие рамки, блестящий текст, расшифровка символов | эффект ради эффекта | ничего, или одна микроанимация, отвечающая на действие |
| Счётчик «от нуля» при загрузке | искажает первое впечатление от цифры | число сразу на месте, переход только при обновлении данных |
| «Всё видно сразу»: врезка «как читать экран» | шум | значок «?» с подсказкой |
| Равный вес всех блоков | глазу не за что зацепиться | вердикт главной строкой, число 24-30, остальное тише |
| Нет клавиатурных сценариев | выглядит как макет | палитра команд Cmd+K, подсказки клавиш |

Общее правило: сначала убрать лишнее (цвет, рамки, капс, квадраты), потом добавить то, что есть у зрелых продуктов (палитра команд, подсказки у значения, переход числа, продуманные пустые состояния).

## 3. Референсы подробно

### 3.1 Kokonut UI

[GitHub](https://github.com/kokonut-labs/kokonutui). React, Tailwind, Motion, лицензия MIT, около 51 компонента через shadcn-реестр.

- **Liquid Glass Card.** Техника: SVG-фильтр `feTurbulence` плюс `feDisplacementMap` через `backdrop-filter: url(#id)` и толщина из шести inset-теней. Искажение работает только в Chromium, грузит видеокарту и размывает цифры под собой. **Взять без искажения:** размытие 20 пикселей, насыщенность 160%, фон 86% непрозрачности, верхний блик `inset 0 1px 0`. Только для слоёв поверх контента: подсказка, палитра команд, уведомление, подсказка графика. Карточки с цифрами стеклянными не бывают. Запасной вариант: при `prefers-reduced-transparency` и без поддержки `backdrop-filter` сплошной фон.
- **Smooth Tab.** Плашка выбранной вкладки едет к новой. У них позиция через `getBoundingClientRect` и пружина. **Взять:** плашку двигать через `clip-path: inset(0 R 0 L round r)`, без пружины и без анимации ширины (раскладка не пересчитывается), следить за `aria-pressed` через MutationObserver.
- **Command Button.** Кнопка палитры команд в шапке. Взять идею, без шиммера.
- **AI Input Search.** Анимирует `width:auto`, для интерфейса нельзя.
- Для лендингов компоненты можно брать целиком, но проверить `prefers-reduced-motion`: у витрин его обычно нет.

### 3.2 Magic UI и его MCP

[GitHub](https://github.com/magicuidesign/magicui), [MCP](https://github.com/magicuidesign/mcp). React, Tailwind v4, Motion, MIT.

- **MCP-сервер** даёт агенту три инструмента: список, поиск, получить компонент, и вставляет исходник в проект. Работает только в проекте на React, Tailwind и shadcn с файлом `components.json`. Подключение: `npx @magicuidesign/cli@latest install claude`. Для чистого HTML это каталог рецептов, а не установщик.
- **Number Ticker.** Взять с поправкой: число переходит к новому значению только при обновлении данных, 450 мс, ease-out по кубу, без перелёта. На первом показе число сразу на месте.
- **Magic Card** (подсветка под курсором). Взять приглушённым: радиальный отлив акцента 6-7% под курсором, только мышь (`pointerType === 'mouse'`), только на кликабельном, координаты через CSS-переменные и `requestAnimationFrame`.
- **Animated Circular Progress.** То же, что кольцо на `stroke-dasharray`.
- **Bento Grid.** Взять только формулу слоистой тени; сама «витрина фич» это лендинг.
- **Border Beam, Shine Border.** Бегущий блик спорит с данными. В интерфейсе нет, на лендинге допустим один раз на главной кнопке.
- **Dock.** Анимирует ширину и высоту, нельзя.
- **Blur Fade.** Анимация `filter` дороже и не проверяет «меньше движения».
- Важно: ни один компонент Magic UI не проверяет `prefers-reduced-motion`. Добавлять руками.

### 3.3 React Bits

[GitHub](https://github.com/DavidHDev/react-bits). 200+ компонентов, MIT с Commons Clause: можно использовать в продукте, нельзя перепродавать сами компоненты. Основа: Motion, GSAP, Three.js, OGL.

- **Spotlight Card.** То же, что Magic Card: взять приглушённым до 6-7%.
- **Count Up.** Идея в переходе числа; пружину заменить на ease-out.
- **Animated List.** Взять тайминг: блоки экрана появляются по очереди с шагом 35 мс, всё не дольше 175-200 мс, без ожидания IntersectionObserver (иначе снимок страницы и быстрый читатель видят пустоту).
- **Glass Surface, Shiny Text, Decrypted Text, Click Spark, Tilted Card, Aurora, Silk, Beams.** В рабочем интерфейсе нет: это главные сигналы AI slop, нечитаемый текст, WebGL под таблицами. На лендинге фон вроде Aurora или Silk допустим в герое при условиях из раздела 12.

### 3.4 Anime.js

[animejs.com](https://animejs.com). Версия 4, около 24,5 КБ, MIT, есть на cdnjs и jsdelivr.

- Для рабочих интерфейсов **не нужен**: пружины и привязка к прокрутке там запрещены, а очередь появления, прорисовка линии и переход числа делаются CSS и Web Animations. Прорисовка линии: `pathLength="1"`, `stroke-dasharray:1`, анимация `stroke-dashoffset` от 1 к 0 (то же, что `svg.createDrawable`).
- Для лендингов полезен: таймлайны, сценарии прокрутки, морф SVG. Альтернатива без библиотеки: CSS scroll-driven animations (`animation-timeline: view()`), но проверять поддержку браузеров.

### 3.5 daisyUI

[Темы](https://daisyui.com/docs/themes/), [генератор тем](https://daisyui.com/theme-generator/). Версия 5, переменные в OKLCH.

- **Роли радиусов** `--radius-field`, `--radius-box`, `--radius-selector`: поле заметно мельче коробки. Взято как `--r-field` 6 и `--r-box` 12.
- **`--depth`**: множитель теней и блика. 0 плоско, 1 норма, больше 1 не ставить: тень начинает спорить с данными.
- **`--noise`** (зерно через feTurbulence): на отчёте читается как грязь, не брать.
- **stats**: показатели одной группой с разделителями вместо отдельных карточек. Взято: сетка с `gap:1px` на фоне цвета границы, разделитель верен при любом числе колонок.
- **toast, skeleton, kbd, tabs-box, status-точка, tooltip на `attr()`**: взяты как уведомление, заглушка загрузки, клавиша, плашка сегмента, точка статуса, стеклянная подсказка с фокусом с клавиатуры.
- Модалки и выпадашки на трюке с чекбоксом: не брать, у панели деталей свой контракт с aria, фокусом и адресом.
- Цвета daisyUI: не брать без проверки контраста и цветовой слепоты.

### 3.6 Bklit UI

В запросе он назван «Backlit UI»; реальный проект [Bklit UI](https://bklit.com) ([GitHub](https://github.com/bklit/bklit-ui)). Свой SVG-рендер на visx, 15+ типов графиков, shadcn-реестр.

- Сетка только горизонтальная и тише фона.
- Точки на линии только при наведении; у ряда из трёх и меньше точек маркеры всегда (иначе линии не видно).
- Перекрестие при наведении, подсказка карточкой (у нас стеклом).
- Цвет сетки из токена темы.
- Заливка под линией от 0,4 к 0: только если ось от нуля, иначе заливка преувеличивает изменение.
- Кривая `monotoneX`: сначала не взяли, потому что обычное сглаживание рисует провалы, которых нет. В 1.5 плавные линии разрешены **только monotone** (`monotoneCubic` в ApexCharts): такая кривая не выходит за соседние точки.
- Отдельные примитивы загрузки и пустого состояния: взяты.

### 3.7 Rive

[Цены](https://rive.app/pricing), [CLI](https://rive.app/docs/cli/overview), [RML](https://rive.app/docs/runtimes/advanced-topic/rml), [параметры веб-рантайма](https://rive.app/docs/runtimes/web/rive-parameters), [data binding](https://rive.app/docs/runtimes/web/data-binding).

- **Лицензия.** Рантаймы под MIT. Тарифы на сентябрь 2026: Free без экспорта `.riv` для продакшна, Cadet 9 долларов за место в месяц (до 3 мест) с экспортом, Voyager 32 доллара, Enterprise 120 долларов при выручке от 10 млн долларов.
- **Главное открытие 1.4:** `.riv` можно собрать без визуального редактора. Официальный **Rive CLI** (Linux x64, macOS Apple Silicon, Windows) собирает сцену из текстового XML-формата **RML**: `rive create`, `rive <папка> --verify`, `--once` (неподписанный `.riv`), `--screenshot`, `rive schema <Тип>`, `rive docs <тема>`. Вход в аккаунт нужен только для `--publish`, `--rev` и `push`. Установка: `curl -fsSL https://releases.rive.app/cli/install.sh | sh` (установщик проверяет SHA-256).
- **Ограничения CLI:** скрипты Luau в неподписанной сборке веб-рантайм отвергает, поэтому анимации без скриптов. Официальный выпуск без водяного знака идёт через тариф Cadet (проект привязывается к файлу в аккаунте). В песочнице без видеокарты `--screenshot` рисует пустые кадры: кадры проверять в веб-рантайме через Playwright, шагая по 1/60 секунды.
- **Веб-рантайм.** Пакет `@rive-app/canvas-single` содержит WASM внутри JS (около 2,8 МБ), не догружает `.wasm` по сети. На cdnjs Rive нет, только jsdelivr: `https://cdn.jsdelivr.net/npm/@rive-app/canvas-single@2.43.0/rive.min.js`. Остальные пакеты (`canvas`, `canvas-lite`, `webgl2`) тянут `.wasm` отдельным запросом.
- **Загрузка без сети:** `.riv` в base64 внутри страницы, параметр `buffer: ArrayBuffer`. Параметр `stateMachine` в единственном числе (множественное устарело). В `onLoad`: `resizeDrawingSurfaceToCanvas()`, затем тема и состояние. Пауза вне экрана через IntersectionObserver и `play()/pause()`, освобождение через `cleanup()`.
- **Data binding (View Models)** с рантайма 2.26.6: `autoBind: true`, `r.viewModelInstance.number('state').value = 1`, `.color('accent').argb(255, r, g, b)`, `.trigger('play').trigger()`. Тему менять привязанными цветами, а не вторым артбордом.
- **Доступность:** семантика Rive в раннем доступе. Холст прятать от диктора, смысл дублировать текстом, «меньше движения» проверять самим.
- **Как применять:** 3-6 микроанимаций поверх родных SVG-версий (синхронизация, подтверждение, пустое состояние). Если рантайм не загрузился, человек ничего не замечает. На лендингах Rive хорош для интерактивных иллюстраций и конфигураторов.

### 3.8 Эталоны: Linear, Vercel Geist, Stripe, PostHog, Raycast, Refactoring UI

[Linear: редизайн](https://linear.app/now/how-we-redesigned-the-linear-ui), [Vercel Geist](https://vercel.com/geist/materials), [разбор дашборда Stripe](https://www.925studios.co/blog/stripe-dashboard-design-breakdown), [признаки AI-дизайна](https://www.925studios.co/blog/ai-slop-design-tells), [Spot the Slop](https://world.hey.com/kostac/spot-the-slop-a-ui-designer-s-guide-to-fixing-ai-defaults-4c448c9c).

- **Stripe:** показатели одной строкой с разделителями, подпись сверху, крупное число, дельта, спарклайн; цвет только как сигнал.
- **Vercel Geist и Linear:** нейтрали без синевы, почти чёрная основная кнопка, роли радиусов, заголовки полужирным 600 с отрицательной разрядкой (-0,015 em, число -0,025 em), палитра команд с подсказками клавиш, подложка выбранного пункта меню переезжает.
- **PostHog:** статусы точкой в таблицах, нейтральные врезки.
- **Raycast:** палитра команд как главный способ навигации.
- **Refactoring UI:** иерархия через вес и цвет текста, а не через размер и рамки; «серый текст на цветном фоне» не работает.

### 3.9 Impeccable, whocanuse, Lucide, shadcn/ui, utopia.fyi, easings.net

- **Impeccable** (`npx impeccable detect страница.html`): 61 правило. Из него в сторож перенесены правила LAYOUTANIM (анимация ширины и высоты), BOUNCE (кривая с перелётом), FONTFLOOR (текст мельче 11), FAINTTEXT (самая бледная ступень на тексте), SIDESTRIPE (цветная полоса сбоку). Известные ложные срабатывания: контраст внутри вложенной темы (не видит фон `[data-theme]`) и 11 пикселей в служебных строках (его порог 12).
- **whocanuse:** идея мерить реальный контраст для разных типов зрения. У нас это автомат `contrast_live.mjs`: каждый текст на реальном фоне в обеих темах на 1280 и 390.
- **Lucide** ([lucide.dev](https://lucide.dev), ISC): имена иконок знают агенты, поэтому набор понимает `trending-up` и прочие. Недостающую иконку брать из Lucide в её сетке 24, штрих пересчитывать. Не смешивать наборы.
- **shadcn/ui** ([ui.shadcn.com](https://ui.shadcn.com)): мост имён. Акцент называть `--primary`, а не `--accent`: у shadcn `--accent` значит фон при наведении. В Tailwind v4 утилиты `bg-primary` вести на почти чёрную основную кнопку, синий отдельной утилитой.
- **utopia.fyi:** плавный размер через `clamp()`. В плотном интерфейсе плавным делать только одно значение (число плитки: 24 на телефоне, 30 от 1100 пикселей), остальное фиксированным.
- **easings.net:** три кривые: вход `cubic-bezier(.2,.8,.2,1)`, выход `cubic-bezier(.4,0,1,1)`, остальное `cubic-bezier(.4,0,.2,1)`. Параметр вне 0..1 это пружина, в интерфейсе запрещена.

### 3.10 View Transitions API

[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition), [Chrome](https://developer.chrome.com/docs/web-platform/view-transitions/same-document), [web.dev: Baseline](https://web.dev/blog/same-document-view-transitions-are-now-baseline-newly-available).

- Поддержка на сентябрь 2026: Chrome и Edge 111+, Safari 18+, Firefox 144+ (Firefox ESR 140 без поддержки). Типы переходов (`types`, `:active-view-transition-type()`): Chrome 125+, Safari 18.2+, Firefox 147+. Baseline с 14.10.2025.
- Шапку и меню исключать: `:root { view-transition-name: none }`, у шапки своё имя, иначе снимок экрана проезжает поверх неё.
- Оверлей перехода ловит клики: `::view-transition { pointer-events: none }`.
- Повторный вызов доматывает предыдущий переход; ошибки на `ready` гасить (`catch`), они штатные: скрытая вкладка, одинаковые имена.
- `::view-transition-old` это статичная картинка, `::view-transition-new` живой.
- При смене темы белая вспышка бывает от `mix-blend-mode: plus-lighter`, если у старого и нового снимка разные кривые; одинаковая длительность и кривая дают точный кросс-фейд.
- Подложку активного пункта меню через переход не двигать: она окажется поверх текста пунктов. Двигать обычным `transform` (FLIP), размер ставить сразу.
- В headless-браузере без видеокарты колбэк обновления запускается через 100-130 мс, в тестах ждать окончания перехода.

## 6. Типографика и шрифты

- **SF Pro** нельзя вкладывать файлом: лицензия Apple разрешает его только для макетов. Берётся системным стеком `-apple-system, BlinkMacSystemFont`: на Mac и iPhone браузер сам включает SF Display и SF Text.
- **Golos Text** (Google Fonts) для всех остальных: гротеск с хорошей кириллицей и табличными цифрами.
- **DM Sans** не брать для чисел: в нём нет табличных цифр, столбцы не выравниваются.
- **Моноширинный** для чисел не брать: он растаскивает «8,3%» и «Расход, ₽». Цифры в столбик через `font-variant-numeric: tabular-nums` того же шрифта.
- **Inter и Space Grotesk** генераторы берут «на всякий случай». Это сразу считывается как шаблон.
- Шкала из восьми ролей вместо девяти близких размеров: 11, 12, 12,5, 13, 14, 16, 22, число 24-30.
- Разрядка: заголовки -0,015 em, крупное число -0,025 em, цифры в таблицах -0,01 em, короткий капс +0,04 em.
- Полужирный 600 для заголовков и чисел; 700 выглядит тяжело в плотном интерфейсе.
- `text-wrap: balance` у заголовков.

## 7. Цвет и темы

- **Текст четырьмя ступенями:** сильный, основной, приглушённый, бледный. Бледный не для чтения: только выключенное и значки-указатели.
- **Статусные цвета зарезервированы** (успех, внимание, серьёзно, критично, нейтрально, инфо) и никогда не становятся цветом серии графика. Бейдж проверять на двух слоях: на карточке и на поднятом слое (строка при наведении).
- **Нейтрали почти без синевы:** светлая тема текст #16191E на фоне #F6F7F9; сине-серый slate читается как тема по умолчанию.
- **Основная кнопка и акцент разные роли:** кнопка `--action` почти чёрная, акцент `--primary` синий для выбора, фокуса и ссылки.
- **Три состояния темы:** явная тёмная, явная светлая, как в системе. Хост (например, просмотрщик артефактов Claude) может сам поставить `data-theme`: страница не должна его перебивать. Тема ставится и на контейнер, вложенный блок заново берёт цвет текста.
- **Тёмная тема не инверсия:** свои значения каждой ступени, свои серии графиков (светлее), тень заменена верхним бликом.
- Поддержать системные настройки «больше контраста», «меньше прозрачности», «меньше движения» и высокую контрастность Windows (`forced-colors`).
- Готовые палитры серий из цветов Контура, прошедшие валидатор в обеих темах: фиолетовый первым (#7B3BC4, #00806A, #3561C9, #A87400, #0F7CB8) и синий первым (#3561C9, #00806A, #7B3BC4, #A87400, #0F7CB8). Порядки с янтарным или бирюзовым первым не проходят. Палитра по умолчанию из скилла dataviz на белой карточке Контура не проходит контраст у двух цветов.

## 8. Движение

- Разрешено: `transform`, `opacity`, `grid-template-rows` (аккордеон 0fr → 1fr), `clip-path`, `stroke-dashoffset`. Запрещено: ширина, высота, отступы, `max-height`: перерасчёт раскладки на каждом кадре.
- Без пружин и перелёта: параметры `cubic-bezier` в пределах 0..1.
- Бесконечная анимация только у вращения индикатора загрузки и мерцания заглушки. Пульсирующие точки и бегущие рамки нет.
- Индикатор загрузки только при настоящей загрузке: изображать работу без работы нельзя.
- «Меньше движения» выключает всё: длительности в ноль, переходы экранов сразу, графики без анимации, Rive не грузится.
- Прокрутку к анимации в интерфейсе не привязывать. Подъём карточки при наведении только в `@media (hover:hover)`, на касании отклик нажатием.
- Всё видно сразу после загрузки: блок может появляться анимацией, но из видимого состояния, а не с `opacity:0` в ожидании наблюдателя.

## 9. Доступность и адаптивность

- Каркас меняется по ширине окна, сетки внутри по ширине своего контейнера (`container-type: inline-size`): один и тот же блок верно ложится в экран, в панель деталей и в половину витрины.
- Дорожки сетки только `minmax(0,1fr)`; строка с прокруткой внутри флекс-колонки получает `min-width:0`. `html{overflow-x:clip}` только страховка.
- Безопасные зоны `env(safe-area-inset-*)`, высота `100dvh`, открытые меню и панели блокируют прокрутку страницы.
- Таблица от четырёх колонок на узком контейнере превращается в карточки «подпись: значение», роли ARIA сохраняют таблицу для диктора.
- Каждый график с таблицей-двойником.
- Подсказка по фокусу с клавиатуры, а не только по мыши. Палитра команд с ролями combobox и listbox.
- Проверка на 360, 390, 768, 1024, 1440 в обеих темах; на iPhone кнопка 44 и поле 16.

## 10. Среды: где что работает

- **Артефакт Claude:** внешние скрипты только с cdnjs.cloudflare.com и cdn.jsdelivr.net/npm, стили только с Google Fonts; fetch к внешним хостам заблокирован, поэтому всё своё внутри страницы. `window.print()` не работает. До `location.hash` доходят только буквы, цифры и `. _ ~ -`, поэтому маршрут через точку. WASM (например, Rive) песочница может запретить: нужен запасной вариант. localStorage у каждого артефакта свой.
- **GitHub Pages и локальный файл:** файлы подключаются ссылками, печать работает. В Chromium страницы, открытые с диска (`file://`), делят одно хранилище localStorage: настройки, сохранённые на одной странице, видны на другой (проверено).
- **Tailwind v4 и shadcn:** мост переменных плюс блок `@theme inline`; проверено компиляцией Tailwind 4.3 в обеих темах, во вложенной тёмной панели и с `hover:bg-primary/90`.
- **Тесты в Playwright:** снимок всей страницы (`fullPage`) искажает липкие элементы, для них снимать окно. Headless без видеокарты замедляет View Transitions, ждать окончания перехода.

## 11. Как проверять

- **Сторож** (`tools/check_ds.py`, 23 правила): контраст токенов, палитра графиков, цвета мимо токенов, прозрачность на тексте, две оси Y, синий рядом с голубым, длинные тире, конверт цифры, анимация раскладки, пружины, пол шрифта, бледный текст, синхронность копий темы и плотности, живой контраст, viewport, подъём на касании, моноширинные цифры, полоса сбоку, капс на бейджах, градиентный знак, бесконечные анимации, цели пальца в компактном режиме, переходы без «меньше движения».
- **Тест сторожа** (`tools/tamper_ds.py`): 31 испорченная версия, каждая обязана быть поймана. Сторож, который всегда зелёный, бесполезен.
- **Живой контраст** (`--live`): каждый текст на реальном фоне, обе темы, 1280 и 390. Ловит то, чего нет в токенах: подложку поверх подложки, подпись на цветной плашке. Проверять и страницы со своими настройками вида.
- **Impeccable:** второе мнение перед сдачей.
- **Попиксельное сравнение** версий: вид по умолчанию не должен меняться без причины.
- **Валидатор палитры** на любую новую палитру графиков в обеих темах.

## 12. Для лендингов, витрин и брендовых материалов

Гайды брендов GENGROUP важнее этого раздела. Эффекты, отвергнутые для рабочих интерфейсов, на маркетинговых страницах допустимы при пяти условиях: работают на смысл (показывают продукт, ведут к действию), один главный эффект на экран, есть запасной вариант при «меньше движения», укладываются в бюджет скорости (страница открывается быстрее 3 секунд), текст поверх них читается с контрастом 4,5:1.

- **Фоны на WebGL** (Aurora, Silk, Beams из React Bits): только в герое, с запасным статичным изображением и паузой вне экрана. Под текстом не использовать.
- **Сценарий прокрутки** (Anime.js v4, GSAP, CSS scroll-driven): для рассказа о продукте, например как собирается перегородка GENGLASS. Не для навигации.
- **Rive:** интерактивные иллюстрации и конфигураторы (выбор профиля, стекла и цвета с живой картинкой), стейт-машины с входами от формы. Для продакшна нужен тариф Cadet или дизайнер с аккаунтом.
- **Border Beam и Shine** из Magic UI: максимум один раз, на главной кнопке.
- **Magic UI MCP:** если лендинг на React, Tailwind и shadcn, компоненты ставятся одной командой агента.
- **Kokonut UI Liquid Glass с искажением:** на фото продукта и декоративных плашках, не на тексте.
- Клише генераторов (фиолетово-синий градиент, кремовый фон с засечками и терракотой, чёрный с кислотным акцентом, эмодзи вместо иконок) не использовать нигде.

## 13. Предпочтения владельца, которые действуют во всех проектах

- Никаких длинных и средних тире ни в текстах, ни в коде, ни в интерфейсе: только дефис.

- На Apple системный SF, у остальных Golos Text.
- Вид уровня мирового SaaS, без признаков AI slop; не ухудшать достигнутый уровень при доработках.
- Ни одна рекламная кампания не запускается и не финансируется без явного подтверждения Ивана.
- Цифры только с источником и датой; гипотезы помечены; правдоподобные числа вместо данных запрещены.

## 14. Чек-лист перед сдачей любого интерфейса

- [ ] Нет квадратов с иконкой на карточках, капса на плашках, полос сбоку, градиентного логотипа
- [ ] Цвет только как сигнал; один акцент; статусные цвета только для статуса
- [ ] Основная кнопка одна на экран; радиусы по ролям
- [ ] Мелкий текст не ниже 4,5:1 в обеих темах, без прозрачности; живой контраст зелёный
- [ ] Числа табличными цифрами шрифта интерфейса; источник и дата у каждого числа
- [ ] Палитра графиков прошла валидатор в обеих темах; двух осей Y нет
- [ ] Анимации только разрешённых свойств, без пружин, с «меньше движения»
- [ ] Пустое, загрузка и нет данных различимы
- [ ] Клавиатура: фокус виден, подсказки по фокусу, палитра команд
- [ ] 360, 390, 768, 1024, 1440 в обеих темах: прокрутки вбок нет, кнопки 44, поля 16
- [ ] Ни одного длинного тире
