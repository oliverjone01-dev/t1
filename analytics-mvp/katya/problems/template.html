Источники, покрытие и правила расчёта

Отмены - текущий статус когорты по дате создания, сумма товаров до вычета возвратов. Один номер отправления считается один раз. Возвраты - движение возвратных товаров по дате возврата, не выплата денег покупателю. Для rFBS изменения плана фиксируются между снимками ведомости, по дате обнаружения в Москве. Опоздание - разница фактической и текущей плановой даты; отмены и возвраты исключены. Текущая ведомость не доказывает обещанный покупателю срок Ozon. История начинается с первого сохранённого снимка.

Минус доставки = стоимость отправки - оплата покупателя по дате отправки из существующей ведомости. Неизвестная оплата не принимается за ноль. Убыточные отправки не перекрываются прибыльными. Таблица логистов не меняется.

Итоги разных блоков не складываются в общий «убыток»: один заказ может иметь несколько проблем. Финансовая сверка с независимым актом или банковской выпиской не выполнена.
