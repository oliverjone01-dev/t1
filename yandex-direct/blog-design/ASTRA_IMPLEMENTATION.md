# Как макет ложится на WordPress + Astra

Макет: `article-template.html`. Кнопка «Разметка Astra» в правом нижнем углу
подсвечивает блоки и подписывает, во что каждый превращается в WordPress.

Принцип: Astra отвечает за каркас, сайдбар и адаптив. Дочерняя тема отвечает
за типографику, линейки и собственные блоки. Ни одного конструктора страниц
(Elementor и подобные) в шаблоне статьи: они ломают типографическую сетку
и добавляют 300-500 КБ на каждую страницу.

---

## 1. Настройки Astra без кода

Внешний вид → Настроить:

| Раздел | Значение | Почему |
|---|---|---|
| Global → Container → Layout | Content Boxed | «полоса» на фоне, как в макете |
| Global → Container → Width | 1180 | совпадает с лендингом |
| Global → Colors | текст `#16181A`, фон сайта `#DCDCD5`, фон контейнера `#E6E6E1`, ссылка `#16181A`, ховер `#27479A` | токены из лендинга |
| Sidebars → Default Layout | No Sidebar | лендинг и служебные страницы без колонки |
| Sidebars → Single Post | Right Sidebar | сайдбар только у статей и рубрик |
| Sidebars → Archive | Right Sidebar | |
| Sidebars → Width | 26% | при контейнере 1180 даёт около 300px, макет рассчитан на 300-312px |
| Blog → Single Post → Structure | снять «Title», «Meta» | шапку статьи рисует свой шаблон, с номером выпуска |
| Blog → Blog Archive → Structure | снять всё лишнее | список выпусков собирает свой шаблон |
| Header Builder → Primary Header | отключить целиком | иначе над мастхедом издания встанет вторая шапка, см. §2 |

Типографику в пикере Astra не трогаем: гарнитуры подключает дочерняя тема (§4).

## 2. Мастхед и отключение штатной шапки

Мастхед издания это и есть шапка сайта. Если оставить включённым Primary Header
у Astra, на странице окажется два хедера подряд.

Надёжнее не полагаться на настройку, а отключить вывод в коде:

```php
// Своя шапка вместо astra_masthead. Снимаем безусловно и выводим мастхед
// тоже безусловно: иначе «Об авторе», «Политика данных», /spasibo/, поиск
// и 404 останутся вообще без шапки и без навигации
add_action( 'init', function () {
    remove_action( 'astra_masthead', 'astra_masthead_primary_template' );
} );

add_action( 'astra_masthead', function () {
    get_template_part( 'template-parts/masthead' );
} );
```

Если мастхед нужен только на блоге, снимать штатную шапку надо тем же
условием, каким выводится свой, а не безусловно:

```php
add_action( 'init', function () {
    if ( ! is_admin() ) {
        add_action( 'template_redirect', function () {
            if ( is_singular( 'post' ) || is_category() || is_home() ) {
                remove_action( 'astra_masthead', 'astra_masthead_primary_template' );
            }
        } );
    }
} );
```

Если версия темы даёт другое имя колбэка, вывести мастхед через
`astra_content_before` и скрыть штатную шапку в Header Builder, но тогда
проверить, что `.ast-primary-header-bar` действительно не рендерится,
а не просто спрятан стилями: скрытый DOM всё равно уедет в разметку.

// Ссылка на канал и счётчик Метрики в одном месте, а не по шаблонам

    wp_enqueue_style(
        'blog-design',

        [ 'astra-child' ],
        filemtime( get_stylesheet_directory() . '/assets/css/blog.css' )
    );
    wp_enqueue_script(
        'blog-design',
        get_stylesheet_directory_uri() . '/assets/js/blog.js',
        [], '1.0', true
    );
    wp_localize_script( 'blog-design', 'BLOG_CFG', [ 'ymId' => BLOG_YM_ID ] );

// Своя виджет-зона: состав колонки фиксирован и не зависит от того,
// что кто-то перетащил в стандартный Main Sidebar
add_action( 'widgets_init', function () {
    register_sidebar( [
        'name'          => 'Колонка блога',
        'id'            => 'blog-sidebar',
        'before_widget' => '<div class="side-block %2$s">',
        'after_widget'  => '</div>',
        'before_title'  => '<div class="side-h">',
        'after_title'   => '</div>',
    ] );
} );

// Мобильная полоса с Telegram
add_action( 'wp_footer', function () {
    if ( ! is_singular( 'post' ) && ! is_category() ) {
        return;
    }
    printf(

Хуки Astra, использованные в примерах: `astra_masthead`, `astra_content_before`,
`astra_entry_content_after`, `astra_sidebars_before`. Перед внедрением сверить
их наличие в установленной версии темы.

## 4. Шрифты

Четыре гарнитуры это много, поэтому только локально и только нужные начертания.

| Гарнитура | Начертания | Где |
|---|---|---|
| Alegreya | 800, 700, 700 italic | заголовки |
| Alegreya Sans | 400, 700 | текст и интерфейс |
| JetBrains Mono | 500 | цифры и метки |
| Caveat | 500, 700 | реплики на полях |

**Пикер Astra не используем.** В бесплатной Astra свою гарнитуру в список
не добавить: для этого нужен плагин Custom Fonts либо Astra Pro. Проще
и легче не задавать шрифты в Customizer вообще, а объявить их в `blog.css`
дочерней темы: правила дочерней темы грузятся после темы и перекрывают её
значения. Настройку `Global → Typography → Load Google Fonts Locally`
включить на случай, если где-то в теме останется вызов Google Fonts.

`@font-face` с подмножеством. Диапазон обязан включать цифры и латиницу:
весь дизайн держится на моноширинных числах, а в тексте встречаются XLSX,
B2B, CRM и Telegram.

```css
/* кириллица + базовая латиница + цифры + типографские кавычки и знаки */
@font-face {
  font-family: 'JetBrains Mono';
  src: url('../fonts/jetbrains-mono-500.woff2') format('woff2');
  font-weight: 500;
  font-display: swap;
  unicode-range: U+0020-007E, U+00A0, U+00AB, U+00BB, U+0401, U+0410-044F,
                 U+0451, U+2010-2015, U+2018-201F, U+2116, U+2212, U+20BD;
}
```

Тот же диапазон для Alegreya, Alegreya Sans и Caveat. Проверять сабсет надо
на реальной странице: если цифры или латинские аббревиатуры визуально
отличаются от соседних символов, диапазон урезан слишком сильно.

Caveat нужен только для реплик на полях. При жёстком бюджете на вес страницы
её можно грузить отложенно: без неё реплика деградирует в наклонный курсив
и страница не разваливается.

## 5. Блоки макета и их источник в WordPress

| Блок макета | Реализация |
|---|---|
| Мастхед издания | `template-parts/masthead.php` через `astra_masthead`, см. §2 |
| Меню рубрик | обычное меню WordPress, класс `topnav`, текущая рубрика получает `.here` |
| Кикер статьи | `template-parts/article-header.php`: рубрика, `issue_number`, дата, время чтения |
| Номер выпуска | поле ACF `issue_number`. Нумерация начинается с №1 от первой публикации, задним числом не проставляется |
| Время чтения | считается по содержимому, формула ниже |
| H1 и лид | заголовок записи и `the_excerpt` |
| Оглавление | собирается в `blog.js` по всем `h2[id]` внутри `.body` |
| Реплика на полях | шорткод `[note]` и `[note warm]` |
| Таблица диагностики | синхронизированный паттерн Gutenberg «Таблица разрывов» |
| Блок самопроверки | синхронизированный паттерн «Проверьте у себя» |
| Врезка Telegram | `template-parts/tg-inline.php`, вставка фильтром либо паттерном вручную |
| Купон | `template-parts/coupon.php` через `astra_entry_content_after` |
| FAQ | блок «Подробности» (details) в редакторе |
| Из этой рубрики | `WP_Query` по той же рубрике, три записи, исключая текущую |
| Сайдбар | виджет-зона `blog-sidebar` плюс `template-parts/sidebar-blog.php` для хвоста |
| Хвост колонки | после виджетов, `margin-top:auto` и `position:sticky`, скрыт до 1000px |

### Время чтения

`str_word_count()` не мультибайтовая и на кириллице возвращает 0. Считать так:

```php
function blog_reading_time( $content ) {
    $text = wp_strip_all_tags( strip_shortcodes( $content ) );
    preg_match_all( '/[\p{L}\p{N}]+/u', $text, $m );
    $words = count( $m[0] );
    return max( 1, (int) round( $words / 180 ) );
}
```

Проверка: `blog_reading_time` на статье из макета (около 780 слов) должна
вернуть 4, а не 9.

### Шорткод реплики на полях

```php
add_shortcode( 'note', function ( $atts, $content = '' ) {
    $warm = isset( $atts[0] ) && 'warm' === $atts[0] ? ' warm' : '';
    return '<div class="note' . $warm . '">' . wp_kses_post( $content ) . '</div>';
} );
```

В редакторе: `[note]«ну сейчас скажет, что нужен аудит за 50 тысяч»[/note]`

### Врезка Telegram: ровно одна на статью

Вставка идёт перед абзацем, а не между `</p>` и следующим тегом, иначе
в разметке появляется лишний закрывающий тег.

Вариант ниже считает абзацы, начинающиеся с новой строки. Это отсекает
`<p>` внутри строки, но **не отличает абзац верхнего уровня от абзаца внутри
`wp-block-group`, колонок или цитаты**: паттерны «Таблица разрывов»
и «Проверьте у себя» как раз такие обёртки, и врезка теоретически может
попасть внутрь. Надёжный вариант, если это случится на реальной статье,
считать позицию по `parse_blocks( $post->post_content )` и вставлять между
блоками верхнего уровня.

```php
add_filter( 'the_content', function ( $content ) {
    if ( ! is_singular( 'post' ) || ! in_the_loop() || ! is_main_query() ) {
        return $content;
    }
    // Ручная вставка приоритетнее: если автор поставил паттерн сам, не дублируем
    if ( false !== strpos( $content, 'tg-inline' ) ) {
        return $content;
    }

    // Позиции только у абзацев, начинающихся с новой строки (верхний уровень)
    if ( ! preg_match_all( '/(?:^|\n)<p[ >]/', $content, $m, PREG_OFFSET_CAPTURE ) ) {
        return $content;
    }
    $positions = wp_list_pluck( $m[0], 1 );
    if ( count( $positions ) < 6 ) {
        return $content;
    }
    $at = $positions[ (int) floor( count( $positions ) * 0.65 ) ];

    ob_start();
    get_template_part( 'template-parts/tg-inline' );
    $block = ob_get_clean();

    return substr( $content, 0, $at ) . "\n" . $block . substr( $content, $at );
}, 20 );
```

Приоритет 20 обязателен, но по разной причине для разных редакторов:
в классическом `wpautop` работает на 10 и до него абзацев в контенте нет,
в блочном `wpautop` снимается совсем, а абзацы приходят из `do_blocks`.
В обоих случаях к приоритету 20 разметка уже собрана.

Проверка на `tg-inline` в тексте нужна, чтобы конвертор остался ровно один.
Это главное правило концепции, и его легко случайно нарушить.

## 6. Купон: приём заявок и 152-ФЗ

Форма собирает имя, контакт, сайт и бюджет. Это персональные данные, значит
нужны три вещи, а не одна.

1. **Чекбокс согласия** с обязательным `required` и ссылкой на политику
   обработки. В макете он есть, поле `lead_consent`.
2. **Страница политики обработки персональных данных**, опубликованная
   и доступная по прямой ссылке.
3. **Хранение данных на серверах в России.** Хостинг сайта и приёмник заявок
   (CRM, бот, почтовый сервис) должны быть российскими.

**Нонс на этой форме не ставим.** `wp_nonce_field` печатает токен в HTML,
живёт он 12-24 часа, а страницы статей почти наверняка попадут под кэш-плагин.
Через сутки закэшированная страница отдаёт протухший токен и каждая отправка
падает в «Ссылка устарела». Для анонимной публичной формы нонс к тому же ни
от чего не защищает. Вместо него honeypot и проверка времени заполнения.

Если кэш-плагин всё же настроен на исключения, страницы статей проще
исключить из кэша, чем чинить форму.

Обработчик отправки:

```php
add_action( 'admin_post_nopriv_blog_lead', 'blog_handle_lead' );
add_action( 'admin_post_blog_lead', 'blog_handle_lead' );

function blog_back_with_error( $code ) {
    wp_safe_redirect( add_query_arg( 'lead_error', $code, wp_get_referer() ?: home_url( '/' ) ) );
    exit;
}

function blog_handle_lead() {
    // Honeypot: поле скрыто стилями, человек его не заполняет
    if ( ! empty( $_POST['lead_site_url'] ) ) {
        exit;
    }
    // Форма, отправленная быстрее трёх секунд после отрисовки, это бот
    $started = (int) ( $_POST['lead_ts'] ?? 0 );
    if ( $started < 1 || ( time() - $started ) < 3 ) {
        exit;
    }
    // Не больше трёх отправок с адреса в час
    $key = 'lead_rate_' . md5( $_SERVER['REMOTE_ADDR'] ?? '' );
    $hits = (int) get_transient( $key );
    if ( $hits >= 3 ) {
        blog_back_with_error( 'rate' );
    }
    set_transient( $key, $hits + 1, HOUR_IN_SECONDS );

    if ( empty( $_POST['lead_consent'] ) ) {
        blog_back_with_error( 'consent' );
    }
    $fields = [
        'Имя'            => sanitize_text_field( $_POST['lead_name'] ?? '' ),
        'Контакт'        => sanitize_text_field( $_POST['lead_contact'] ?? '' ),
        'Сайт'           => esc_url_raw( $_POST['lead_site'] ?? '' ),
        'Бюджет'         => sanitize_text_field( $_POST['lead_budget'] ?? '' ),
        'Что не сходится'=> sanitize_textarea_field( $_POST['lead_task'] ?? '' ),
    ];
    if ( '' === $fields['Имя'] || '' === $fields['Контакт'] ) {
        blog_back_with_error( 'empty' );
    }

    $body = '';
    foreach ( $fields as $label => $value ) {
        $body .= $label . ': ' . $value . "\n";
    }
    wp_mail( get_option( 'admin_email' ), 'Купон на разбор', $body );

    wp_safe_redirect( home_url( '/spasibo/' ) );
    exit;
}
```

Ошибки возвращают читателя на статью с параметром `lead_error`, а не в
`wp_die`: на конверторе терять напечатанное дороже, чем кажется. Шаблон
купона читает параметр и показывает строку над формой.

В шаблоне купона: `action="<?php echo esc_url( admin_url( 'admin-post.php' ) ); ?>"`,
скрытые поля `action=blog_lead`, `lead_ts` со значением `time()` и honeypot
`lead_site_url`, спрятанный не через `display:none`, а уводом за экран
(`position:absolute;left:-9999px`) с `tabindex="-1"` и `autocomplete="off"`.

Страницу `/spasibo/` создать до запуска: на неё уходит редирект, и на ней же
считается цель заявки.

Письма от `wp_mail` часто уходят в спам. Ставить SMTP-плагин и отправлять
с почты на своём домене, после чего обязательно проверить доставку.
В макете отправка заглушена: `onsubmit="return false;"`.

## 7. SEO: сначала Яндекс

Целевая аудитория ищет в Яндексе. Часть механик, привычных по Google,
здесь не работает, и это меняет приоритеты.

| Что | Как |
|---|---|
| Яндекс.Вебмастер | подтвердить сайт, задать регион, загрузить sitemap, следить за «Страницы в поиске» |
| Переобход | после публикации отправлять адрес в «Переобход страниц» вручную, это ускоряет индексацию заметно |
| Sitemap и robots | плагином, `Clean-param` для utm-меток |
| ЧПУ | `/blog/<рубрика>/<слаг>/`. **Одна рубрика на запись**, иначе `%category%` породит дубли |
| Article / BlogPosting | Yoast или Rank Math |
| BreadcrumbList | хлебные крошки плагина, выводить над кикером |
| FAQPage | размечать стоит, но не ради сниппета: Google с 2023 года показывает его почти никому, Яндекс разметку не использует. Ценность в структуре ответов для AI-выдачи |
| Оглавление и якоря | навигация по длинному тексту, для Яндекса это не «быстрые ссылки» |
| Нейро и AI-выдача | лид под H1 и первый абзац каждого H2 писать так, чтобы их можно было забрать целиком как ответ |
| Скорость | без конструктора, критический CSS в `<head>`, webp, ленивая загрузка ниже первого экрана |

**Кластеры пока непроверены.** Восемь рубрик из `CONCEPT.md` собраны по логике
задач клиента, а не по частотности. До запуска нужен Wordstat по каждому
кластеру и разбор топ-10 по трём опорным запросам: в этой нише выдачу часто
занимают справка Яндекса, ppc.world, vc.ru и агентства с возрастными доменами.
Результат может сократить список рубрик, и это нормально.

## 8. Цели Метрики

Все кнопки в макете размечены атрибутом `data-goal`. Один обработчик:

```js
document.addEventListener('click', function (e) {
  var el = e.target.closest('[data-goal]');
  if (!el) return;
  // wp_localize_script приводит скаляры к строке, а строка "0" в JS истинна,
  // поэтому проверять надо число, а не «что-то пришло»
  var id = window.BLOG_CFG ? parseInt(BLOG_CFG.ymId, 10) : 0;
  if (typeof ym === 'function' && id > 0) {
    ym(id, 'reachGoal', el.dataset.goal);
  }
});
```

`BLOG_CFG.ymId` приходит из `wp_localize_script` (§3). Без него цели молча
не срабатывают, а клики визуально проходят, и это замечают через месяц.

Цели подписки: `tg_sub_side`, `tg_sub_inline`, `tg_sub_tail`, `tg_sub_mobile`.

**Цель `lead_audit` вешается не на клик по кнопке, а на загрузку `/spasibo/`.**
Клик по `submit` срабатывает и при пустом обязательном поле, и на каждом боте,
пробившем honeypot. Считать заявку можно только после того, как обработчик её принял.

**Точный замер подписок делает не Метрика, а Telegram.** Создать четыре
пригласительные ссылки `t.me/+...`, по одной на плейсмент, и подставить каждую
в свою точку. Telegram показывает число вступивших по каждой ссылке, поэтому
вопрос «какая точка работает» закрывается фактом, а не оценкой. Цели Метрики
остаются для воронки внутри сайта.
