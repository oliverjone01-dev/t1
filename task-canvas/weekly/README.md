# Недельный план/факт

Страница `/tasks/weekly/` читает обе вкладки задач, неизменяемые планы/закрывающие снимки и журнал из той же Google Таблицы. Просмотр без входа, CSV без credentials. План — активные задачи со сроком до конца недели, включая долг. Нет срока — раздел решений. Внеплановое выполнение, отмена, удаление и перенос не увеличивают выполнение первоначального плана. Смена владельца сохраняет исходного.

Закрытый уже авторизованный Telegram Apps Script получает дополнительный независимый обработчик. `startWeeklyReports` создаёт один пяти-минутный trigger `pollWeeklyReports`; минутный Telegram-приёмник не включается. Дополнительные Google-разрешения, API-ключи и Firestore не нужны. Данные в рамках бесплатных квот Google; точное время запуска триггера не гарантируется. Начало подготовки в пн с 09:45 МСК оставляет запас до планёрки в 10:00. При сбое свежесть/неполнота должна быть видна; это не SLA.

Служебные вкладки: снимки `1909260101`, события `1909260102`, состояние `1909260103`. Не переименовывать/не редактировать JSON вручную. Все изменения журнала, недельные снимки и последнее состояние фиксируются одной Sheets batchUpdate под Script Lock. Потерянный ответ сверяется чтением последнего состояния, повтор не дублирует журнал. Последнее состояние хранится в таблице, не в эфемерном кеше. Неизменяемость обеспечена кодом сборщика; редактор таблицы технически может изменить архив.

Факт закрывается по наблюдаемому состоянию до конца воскресенья: понедельничные изменения не попадают в прошлую неделю. Время завершения — обнаружение при опросе; быстрые переходы между опросами могут быть не видны. При паузе на границе недели >15 минут факт отмечается `gap`, процент не выводится. Снимок плана, созданный позднее пн 10:00, отмечается `late`.

Первая прошлая неделя — реконструкция по датам источников/срокам без выдуманного исторического плана и выполнения. Восстановленный текущий статус не доказательство даты завершения. Отсутствующий закрывающий снимок не заменяется текущей доской. Данные в GitHub не публикуются; только исходники.

Установка: `npm run build:telegram`, заменить Code.gs закрытого проекта на telegram/dist/Code.gs, сохранить прежний манифест и свойства, выполнить `startWeeklyReports`, затем `checkWeeklyReports`. Полный Code.gs сохраняет старые функции Telegram. Проверить первое сохранение, повтор без дублей, страницу и триггер. Глобальные функции не раскрывают токен.

Контракт приёмки: выбор недели → факт/план/решения → фильтр ответственного → карточка; печать; узкий экран; закрытая неделя не зависит от текущего статуса; пропуск данных не считается нулём; понедельник 00:00 МСК; отмена/переоткрытие/перенос/смена ответственного; атомарность и повтор после потерянного ответа.
