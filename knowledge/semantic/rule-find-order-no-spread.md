# Правило: расход ищется по номеру заказа, а не раскладывается

**Решение Ивана, 28.09.2026.** Действует для всех таблиц «Денег» (OZON и Маркет) и для любых будущих источников расходов по заказу (ведомость доставки, реклама «за заказ», услуги партнёров, возвраты).

## Правило

1. Расход по заказу ищется **по номеру этого заказа** и встаёт на **его дату заказа** (аналитика «Денег» по заказам построена по дате заказа).
2. Если номер записан не так, как в выгрузке площадки, его приводят к номеру площадки: «бывш.» (действует номер до «бывш.»), номер без хвоста отправления, два номера в одной строке. Сумма одной строки делится только между отправлениями, которые эта строка сама назвала (по штукам).
3. Если заказ по номеру **не нашёлся**, расход **не раскладывается** ни по другим заказам, ни по артикулу, ни по месяцу, и не добирается строкой «Общие расходы». Он выводится **плашкой над таблицей** со списком номеров и сумм, по образцу плашки «Нет производственной СС»: пробел должен быть виден, а не спрятан в чужих строках.
4. Остаток «итог документа за окно минус разнесённое» как источник числа запрещён, если документ и таблица стоят на разных датах (отгрузка против заказа, начисление против заказа).

## Почему

22.09 в таблицу по заказам добавили добор: ведомость по артикулу (на дате отгрузки) минус разнесённое по номерам (на дате заказа) раскладывалась по заказам артикула. Доставка заказа 79214675-0180-2 (оформлен 31.07, отгружен 04.08, 3 666 ₽) стояла в июле по номеру и второй раз попадала в август добором: у 46952822-0108-1 выходило 3 559 ₽ при 2 948 ₽ в ведомости (замечание Ивана 28.09). Тот же механизм сидел в строке «Общие расходы».

## Как исполняется

- Код: `analytics-mvp/src/scripts/delivery-match.ts` (`matchLedger`), подключён в `build-katya.ts`.
- Тесты: `delivery-match.test.ts`. В их числе инвариант на живых данных: «найдено + не найдено = вся ведомость до копейки», и точная сверка заказа 46952822-0108-1.
- Плашка: `#ordan-dlwarn` над «Аналитикой по заказам».
- Счёт перевозчика по отменённому заказу стоит на этом отменённом заказе (товар возили, покупатель отказался), а не пропадает.
