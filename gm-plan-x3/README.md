# gm-plan-x3

Декомпозиция цели GLASS MEMORY: выручка 2027 = 3 x выручка 2026. Вкладки: 2026, 2027, Сравнение.

- Данные: `data/fact-2026.json`, помесячные агрегаты оплат 2026 из вкладки «Отчет отдела продаж2» (выгрузка 20.11.2026), без персональных данных.
- Модель и допущения: `build.py` (словарь ASSUMPTIONS, инварианты в конце).
- Сборка: `python3 gm-plan-x3/build.py` -> `index.html`.

Статус: черновик. Нормы с пометкой «гипотеза» не согласованы, мощность производства под x3 не подтверждена. В Pages не подключено: для публикации нужен шаг в `deploy-pages.yml` на main (гейт ФЕНИКСА и «да» Ивана).
