# Прогресс и оформление · PR 626

Ручной процент 0–100 доступен по клику на круг во всех рабочих представлениях и в редакторе. Запуск переводит в «В работе», пауза — в «Приостановлено» с сохранением процента. Активный круг пульсирует, пауза не анимируется; prefers-reduced-motion отключает пульсацию. Статус «Готово» задаёт 100%, снижение готовности у завершённой задачи возвращает её на паузу. Автоматического роста процента по времени нет.

Данные progress/workStarted сохраняются в существующем R._task без новых столбцов и с сохранением positions/срочности/дат. В командной доске прогресс и выполнение входят в группу status для явных конфликтов. WeeklySignals учитывает эти поля в наблюдениях и снимках. Закрытые недели остаются только для чтения; изменения текущей недели, как и срочности, открывают редактор основной доски для подтверждения.

Исходный PNG пользователя сохранён побайтово. Его отрицательный альфа-канал отображается через CSS-маску; цвет берётся из темы. На узкой ширине показан знак, на широкой — полная подпись. Прямая кнопка темы записывает выбор в существующие preferences на устройстве, не меняя плотность; выбор действует и на странице план/факт. Настройки доступны отдельной кнопкой.

Авторская проверка: 251 тест; round-trip Sheets, жизненный цикл, конфликт прогресса и запуска, независимый комментарий, numeric/boolean weekly, редактор, сохранение темы и плотности. Браузер demo: 26% по клавиатуре, пауза сохраняет 26% и убирает animation/pressed-play, запуск возвращает их; reload сохраняет прогресс и dark; редактор сохраняет 27%; просмотрены матрица, обзор, команда, список, Гант, календарь, 390×844 без горизонтального переполнения, логотип в обеих темах. Настоящие задачи тестовыми изменениями не затронуты. Четыре исходных незакоммиченных Telegram-файла не изменялись, сборка проверяется отдельно.
