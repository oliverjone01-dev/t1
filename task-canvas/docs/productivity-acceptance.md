# Десять улучшений ежедневной работы

Объект: task-canvas на базе 2cab1c6. Использование: владелец планирует и редактирует, коллега читает общую доску. Реализация и публикация разрешены в текущем чате. Проверка собственной реализации, не независимый аудит.

## Отбор до реализации

Наблюдение по исходному коду: уже есть команды, черновики, undo, групповой перенос, Overview. Не считать их новыми функциями. Ручной поиск по тексту не заменяет выборки по датам; редактор закрывается после каждой сохранённой карточки; массовые действия ограничены переносом/статусом.

Приняты: быстрые выборки; сохранённые виды; личное избранное; сортировки списка; ссылка на задачу; последовательный разбор карточек; быстрые сроки; массовое редактирование с предпросмотром; создание задач из строк; новая задача по образцу.

Отклонены: автоприоритеты, AI-оценки и новые уведомления без подтверждённой потребности; отдельный backend; счёт существующих возможностей как новых. Польза принятых функций — продуктовая гипотеза, не измеренный рост эффективности.

## Приёмка

Авторская проверка ФЕНИКС: UI и модель `ready` для публикации после CI. Справочник Bitrix требует наблюдения результата серверной сборки; до него реальные имена/фото не объявлены загруженными.

Проверено: 172 теста (на момент финальной локальной проверки) (включая исходную синхронизацию), сборка и синтаксис; браузер IAB, ширины 390×844, 1024×768 и 1341×924, светлая/тёмная темы. В демо кликами: быстрый срок; черновик при переходе туда/обратно; сохранить и далее; 3 строки → 2 задачи с предупреждением о дубле; массовые owner/due → undo; копия с новым ID/пустым сроком; избранное после reload; сохранение и применение вида; день/неделя/месяц/12 месяцев; создание на конкретную дату. На рабочих 49 задачах только чтение: гостю недоступны drag/create/edit; календарь и карточки доступны; deep link открывает нужную readonly-задачу; отсутствующий ID показывает сообщение. Console errors не обнаружены.

Контраст 82 текстовых сочетаний новых элементов на календаре/фильтрах: минимум 5.23:1 в светлой, 7.30:1 в тёмной теме. Это целевая проверка, не сертификация всего интерфейса.

Найдено и исправлено до допуска: (1) «Назначить» с пустым значением могло означать очистку — теперь отдельная валидация, для очистки явный пункт; (2) узкий месяц с названиями задач давал слишком мелкий текст — на телефоне нагрузка по дням и переход к читаемому дню; (3) длинное меню из пяти видов занимало две строки — компактная строка с иконками; (4) широкая плашка иконки в обзоре из-за flex наследования — фиксированный размер; (5) непросмотренная задача могла исчезать из очереди после acknowledgement — выборка фиксируется перед открытием; (6) фамилия из справочника и короткий alias должны давать одну дорожку/фильтр — отображение нормализовано без перезаписи исходных данных.

Ограничения: новые реальные записи в Google не создавались ради теста; мобильная проверка — viewport, не физическое устройство; экранный диктор не запускался; полезность проверена сценариями, а не пользовательским исследованием. Избранное/виды персональны для браузера. Новых защит прав сервера не вводилось; существующий emulator-suite проверяет права и конфликтный путь в CI.

## Единое правило переноса (добавлено пользователем перед публикацией)

Список: в сортировке по дате перенос изменяет срок/очередь, по человеку — назначение/очередь, по приоритету и вручную — квадрат/очередь. Из алфавитного вида после переноса включается ручной порядок. Календарь: перенос между днями/месяцами и порядок внутри дня; «месяцы» теперь содержит реальные карточки; на телефоне месяц открывает карточки выбранного дня рядом с календарём. На ручке работает Pointer Events (мышь/касание), Пробел/стрелки, Escape; есть цель вставки, предпросмотр результата и автопрокрутка. Существующие квадраты/обзор и дорожки времени/людей сохраняют свой перенос.

Браузер: список по сроку, keyboard lift → down → drop изменил 9→10 ноября и поставил после соседней задачи; undo вернул дату. В неделе pointer drag перенёс 9→12 ноября. В «месяцах» keyboard right → drop перенёс 12 ноября→12 декабря, две отмены восстановили исходное. Pure-тесты: день сохраняется/ограничивается длиной месяца, terminal status не открывается заново от переноса даты/ответственного, групповой порядок стабилен, удалённая/изменённая во время drag задача блокирует перенос, чужой комментарий сохраняется. Полноценный touch на физическом телефоне не проверен.
