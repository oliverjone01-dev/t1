# Важность, недельный реестр и архив статусов

- Важность: 1–5, 0 — не оценена. Отдельное поле от квадрата срочности/важности. Цвет, число и 5 сегментов; native select для прямой установки с клавиатуры и касанием. Карточки, обзор, холст по людям/срокам, список, календарь, редактор, массовая правка, недельный отчёт. В отчёте выбор открывает редактор доски для сохранения по действующим правам.
- Поля importance/closedAt/archiveKind хранятся в JSON R в `_task`, существующие позиции сохраняются. Это не новые столбцы: старая 22-колоночная схема сохраняется. Рейтинг входит в групповой конфликт приоритета; даты/архив — в конфликт статуса. Старые операции без дополнительных полей допускаются без обнуления метаданных.
- Рабочий фильтр недели действует в любом виде. Готовые/отменённые включаются вопреки переключателю скрытия; выборка — срок в неделе или завершение в неделе. В календарной неделе завершённая задача с датой завершения в этой неделе размещается на дату завершения. Иначе остаётся на плановом сроке. Статус меняется прямо в календаре, списке или редакторе.
- Отсчёт по Москве. В архив попадают завершённые раньше начала прошлой недели, то есть позапрошлая неделя и старше. На 09.11.2026 архивируются завершённые до 02.11.2026; 02–08 ноября сохраняются в обычных зонах. Дата не выводится из срока. Для старого терминального статуса без даты сохраняется первое наблюдение.
- Автоархив — lifecycle-проекция в служебной вкладке состояния; сборщик никогда не перезаписывает R с пользовательскими позициями/оценкой. Ручное удаление/архив T остаётся отдельной операцией. Чтение проекции накладывает только lifecycle и только при совпадающем статусе, поэтому переоткрытая задача не получает старый архив.
- Установка сборщика: `npm run build:weekly`, добавить отдельный файл WeeklySignals.gs в существующий закрытый Apps Script, сохранить остальные файлы/свойства. `startTaskSignalsReports` сначала выполняет новый сбор, создаёт один pollTaskSignalsReports, затем удаляет только старый pollWeeklyReports. Telegram-триггеры не меняются. Новые права/ключи/платные сервисы не нужны.
- Проверить: 0/1/5 и отказ для нецелых значений; JSON roundtrip; конфликт рейтингов с разных устройств; независимое назначение; Moscow midnight; повторное открытие; неизвестная дата; сохранение старых недель; недельный фильтр и терминальные статусы во всех видах.
