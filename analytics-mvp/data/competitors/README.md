# Конкуренты OZON

`mpstats-matched-2026-10-22.json` - проверенный исторический набор за 23.09–20.10.2026: 29 ручных связей, 26 наших SKU, 29 конкурентных SKU. Набор используется только на странице OZON. Дата сборки страницы не сдвигает период данных.

Импорт из проверенного локального файла прототипа:

```
python3 tools/competitors/import_reviewed.py /path/to/reviewed/data.json
```

Импорт оставляет только необходимые публичные поля. Полные исходные строки кабинета, API и ответы MPSTATS, секреты и локальные пути в набор не включаются. Ссылки на источники заменены именами файлов и SHA-256. История и показатели не рассчитываются заново.

Валидация перед каждой сборкой: `src/scripts/competitors/matched-data.ts`. Штатная сборка `build-katya.ts` заменяет прежние демо-числа OZON этой страницей. Данные Яндекс Маркета не меняются. Новое окно или состав связей требуют отдельной проверки и обновления контракта; текущий набор не является ежедневным сборщиком MPSTATS.
