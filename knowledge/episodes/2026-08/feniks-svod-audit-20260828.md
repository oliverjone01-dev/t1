## Ключевые уроки (для реюза)

1. **`\b` в JS-регексах не работает рядом с кириллицей.** `ч`, `дн` - не `\w`, границы нет: `/\bN\s*ч\b/.test("клиент ждёт N ч") === false`. Границы задавать явными пробелами/скобками. Дважды наступили (шаблон + guard в smoke).
2. **Guard обязан проверяться мутацией.** Тест «под фикс» вместо «под требование» - PASS при удалённом фиксе. Приёмка: убрал фикс - тест упал с цитатой; вернул - зелёный. В smoke-svod теперь 4 таких guard'а (deN, outlier-чип, безымянный этап, plural).
3. **Guard должен бежать после рендера проверяемого.** topLoss живёт только на личных страницах - smoke рендерит все 11 и копит видимый текст, исключая `<script>` (в сыром JSON плейсхолдеры легитимны).
4. **Двойной счёт денег - главный семантический риск сборных дашбордов.** Открытые сделки в предоплатных стадиях (69 шт / 10,4 млн) уже посчитаны в «Продано» - исключены из «Под риском»/«Дожать»/прогноза с видимыми оговорками. Разница «дожать»: 15,1 млн → 6,3 млн.
5. **Сверка до копейки как видимый элемент UI.** Колонка (18 041 454,25) + вне разбора (1 648 527) = плитка (19 689 981,25) - строка под таблицей, а не вера на слово.
6. **body.textContent в jsdom включает `<script>`** - проверки текста страницы фильтруют скрипты, иначе ложные срабатывания на JSON.
