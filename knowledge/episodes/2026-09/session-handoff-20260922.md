## ГОЧА (проверено в этой сессии)

- Данные-ветки правим через `git worktree add <путь> origin/<branch> --detach`.
  Ветка большая: тянуть `git fetch --depth=1 --filter=blob:none`, иначе долго.
- Локальная сборка: `cd analytics-mvp && ROP_JSON=<путь>/rop.json npx --yes tsx@4
  src/scripts/b24/score-dialog.ts`, затем `build-dialog.ts`. node_modules в ветке нет, tsx через npx.
- `rop.json` берётся из `rop-dashboard-v1:analytics-mvp/rop/data/rop.json`.
- score-dialog.ts ИДЕМПОТЕНТЕН и детерминирован по снимку: базовый прогон на неизменённом коде
  воспроизводит закоммиченный dialog.json байт-в-байт. Это главный инструмент замера:
  сначала базовый прогон, потом правка, потом диф - тогда весь диф объясняется правкой.
- `public/dialog.html` для `/dialog/` НЕ коммитим, деплой пересобирает. Для `/rop/` коммитим.
- Смоук страницы: playwright ставится локально (`npm i playwright@1.56`), Chromium уже
  в `/opt/pw-browsers`, `playwright install` не запускать.
- egress-прокси блокирует `oliverjone01-dev.github.io`, живую страницу curl-ить нельзя.
- Force-push блокируется классификатором, использовать новые ветки и PR.
- Стоп-хук требует коммитить `traces/YYYY-MM-DD/agents.jsonl` каждый ход. При мерже main
  файл конфликтует: лог append-only, резолв - объединение обеих сторон с дедупом и сортировкой
  по ts, каждая строка проходит `python3 schemas/validate.py agent-trace -`.
