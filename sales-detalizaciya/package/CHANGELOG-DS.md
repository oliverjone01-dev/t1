# Контур DS · 1.4 (kx)

База: Контур DS 1.3 из макета «Разбор недели» (`tokens.css`, `kit.css`, `kit.js`), без изменений. Расширение 1.4 лежит отдельно в `kx.css`, `kx.js` и `kx-showcase.js`. Его можно накатить поверх 1.3 и откатить, удалив два файла.

## Система

Одна система на всю страницу. По ней собран каждый подраздел «Детализации».

| Что | Значения |
|---|---|
| Шаг отступов | 4 · 8 · 12 · 16 · 20 · 24 · 32 · 56 |
| Зазор сетки | 12, сетка 12 колонок (`.grid12`, `.c4 .c6 .c8`) |
| Поле карточки | 20 |
| Радиусы | клавиша 4 · кнопка 8 · плитка 12 · карточка 16 |

**Текст:**

- число-герой;
- заголовок экрана;
- заголовок раздела 24;
- вывод 15,5 / 500;
- текст 14;
- служебный 12;
- подпись 11 капсом.

**Цвет только как статус:**

- красный: теряем;
- жёлтый: близко к норме;
- зелёный: норма;
- синий: поток клиентов.

**Анатомия раздела:** номер → заголовок → вывод → метка «данные / гипотеза» → визуал → действие.

## Новые токены (`kx.css`, глобальные)

- `--e-in` `cubic-bezier(.2,.8,.2,1)` для появления, панелей и чисел.
- `--e-out` `cubic-bezier(.4,0,1,1)` для закрытия.
- `--e-std` `cubic-bezier(.4,0,.2,1)` для плашек и аккордеона.
- `--lift`, `--lift-hi`: глубина покоя и наведения, отдельно для тёмной темы.

**Стекло** (размытие 20, насыщенность 160%) только на слоях поверх контента: подсказка, уведомление, панель, палитра.

**Движение** только через transform, opacity, clip-path, stroke-dashoffset и grid-template-rows, без пружин. «Меньше движения» выключает всю анимацию, «меньше прозрачности» выключает стекло.

## Пересечения с 1.3, которые нужно решить

- В `kit.js` уже есть `KS.seg`, `KS.tip`, `KS.toast`, `KS.spot` и `KS.cmdk`. В 1.4 появились версии `KS.kx.*` с другим движением и стеклом.
  - Классы не конфликтуют: kx работает только внутри `.kx`.
  - Двух палитр одновременно не будет: `kx.js` перехватывает ⌘K.
  - Рекомендация: новые экраны делать на `KS.kx.*`, старые переводить постепенно, затем удалить дубли из `kit.js` и выпустить 2.0.
- Классы kx без префикса (`.card`, `.b`, `.seg`) безопасны только внутри `.kx`. Не снимайте `.kx` с корня.
