## SKIP - не берём (конфликт с дисциплиной или вне мандата)

Чёрные/серые тактики - прямой конфликт с Anti-Slop, Protocol 9, Comprehension Gate,
премиум-доверием GENGLASS. **Не выброшены, а вынесены в разведотчёт с оценкой
эффективности и риска:** `knowledge/grey-tactics-intel.md` (архив, не для исполнения).

| Атом | Почему не берём |
|---|---|
| ПФ-накрутка через инсценированный путь клиента (3.7) | Нарушение ToS Яндекса, сфабрикованный сигнал = конфликт Protocol 9 |
| Накрутка персональной подсказки инкогнито-поисками (6.3) | Та же манипуляция поведенческим сигналом |
| Фейковые видео-«звонки» как реальные (6.4) | Конфликт с Comprehension Gate (честность подачи), не premium-voice |
| Массовая покупка размещений VC/DTF/Habr через биржи (3.2) | Конфликт с citation-worthy уникальностью и Anti-Slop; максимум пилот ≤50К |
| Крауд-ссылки/каталоги пакетами (3.2) | Количество без качества, риск спам-профиля |
| Ловцы номеров (DMP fingerprinting) | Приватность/152-ФЗ риск, вне мандата, против доверительного бренда |
| Домен-сквоттинг брошенных доменов конкурентов | Юридический/репутационный риск |

Вне мандата SEO/GEO (не конфликт, просто чужой домен): промты по резюме/карьере,
бизнес-SWOT, партнёрские цепочки, фокус/продуктивность, CPA/CPL шпаргалки,
реверс виральных Reels (передать в krea/content-factory backlog).
