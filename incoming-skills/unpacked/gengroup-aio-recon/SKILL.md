# AIO/GEO/AEO RECON - Разведка AI-видимости GENGROUP

## Назначение

Воспроизводимый 8-шаговый процесс исследования AI-видимости любого бренда GENGROUP в любой продуктовой категории. На выходе: верифицированный HTML-лендинг для команды с реальными данными, стратегией и чек-листом первой недели.

**Проверено на:** GENGLASS / стальные межкомнатные перегородки (апрель 2026)
**Следующий запуск:** GLASS-MEMORY / стеклянные ритуальные изделия

## 8 ШАГОВ ПРОЦЕССА

### ШАГ 1: СБОР ОРГАНИКИ (30 мин)

**Что делаем:** Прогоняем 5-6 поисковых запросов через web_search и собираем кто реально стоит в органике.

**Промпт-шаблон:**
```
Прогони следующие поисковые запросы и собери для каждого:
- Топ-10 результатов (бренд + домен + краткое описание)
- Есть ли наш бренд [БРЕНД] в результатах? На какой позиции?
- Есть ли рейтинговые статьи (Топ-N, обзоры, сравнения)?
- Новые конкуренты, которых нет в нашем списке

Запросы:
1. [ЦЕЛЕВОЙ ЗАПРОС]
2-6. [ДОПОЛНИТЕЛЬНЫЕ ЗАПРОСЫ]

ПРАВИЛО: Все URL из результатов проверяй через web_fetch. 
Мёртвые ссылки (404) = удалять немедленно. 
Никаких утверждений без проверенного URL.
```

**Выход:** Таблица "Кто реально в органике" + список новых конкурентов

---

### ШАГ 2: ПРОВЕРКА AI-ОТВЕТОВ (требует участие Ивана)

**Что делаем:** Иван вручную проверяет 4 AI-системы и присылает скриншоты.

**Шаблон для Ивана (копировать в чат):**
```
Иван, проверь этот запрос в 4 AI-системах и пришли скриншоты:

Запрос: "[ЦЕЛЕВОЙ ЗАПРОС]"

1. Google AI Mode (google.com -> "Режим ИИ")
2. ChatGPT (chatgpt.com, новый чат, временный)
3. Claude AI (claude.ai, инкогнито чат)
4. Яндекс Алиса (ya.ru -> "Алиса AI")

Для каждого: скриншот полного ответа с видимыми брендами и источниками.
```

**Выход:** 4 скриншота с реальными AI-ответами

**После получения скриншотов - промпт:**
```
Проанализируй скриншоты AI-ответов. Для каждой AI-системы зафиксируй:
- Какие бренды упомянуты и на какой позиции
- Есть ли наш бренд [БРЕНД]? На какой позиции?
- Есть ли суб-бренды GENGROUP (Metal-GM, GENGLASS, etc.)?
- Какие источники процитированы?
- Какие конкуренты НОВЫЕ (не были в нашем списке)?

Собери сводную таблицу:
| AI-система | Наш бренд | Позиция | Топ-3 конкурента |
```

---

### ШАГ 3: ВЕРИФИКАЦИЯ КОНКУРЕНТОВ (20 мин)

**Что делаем:** Проверяем каждого конкурента из AI-ответов.

**Промпт:**
```
Для каждого конкурента из AI-ответов проверь:
1. Сайт жив? (web_fetch главной страницы)
2. Есть ли [КАТЕГОРИЯ] в их ассортименте? (реально ли они конкурент)
3. Есть ли блог / внешние публикации?
4. Есть ли FAQ Schema на сайте? (ищи в HTML "@type":"FAQPage")
5. robots.txt: открыт ли для GPTBot/ClaudeBot?

ПРАВИЛО: Если бренд НЕ продаёт [КАТЕГОРИЯ] - помечай "не конкурент по категории".
Не путать зеркала с перегородками, мебель с памятниками, 
AL-конструкции со стальными. Каждый сегмент - отдельный.

Собери таблицу:
| Конкурент | Домен | Жив | Категория | Блог | FAQ Schema | robots.txt |
```

---

### ШАГ 4: СБОР РЕЙТИНГОВ И ВНЕШНИХ ПУБЛИКАЦИЙ (30 мин)

**Что делаем:** Ищем существующие рейтинги, обзоры, статьи по категории.

**Промпт:**
```
Найди все существующие рейтинги и обзорные статьи по запросам:
- "рейтинг [КАТЕГОРИЯ] 2025"
- "рейтинг [КАТЕГОРИЯ] 2026"  
- "лучшие [КАТЕГОРИЯ] Москва"
- "топ производителей [КАТЕГОРИЯ]"
- "сравнение [КАТЕГОРИЯ]"
- "[КАТЕГОРИЯ] отзывы обзор"

Для каждого найденного рейтинга зафиксируй:
1. URL (ПРОВЕРИТЬ через web_fetch - жив?)
2. Площадка (vc.ru, Дзен, MetroNews, Пикабу, DTF, отраслевой, etc.)
3. Кто на #1 в рейтинге
4. Есть ли наш бренд [БРЕНД]?
5. Дата публикации
6. Тип: партнёрский / редакционный / UGC

ПРАВИЛО: Каждый URL проверяется. 404 = не включать.
```

### ШАГ 5: СИНТЕЗ + ФЕНИКС-АУДИТ (30 мин)

**Что делаем:** Собираем все данные в единую картину, ФЕНИКС проверяет.

**Промпт:**
```
На основе собранных данных (органика, AI-ответы, конкуренты, рейтинги) создай:

1. СВОДНАЯ ТАБЛИЦА AI-ВИДИМОСТИ:
| AI-система | Наш бренд | Суб-бренды | Топ-3 конкурента | Что делать |

2. МАТРИЦА КОНКУРЕНТОВ (только верифицированные):
| Бренд | Домен | AIO-балл | Площадки | Рейтинги | Ключевое |

3. КАРТА РЕЙТИНГОВ:
| Рейтинг | Площадка | Лидер | Наш бренд? |

4. НЕЗАНЯТЫЕ НИШИ:
| Ниша | Проверка | Приоритет |

5. КЛЮЧЕВЫЕ ОТКРЫТИЯ (5 пунктов):
Каждое открытие = ФАКТ со скриншота или проверенного URL.
Никаких "по данным исследования" без конкретного источника.

ФЕНИКС-АУДИТ каждого пункта:
- Источник данных? (скриншот / URL / исследование / гипотеза)
- URL проверен? (да/нет/не применимо)
- Конкурент реально продаёт [КАТЕГОРИЯ]? (да/нет/не проверено)
- Пометить непроверенное как "ТРЕБУЕТ ВЕРИФИКАЦИИ"
```

### ШАГ 6: СТРАТЕГИЯ (20 мин)

**Что делаем:** Формируем план действий.

**Промпт:**
```
На основе синтеза создай стратегию:

1. ПРИОРИТЕТЫ (по AI-системам):
- Для каждой AI где нас НЕТ: что конкретно нужно сделать
- Для каждой AI где мы ЕСТЬ: как удержать/усилить
- Если суб-бренд виден: как использовать как трамплин

2. ПЛАН ДЕЙСТВИЙ (timeline):
- Месяц 1: техническая база + первый контент
- Месяц 2-3: экспансия
- Месяц 4-6: масштабирование

ПРАВИЛА БЮДЖЕТА:
- ФОТ штатных сотрудников (Сергей, маркетолог, PM) НЕ включать в бюджет
- Включать только внешние расходы: vc.ru аккаунт, копирайтеры, промо Дзен
- Рейтинги: "рамочный бюджет" (не придумывать цены)
- vc.ru коммерческий аккаунт юрлица = 50К/мес (верифицировано)
- Копирайтеры = 20-30К/мес

3. РАЗГОН ДЗЕН (если Яндекс Алиса = приоритет):
- 5 шагов: тематика, Вордстат, буст через TG, VK Реклама "Промо", регулярность

4. ЮРИДИЧЕСКАЯ ЧИСТОТА:
- Сравниваем технологии, не бренды (ст. 14 ФЗ "О рекламе")
- Наш бренд НЕ на #1 месте в собственных рейтингах (честность > самопиар)

5. СИСТЕМА ИЗМЕРЕНИЯ:
- n8n AI Visibility Probe (еженедельно, ChatGPT API + web_search)
- Ручная проверка Perplexity + YandexGPT (2x/мес)
- Мониторинг рейтингов (ежемесячно)
```

## ANTI-PATTERNS (ошибки из сессии GENGLASS)

1. **"20+ запросов проверено"** - если проверено 3, пиши 3. Не округляй вверх.
2. **"GENGLASS невидим"** - проверь все 4 AI прежде чем писать "невидим". Может быть #1 в Google.
3. **Мёртвые ссылки как факт** - Пикабу 404 включили как действующий рейтинг. ВСЕГДА web_fetch.
4. **Miralls = конкурент по перегородкам** - Miralls = зеркала. Не путать категории.
5. **Цены из сниппетов** - "от 5 900 руб/м2" из сниппета = неточная цена. Не включать.
6. **"GENGLASS vs NAYADA"** - прямое сравнение брендов = юр. риск. Сравниваем технологии.
7. **ФОТ в бюджете** - работа Сергея = ФОТ, не "15К разово". Не включать в внешние расходы.
8. **"Исправить за 45 дней"** - уточнять: "первые результаты X дней, полная видимость Y мес."
9. **TenChat = приоритет** - DAU 150К. Не приоритет. P3 максимум.
10. **Archpole = конкурент по перегородкам** - делает мебель, не перегородки. Проверять ассортимент.
