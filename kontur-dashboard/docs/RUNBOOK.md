# Регламент обновления

## Раз в неделю, пятница (сверка руками)

```bash
cd kontur-dashboard

# 1. Убедиться, что свежие выгрузки keys.so приехали
#    (их кладёт .github/workflows/harvest.yml, ежедневно в 03:00 МСК;
#     keyso-collect.yml собирает другое - рынок конкурентов, раз в неделю)
ls -l ../gg-seo-geo-monster/data/genglass/keysso.json

# 2. Записать точку в дневной ряд; пропуски добрать из истории выгрузок в git
python3 tools/snapshot.py
python3 tools/snapshot.py --backfill

# 3. Пересобрать блок данных
python3 tools/build_data.py

# 4. Пересобрать страницу
python3 src/build.py

# 5. Проверить
python3 tools/check_dash.py      # сторож: цифры, цвет, запреты, ряд
python3 ../kontur-ds/tools/check_ds.py public/index.html   # сторож Контур DS
python3 tools/snapshot.py --check # ряд без разрывов и не просрочен
node   tools/smoke.mjs           # все экраны в двух темах и на трёх периодах
node   tools/contrast.mjs        # контраст каждого текста: 52 экрана × 2 проекта × 2 темы × 2 ширины
node   tools/seal_test.mjs       # шифровальщик: 38 утечек, правок исходников и слабых паролей обязаны остановить публикацию
node   tools/text_scan.mjs       # согласование числа и слова на 104 экранах, дамп текста в KONTUR_TMP/screens.txt

# 6. Закоммитить data/ и public/
```

Шаги 2-5 делает и воркфлоу `kontur-snapshot.yml` по расписанию. Ручной прогон
нужен, когда выгрузка пришла вне расписания или после правок в интерфейсе.

## Что делать, если сторож упал

Он не капризничает: каждая проверка стоит за конкретной ошибкой, которая уже
случалась. Разбор по коду:

| Код | Что случилось | Что делать |
|---|---|---|
| `EMDASH` | в текст попало длинное тире | заменить на дефис |
| `NOSRC` `NODATE` | у цифры класса ДАННЫЕ нет источника или даты | заполнить конверт |
| `NULLDANN` | пустое значение помечено как ДАННЫЕ | поставить класс ДЕМО |
| `KIND` | класс не из трёх допустимых | исправить на ДАННЫЕ, ГИПОТЕЗА или ДЕМО |
| `BAN` | в текст попал запрещённый факт | убрать, список в `check_dash.py` |
| `COLOR` | в коде графиков записан цвет (`#abc`, `#aabbcc`, `rgb()`, `hsl()`, `oklch()`) | убрать: цвет задаёт слот пресета `KS.charts` (`slot:1..5`) |
| `KIT` | в странице нет токенов или кита Контур DS, или вернулся Tailwind | собирать только через `src/build.py`, пакет в `kontur-ds/` |
| `OPACITY` | текст приглушён классом `opacity-*` или `opacity:` в модулях | заменить на `ks-muted` |
| `CVD` | синий и голубой встали соседними сериями | переставить слоты |
| `DUALAXIS` | две оси Y на одном графике | привести ряды к индексу |
| `EMPTY` | контейнер графика без кода отрисовки | дописать в `draw.py` |
| `NOVIEW` | пункт меню без экрана | добавить экран или убрать пункт |
| `NOSNAP` | в ряду нет ни одного своего съёма, только ретроспектива выгрузки | запустить `tools/snapshot.py`; разрывы между своими съёмами больше 8 дней сторож печатает, а экраны показывают, но сборку они не валят: пропущенный съём не восстанавливается |
| `NOHIST` `SHORTHIST` | ряда нет или в нём одна точка | `python3 tools/snapshot.py --seed` |

## Проверка сторожа

Сторож, который всегда зелёный, бесполезен. Раз в месяц:

```bash
python3 tools/tamper.py     # ждём: 18 из 18
```

Скрипт подсовывает восемнадцать заведомо испорченных версий и требует, чтобы
сторож поймал каждую. Если поймал меньше, чинить надо сторожа, а не данные.

## Добавить проект

1. Запись в `PROJECTS` в `tools/build_data.py`: код, папка выгрузки, имя, домен, план.
2. При наличии внутренних фактов - запись в `FACTS`.
3. Кнопку проекта в шапке в `src/modules/shell.py`.
4. `python3 tools/build_data.py && python3 src/build.py`.

## Публикация

`.github/workflows/deploy-pages.yml`, шаг «Build KONTUR dashboard». Копирует
`kontur-dashboard/public/` в `/kontur/` на сайте. Отдельной сборки не требует:
в `public/index.html` уже всё вшито.

## Дымовой тест вне песочницы автора

`tools/smoke.mjs` и `tools/contrast.mjs` берут зеркало ApexCharts 3.54.1
(`apex.js`) из каталога `KONTUR_LIBS` (по умолчанию `/tmp/claude-0`), пишут страницу
в `KONTUR_TMP`, браузер берут из `KONTUR_CHROMIUM` или ставленный playwright. Стили и
кит Контур DS уже внутри страницы, шрифт с Google Fonts при прогоне вырезается.

Сторож пакета с ключом `--live` (`kontur-ds/tools/check_ds.py ... --live`) открывает
только первый экран, а если браузер не запустился, выходит с «чисто»: код выхода 1
он читает как «провалы найдены», а строк провалов в выводе нет. Поэтому живой
контраст дашборда меряет `tools/contrast.mjs`: та же функция замера из пакета, но
все экраны, и сбой браузера роняет проверку. Код выхода проверять отдельно от вывода: тест печатает
счётчики до прохода на 390 px, а ошибки этого прохода выводит последней строкой.

## Публикация и пароль

Выбрано ответом в сессии 23.09.2026, подтверждено там же 23.09.2026
(`docs/RISK.md`): данные на опубликованной странице шифруются, а не прячутся за
хэшем пароля. Шаг `Build KONTUR dashboard` в `deploy-pages.yml`
прогоняет `tools/seal_page.mjs`: весь основной скрипт страницы (данные, экраны,
оболочка) заменяется шифротекстом AES-256-GCM, ключ выводится из пароля через
PBKDF2-SHA256 на 600 000 итераций. Схема та же, что у академии. В открытом виде
остаются только стили, пустая разметка и окно пароля.

Пароль берётся из секрета репозитория **`KONTUR_PASS`**, не короче 12 знаков.
Общий `HUB_PASS` не используется намеренно: `/seo/` публикует его быстрый SHA-256,
и по нему пароль подбирался бы офлайн в обход PBKDF2.

- секрета нет: раздел не публикуется, в логе `::warning::`, остальной сайт уезжает;
- пароль короче 12 знаков, совпадает с `HUB_PASS` или с паролем, уже опубликованным
  в репозитории: раздел не публикуется, причина в логе шага;
- вне шифроблока нашлось любое значение из данных (число от 1000 или строка от
  8 знаков, кроме имён проектов и доменов) или шифрование изменило страницу вне
  блока `app-js`: раздел не публикуется.

Предупреждение о пропущенном секрете видно только в логе Actions. Проверять, что
`/kontur/` появился на сайте, после первого деплоя с `KONTUR_PASS` нужно руками.

Пароль закрывает страницу на сайте, но не данные в репозитории: он публичный, и
незашифрованные `public/index.html` и `data/kontur.json` читаются по прямой
ссылке. Это принятый риск: решение записано и подтверждено ответом в сессии
23.09.2026. Что именно открыто и почему: `docs/RISK.md`.

Дымовой тест проверяет и запечатанную копию: шифрует страницу тестовым паролем,
убеждается, что до пароля нет ни данных, ни кода, неверный пароль не открывает,
а верный открывает все экраны обоих проектов.

Локальная сборка (`src/build.py`) не шифруется и открывается без пароля: сторож,
`tamper.py` и дымовой тест работают с ней. Проверить шифрование руками:
`KONTUR_PASS='...' node tools/seal_page.mjs <копия index.html>`.

Смена пароля: поменять секрет и перезапустить деплой. Открытые вкладки держат
ключ в `sessionStorage` до закрытия, новая вкладка спросит новый пароль.


## Что проверяет шифровальщик

`tools/seal_page.mjs` сначала сравнивает открытую часть страницы (всё вне блока
`app-js`) с эталоном из исходников: `python3 src/build.py --shell` отдаёт шапку,
стили пакета и свои, разметку каркаса и окно пароля. Расхождение хотя бы в один
символ останавливает публикацию: вне шифра не может оказаться комментария с
цифрой, производного числа или обработчика события, которых нет в исходниках.
Вторым слоем идут список скриптов (ровно ApexCharts по закреплённому адресу с
хэшем SRI и окно пароля), запрет обработчиков в атрибутах и поиск значений из
данных по всему открытому тексту вместе с комментариями.

Ошибка «страница расходится с исходниками» значит, что `public/index.html` собран
не из тех модулей, что лежат рядом, или правился руками. Лечится пересборкой
`python3 src/build.py`.

Второй слой ищет значения из данных от 100 и больше: в сыром виде, с разрядами
через обычный, неразрывный, узкий неразрывный и тонкий пробел, в формах «тыс.»,
«млн», «млрд». В стилях и в окне пароля ищутся только комментарии и строки.
Параметры шифра (256, 600 000) открыты и не считаются утечкой.

Стили пакета Контур DS (`tokens.css`, `kit.css`) шифровальщик пропускает, только
если их sha256 равен закреплённому в `tools/seal_page.mjs` (`PINNED`). Любая правка
или новая версия пакета без пересчёта хэшей останавливает публикацию `/kontur/`,
и бот не коммитит страницу, пока хэши не обновлены. Новая версия пакета:

```bash
python3 -c "import hashlib,pathlib;[print(f, hashlib.sha256(pathlib.Path('../kontur-ds/'+f).read_text(encoding='utf-8').strip().encode()).hexdigest()) for f in ('tokens/tokens.css','kit/kit.css')]"
```

Хэши записать в `PINNED`, пересобрать страницу, прогнать `node tools/seal_test.mjs`.

Чем грозит правка пакета без пересчёта хэшей: шаг деплоя `Build KONTUR dashboard`
упадёт на шифровальщике, раздел не попадёт в сборку сайта, и ближайший деплой
Pages (он идёт на каждый push в main и раз в сутки) выложит сайт без `/kontur/`:
по адресу будет 404. Бот съёма при этом тоже не закоммитит страницу (падает
`seal_test.mjs`). Сам раздел не вернётся: хэши пересчитывает и коммитит человек.
Тест правит исходники во временной копии (правило в `kit.css`, числа и обработчики
в `shell.py`, комментарий в своём CSS) и требует, чтобы каждая правка остановила
публикацию.
