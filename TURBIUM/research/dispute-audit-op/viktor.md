# Позиция ВИКТОРА (методология аудита), диспут 22.07.2026

## Каркас правил: 4 уровня, формат «факт → как надо было → severity»
- Уровень (а) одна коммуникация: 10 правил (имя в первых 100 симв., SLA первой реакции, полнота ответа на все вопросы, конкретный срок в обещании, текст к вложению, извинение раньше объяснения, закрытие следующим шагом, фиксация внеканального контакта, пятничное правило, анти-штамп)
- Уровень (б) сделка+CRM: 8 правил (темп по типу клиента, «дорого» с альтернативой, стадия=содержание, один запрос-одна сделка, срыв срока - менеджер пишет первым, юрлексика=эскалация, закрытие с причиной, SLA по источнику)
- Уровень (в) менеджер: паттерн ≥2 повторений, выборка ≥10 сделок, % сроков с датой, % альтернатив, рецидив vs baseline, динамика к себе
- Уровень (г) отдел: системное vs личное, дисперсия важнее среднего, артефакты миграции, калибровка порогов раз в 2 нед, ноль флагов = проверка детектора

## Продающие факты из данных GENGROUP [ДАННЫЕ, phrasebook/defect-catalog]
- Из 631 обещания конкретную дату содержали 26 (4.1%)
- 956 вложений без сопроводительного текста (8.8% исходящих; у одного менеджера 52%)
- Альтернатива на возражение «дорого» - в 23% из 66; скидка упомянута 92 раза при ≤26 вопросах о бюджете
- 37% переписки - после предоплаты; все 16 эскалаций выросли там; ни одна не началась с сообщения менеджера; извинение первым ходом - 3 из 16

- Напрямую: D01-D14 (поля CRM, без текста)

- НОВОЕ (нет даже у Кости) = новизна продукта: КАЧЕСТВО отработки возражений, перевод фокуса, тон под претензию
- Звонки: Bitrix REST транскрипт не отдаёт - STT свой, либо честно «звонки по резюме»

## Где AI-судья наврёт (8 типовых ложных срабатываний)
Клиент сам пропал (нет поля «автор последней активности» - без него обвинение в бездействии недоказуемо); общение ушло в телефон/личку; чужой номер (прецедент: 228/650 сделок с активностью при нулевых касаниях); ниша меняет норму тишины; резюме чужого AI как факт; атрибуция автора (37008/37095 строк ошибочно помечены менеджером, 2985 - unknown); артефакты миграции (7997/9255 отказов - легаси); штампы, обязательные по регламенту ниши.

## Правила защиты (NEVER)
- Каждый флаг: метка уверенности (высокая/средняя/низкая) + цитата-доказательство + ссылка на сделку
- НИКОГДА «менеджер бездействовал» без знания, кто писал последним - только «нет ответа в ленте CRM за N дней»
- НИКОГДА персональное обвинение на 1 инциденте (≥2), индекс на <10 сделках
- «Нет данных» ≠ «нарушение» - отдельная корзина
- НИКОГДА вывод об увольнении/PIP - HITL
- Первые 2 недели у нового клиента - без вердиктов, только накопление
- Кнопка «оспорить» с ПЕРВОГО релиза, спор логируется в калибровку

## Формат планёрки
Костин каркас (светофор → топ-косяки с «как надо было» → что стало лучше → системные дефекты → нехватка данных) + колонка уверенности + строка «покрытие: N% коммуникаций в CRM» + «оспорить». Убрать: жаргон GG, чужие baseline.

## Архитектурное решение (ответ на атаку «у каждой ниши свои правила»)
Гипотеза Ивана подтверждается структурой каталога: T01-T09 - чистая дисциплина, ни один пункт не завязан на продукт компании.
- **Слой 1 «Дисциплина» - универсален, продаётся без адаптации**
- **Слой 2 «Техника» - требует онбординга из 5 параметров** (цикл решения, SLA/часы, каналы, торгуемость цены, триггеры эскалации ниши)
Продавать честно: слой 1 сразу, слой 2 после онбординга - внести в упаковку, не прятать.
