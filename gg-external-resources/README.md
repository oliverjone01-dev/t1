# Аналитика внешних ресурсов GENGROUP

Отдельный модуль монорепозитория: единый реестр и дашборд **внешних ресурсов**
GG - всего, что находится вне собственных сайтов холдинга и требует замера
присутствия и эффективности.

Владелец задачи: **Иван Раюшкин (CMO)**. Дисциплина цифр - **data** (Protocol 9).
Гейт перед публикацией - **feniks** (Step 12.5).

## Зачем отдельный модуль

Разные внешние каналы GG живут в разных проектах: OZON P&L - в `analytics-mvp/`,
органика и AI-видимость - в `gg-seo-geo-monster/`, соцсети - в `smm/`, платный
трафик - в `yandex-direct/`. Ни в одном месте нет **единой карты** всех внешних
точек присутствия с честной разметкой «есть данные / гипотеза». Этот модуль
собирает их в один реестр и показывает, где мы реально меряем эффект, а где пока
только план.

## Структура

```
gg-external-resources/
  README.md              # этот файл
  data/resources.json    # канонический реестр (машиночитаемый, под автоматизацию)
  public/index.html      # дашборд (self-contained, GENGROUP dark, готов к GitHub Pages)
```

## Категории внешних ресурсов

| Категория | Что входит | Статус замера |
|---|---|---|
| **Маркетплейсы** | OZON, WB, Яндекс.Маркет | OZON - живой P&L; WB/Маркет - план |
| **Платный трафик** | Яндекс.Директ (genglass, glass-memory), Метрика | genglass - живые цифры; GM - требует ре-выгрузки |
| **Площадки публикаций** | vc.ru, dzen.ru, dtf.ru | инструмент готов (forge.js), замера присутствия нет |
| **Соцсети / SMM** | VALONTI/TURBIUM (Instagram, Pinterest) | пилот, baseline не снят |
| **AI-видимость / GEO** | YandexGPT/Алиса, ChatGPT/Perplexity/Gemini | keys.so даёт AI-ответы; Share of Model - план |
| **Внешнее поле** | 19 конкурентных доменов (keys.so) | живой мониторинг |

## Дисциплина данных (Protocol 9)

Каждая метрика в реестре помечена:

- `kind: "data"` - есть живой источник в репозитории (путь указан в поле `source`);
- `kind: "hypo"` - выгрузки нет, значение `null`, в план и отчёты **не подавать**.

Hard rule: цифра без источника не идёт в Roadmap. Дашборд визуально разделяет
`[ДАННЫЕ]` (зелёный) и `[ГИПОТЕЗА]` (жёлтый).
