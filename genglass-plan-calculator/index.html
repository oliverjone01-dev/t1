02 · Из чего складывается план

Конструктор покрытия

Пять источников выручки плюс два разовых резерва пайплайна. Розничный вход считается из воронки, остальное - вилками из плана Романа. Смотри, тянет ли выбранная комбинация план из блока выше.

Розница · вход (воронка)

Перегородки, зеркала, платная реклама. Единственный источник с полной математикой воронки.
