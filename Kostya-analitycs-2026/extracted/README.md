# Машиночитаемые копии разборов Кости

**Файлы в этой папке не хранятся в git.** Внутри разборов Кости лежат именные
характеристики конкретных сотрудников. Репозиторий публичный, а плоский текст,
в отличие от docx, открывается в один клик и индексируется поиском по коду.

Генерируйте локально:

```bash
python3 Kostya-analitycs-2026/extracted/docx-to-md.py Kostya-analitycs-2026 Kostya-analitycs-2026/extracted
```

Скрипт распаковывает `word/document.xml` из соседних docx и сохраняет заголовки,
списки и таблицы. Зависимостей нет.

## Что учесть при работе с результатом

Имена файлов на выходе повторяют имена docx. Часть исходных имён в macOS-нормализации
NFD, из-за чего инструменты чтения по пути их не находят: переименуйте в латиницу.

Два разбора воронки содержат 39 скриншотов лент из amoCRM. Текст извлекается,
картинки нет.

Разборы GG ссылаются на `gengroup.amocrm.ru`, потому что писались до миграции.
Восьмизначные идентификаторы оттуда **не сшиваются** с Bitrix24: это legacy-ID
amoCRM. Все данные сейчас в Bitrix24, категория 49. Разбор поведения менеджеров
остаётся валидным, сквозная сверка по номеру сделки невозможна. Подробнее в
`knowledge/episodes/2026-06/kostya-analitycs-synthesis-20260630.md`.

Разборы Glass Memory уже ссылаются на `glassmemory.bitrix24.ru`.
