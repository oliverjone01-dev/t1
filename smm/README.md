# SMM-стратегия GENGROUP

Отдельный проект холдинга в общем монорепозитории. Изолирован по папке и по рабочей
сессии, но опирается на общую базу знаний GENGROUP в корне (`CLAUDE.md`, `knowledge/`,
`.claude/agents`, скиллы).

## Изоляция
- Работа ведётся в отдельной сессии Claude Code («работаем в smm/»), аналитику OZON не трогаем.
- Код проекта живёт только здесь, в `smm/`.
- База знаний и агенты - общие, из корня репозитория.

## Публикация
Сайт публикуется единым сборщиком `.github/workflows/deploy-pages.yml` (на репозиторий
один Pages-сайт, поэтому деплой общий, раскладка по подпапкам):
- бой: `https://oliverjone01-dev.github.io/t1/smm/` (из ветки `main`);
- превью: `https://oliverjone01-dev.github.io/t1/smm/preview/` (из рабочей ветки).

В `public/index.html` - финальный артефакт: SMM-стратегия Q3-Q4 2026 «Valonti by
GENGLASS» в формате премиального сайта (SF Pro Display, дизайн-система с разделением
двух движков светлая/тёмная зона).

## Как собрана стратегия
1. Council 5 ролей (MARCO, ROMAN, KREA, SEMYON, DATA) - параллельные дебаты.
2. Protocol 9 Reality Audit - маркировка цифр, 5 вопросов, hard rules. Вердикт: PILOT.
3. ФЕНИКС adversarial audit, итерация 1: 7.3/10 RETURN, 10 gaps, ТЗ блоки A-E.
4. Переработка v2: закрыты все gaps (capacity-расчёт, владельцы, P&L пилота,
   альтернативы, reversibility, bus-factor, метрики QDC, эскалация фантомного источника).
5. ФЕНИКС приёмка, итерация 2: 9.2/10 GO + 4 микро-правки до ~9.5.

## Ключевые ограничения (из аудита)
- Статус: PILOT, не «стратегия роста». Полная амплификация заблокирована до baseline.
- Все цифры экономики - [ГИПОТЕЗА] до сбора 6 выгрузок (Bitrix24/1С) и snapshot 8 аккаунтов.
- HITL Ивана обязателен: бюджет пилота (≤200K) и назначение владельцев движков.
- Открытый тикет вне SMM: фантомный источник `knowledge/semantic/sales-history-2018-2025.csv`
  отсутствует физически, но цитируется как [ДАННЫЕ c=1.0] семью файлами агентов/скиллов.
