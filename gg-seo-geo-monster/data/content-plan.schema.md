# Контракт единой Google-таблицы контент-плана

Одна таблица на все 5 брендов. Импорт в хаб идёт через CSV-экспорт вкладки
(auth не нужен, таблица открыта «Все, у кого есть ссылка → Читатель»), по образцу
`competitors-import.yml`. Ниже - контракт колонок. Порядок колонок можно менять,
имена заголовков - нет (импортёр читает по заголовку).

## Вкладка `clusters` (обязательная)

| Колонка | Тип | Обязательна | Пример | Заметка |
|---|---|---|---|---|
| `id` | slug | да | `peregorodki-steklo` | уникальный, латиница-дефис |
| `brand` | enum | да | `GENGLASS` | один из: GENGLASS, VALONTI, GENTERO, Metal-GM, GLASS-MEMORY |
| `pillar` | текст | да | `Стеклянные перегородки для квартиры` | заголовок кластера |
| `intent` | enum | да | `commercial` | `informational` / `commercial` / `transactional` |
| `satellites` | текст | нет | `перегородка кухня-гостиная; цена` | список через `;` |
| `priority` | int | нет | `1` | 1 = высший (GENGLASS-кластеры по умолчанию выше) |
| `status` | enum | да | `planned` | `planned` / `in_forge` / `review` / `published` |
| `assignee` | текст | нет | `София` | кто ведёт приёмку |
| `doc_url` | url | нет | `https://docs.google.com/document/d/...` | черновик статьи в Google Docs |
| `target_url` | url | нет | `genglass.ru/blog/steklyannye-peregorodki/` | боевой URL публикации |
| `updated` | дата | да | `2026-07-07` | YYYY-MM-DD, дата последнего изменения строки |

## Вкладка `citations` (обязательная, baseline AI-видимости)

| Колонка | Тип | Обязательна | Пример | Заметка |
|---|---|---|---|---|
| `query` | текст | да | `производитель стеклянных перегородок Москва` | целевой запрос |
| `brand` | enum | да | `GENGLASS` | как в `clusters.brand` |
| `measured` | дата | да | `2026-07-14` | дата замера. Пусто = НЕ измерено (не «ноль») |
| `chatgpt` | enum | нет | `yes` | `yes` / `no` / пусто(=не измерено) - цитирует ли бренд |
| `perplexity` | enum | нет | `no` | так же |
| `yandexgpt` | enum | нет | `yes` | так же |
| `gemini` | enum | нет | `` | так же |
| `source` | текст | да | `ручная проверка semyon` | откуда цифра (Protocol 9: без источника - не показывать) |

## Правила данных (Protocol 9)

- Пустое поле цитируемости значит «не измерено», а не «не цитируется». Хаб рисует
  такие ячейки серым «нет данных», не красным «ноль».
- Каждая строка `citations` без `measured` + `source` в хаб не попадает (блок).
- Прогнозные цифры («вырастем на N%») в таблицу контент-плана не кладём - это план
  публикаций и замеры, не форкаст.
