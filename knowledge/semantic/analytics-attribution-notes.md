## Изоляция кабинета Директа e-20085264 от abdm (программатик) — МЕТОД

**Проблема:** `ym:s:trafficSource=='ad'` и любой UTM-срез тащат **abdm** (программатик-подрядчик, utm_source=abdm/abdm_*). За 30д (июнь-июль 2026) abdm давал ~28 царь-целей / 3349 визитов — БОЛЬШЕ, чем сам кабинет. abdm — НЕ кабинет (P0).

**Как считать ТОЛЬКО кабинет:**
1. **Директ API** — эталон. Токен = аккаунт e-20085264, abdm физически не попадает. За 30д: LSC=23, AUTO=25 конверсий по 487033158.
2. **Метрика нативно:** фильтр `ym:s:directClickOrder!n` (кампании линкованного аккаунта, НЕ UTM). За 30д: last-touch=50, ассист=54.
3. **НИКОГДА** не брать `trafficSource=ad` или `utm_source` в лоб для «Директа» — там abdm.

**Ассист-эффект кабинета:** «все, кто касался Директа» (`EXISTS ym:u:userID WITH (ym:s:directClickOrder!n)`) = 54 vs last-touch 50 = **+8%** (возвраты через бренд/органику). Вклад кабинета занижен в last-touch на ~8% + чат-Битрикс сверху.

**Расхождение Директ-API (25) vs Метрика-нативно (50):** движок + окно атрибуции (Директ 21 день, строже). Для «сколько дал кабинет» — Директ-API; для полного вклада с ассистами — Метрика-нативно.
