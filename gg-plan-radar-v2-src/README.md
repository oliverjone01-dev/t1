# План-Радар v2 - исходник (не деплоится)

Исходник простой версии калькулятора плана с данными по менеджерам.
На GitHub Pages уходит ТОЛЬКО запечатанная копия
(`genglass-plan-calculator/v2/index.html`): payload зашифрован
AES-256-GCM по механике академии (`.claude/skills/kostya-ai/scripts/seal.mjs`,
шаблон `gate.html`) - решение Ивана от 08.08.2026 о публикации контуров
с персональными данными только запечатанными.

Пересборка после правок исходника:

    node gg-plan-radar-v2-src/build-sealed.mjs "<пароль>"

Пароль выдаёт Иван / РОП. Смена пароля = пересборка.
