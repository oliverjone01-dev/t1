## 4. ЧТО НЕ ДЕЛАЕМ СОЗНАТЕЛЬНО (чтобы команда не растеклась)

Полноценный водопад M4/M5 - это P1, не в этом спринте (требует операционку 2.1/2.2 для честности). В v2 ограничиваемся: оценка M5 показывается только если есть обе плашки, иначе не показываем.
3. **НЕ строим seller-URL карточки по product_id** - такого честного паттерна нет (offer_id в истории null). Где нет offer - ведём на публичную карточку OZON по числовому sku. Не выдумываем кабинетный диплинк.
4. **НЕ переписываем движок периодов** под мобайл целиком. Обзор = mobile-first (KPI без скролла), остальные страницы = десктоп + скролл-обёртки таблиц. Полная мобильная переверстка матрицы/BCG/хитмапа - НЕ в этом спринте (это P2 UX, токены Orbi сохраняем, переверстка ядра аналитики - отдельная работа).
5. **НЕ чиним payout-gap и ordered/accrued в коде** - это операционка (раздел 2). Код только честно подписывает сноской.
6. **НЕ убираем** автодетект нарушения позиционирования (VIOLUR-плашку на marketing) - маскируем СЛОВО в публичном HTML, но агрегат-предупреждение «N позиций скрытой линии» остаётся (бизнес-логика Ивана).
7. **НЕ вводим P2** (сквозной SKU-дрилл, достоверный ДРР по линиям, возвраты в деньгах, двойной счёт Акта) - отдельный цикл после приёмки v2.
