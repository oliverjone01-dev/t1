# /phoenix - Перегородки: разбор направления

Лендинг-отчёт по ключевому направлению GENGLASS. Публикуется на GitHub Pages по адресу
`/t1/phoenix/`, ссылка стоит в хабе GEO-MONSTER.

## Стек

React 18 + TypeScript + Vite. Ни одной библиотеки графиков и анимаций: все десять
диаграмм нарисованы вручную в SVG, движение сделано на CSS-переходах и одном общем
`IntersectionObserver`. Так проще держать единый визуальный язык и не тащить 200 КБ
чужих стилей ради семи полосок.

Шрифты (Playfair Display и Golos Text, оба с кириллицей) лежат в `public/fonts`:
ни одного внешнего запроса, страница открывается полностью на своём хостинге.

## Где что лежит

- `src/data.ts` - все цифры отчёта с метками `ДАННЫЕ` и `ГИПОТЕЗА`. Единственное место,
  которое правится при обновлении замера.
- `src/charts.tsx` - девять диаграмм.
- `src/sections.tsx` - разделы отчёта и тексты.
- `src/styles.css` - палитра и типографика, светлая и тёмная темы.
- `src/lib.tsx` - появление при прокрутке, счётчики, русские окончания, шкалы.

## Сборка

```
cd phoenix
npm install
npm run build      # результат в phoenix/dist
```

`phoenix/dist` коммитится в git намеренно: деплой Pages не должен зависеть от
доступности npm в CI. После правки исходников обязательно пересобрать и закоммитить dist.

## Доступ: чего заглушка НЕ делает

На странице стоит парольная заглушка и `noindex`. Пароль тот же, что у хаба GEO-MONSTER,
на деплое хэш подменяется из секрета `HUB_PASS`.

**Содержимое она не защищает.** Репозиторий `oliverjone01-dev/t1` публичный, поэтому
`phoenix/src/data.ts` и собранный бандл `phoenix/dist/a/*.js` открываются по прямой ссылке
на github.com и raw.githubusercontent.com без всякого пароля. Внутри бандла весь отчёт
лежит открытым текстом: расход, цены, число заявок. Заглушка стоит перед контентом,
который к тому моменту уже загружен в браузер, а `noindex` в `index.html` на `.js` не
распространяется и заголовков ответа на GitHub Pages не задать.

Формально это свойство не лендинга, а всего репозитория: `gg-seo-geo-monster/data` и
текстовый отчёт в том же положении. Но написать «защищено» было бы неправдой, поэтому
записано как есть.

Что с этим делать - решение Ивана. Варианты, в порядке цены:
1. Сделать репозиторий приватным. На бесплатном тарифе это выключит GitHub Pages целиком,
   то есть уронит и хаб, и все дашборды. Нужен платный тариф.
2. Вынести цифры из бандла в отдельный `data.json`, шифруемый на деплое паролем.
   Тогда без пароля страница пустая, а в git лежит шифротекст.
3. Оставить как есть, признав, что данные по перегородкам не являются секретом.
