Юнит-экономика рекламы: ДРР vs безубыток
безубыточная ДРР = 100% − все сборы OZON (комиссия+логистика+эквайринг+хранение, из payout) − себестоимость. Запас = безубыток − факт ДРР. Решение: 🟢 запас ≥30% безубытка · 🟡 0…30% · 🔴 <0. SKU агрегирован по всем кампаниям. Таблица - по данным Performance API (снимок/живой запрос).
