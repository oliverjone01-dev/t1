# Контур: инструкции для работы в этой папке

Читается вместе с корневым `CLAUDE.md` репозитория. Здесь только то, что
специфично для дашборда.

## Порядок работы

Никогда не правь `public/index.html` руками. Это результат сборки, его перезапишет
следующий `src/build.py`. Правки идут в `src/modules/*.py`, данные в
`tools/build_data.py`.

После любой правки:

```bash
python3 tools/build_data.py && python3 src/build.py
python3 tools/check_dash.py && python3 ../kontur-ds/tools/check_ds.py public/index.html
node tools/smoke.mjs && node tools/contrast.mjs && node tools/seal_test.mjs && node tools/text_scan.mjs
```

Сборка без зелёного сторожа и дымового теста не считается сделанной.

## Жёсткие правила

1. **Протокол 9 на каждой цифре.** Класс `ДАННЫЕ`, `ГИПОТЕЗА` или `ДЕМО`, источник,
   дата съёма. Выгрузки нет, значит `v: null` и класс `ДЕМО`. Правдоподобное число
   вместо прочерка запрещено.
2. **Ни одного длинного тире.** Только дефис. Ловится сторожем.
3. **Вид только из Контур DS 1.5** (`kontur-ds/` в корне репозитория). Цвета,
   шрифт, отступы и компоненты берутся из пакета: токены `tokens.css`, кит `KS.*`,
   графики пресетами `KS.charts` по слотам `--cat-1..5`. Своих hex в модулях нет,
   прозрачность на тексте запрещена (приглушённый текст это класс `ks-muted`).
   Пакет здесь не правится: новая версия кладётся в `kontur-ds/` целиком.
4. **Две оси Y на одном графике запрещены.** Разные по величине ряды приводятся
   к индексу: первая точка периода это 100.
5. **У каждого графика таблица-двойник.**
6. **Ни одна рекламная кампания не запускается и не пополняется** без прямого
   подтверждения Ивана, что бы ни показывал экран.
7. **Пропущенный съём позиций восстанавливается только из истории выгрузок.**
   `snapshot.py --backfill` берёт точку из keysso.json, закоммиченного в тот день.
   Дня без выгрузки в git не вернуть ничем. Если `snapshot.py --check` ругается на
   разрыв, это не повод его заглушить.

## Чего не делать

- Не подставлять «примерно такие» числа, чтобы график выглядел полнее.
- Не сглаживать аномалии в ряду. Скачок видимости с 37 до 17 остаётся как есть,
  рядом с ним стоит предупреждение.
- Не выводить оценку трафика от keys.so: при 547 запросах в топ-50 она показывает
  около двух визитов. Визиты берутся только из Метрики.
- Не смешивать брендовые кампании Директа с остальными в одной средней.
- Не добавлять внешние библиотеки: разрешены только пакет Контур DS (вшивается в
  страницу при сборке), ApexCharts с cdnjs и шрифт Golos Text с Google Fonts.
  Tailwind больше не подключается.

## Где что лежит

`src/modules/` собирается в `public/index.html`. Разбивка по файлам в
`docs/ARCHITECTURE.md`, формат данных в `docs/DATA_CONTRACT.md`, регламент
обновления и разбор ошибок сторожа в `docs/RUNBOOK.md`.
