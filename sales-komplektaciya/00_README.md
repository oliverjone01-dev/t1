## Проверка качества

- Адверсариальный аудит ФЕНИКСА (Step 12.5): раунд 1 - RETURN 6.4/10 (имена клиентов, гарантия, «своё стекло», сроки партий, регионы); раунд 2 - RETURN 7.7/10, в выборке из 29 писем 0 выдуманных фактов, остались механические правки (срок консолей 20-30, White Label вне К2/К3/К7, дубли адресатов, устаревшие поводы №22 и №125, AB Motors к 03.10). Все правки раунда 2 внесены. Раунд 3 - GO 8.4/10, 5 мелочей закрыты. GO относится к текстам: рассылка ждёт решений Ивана и РОПа из шага 4 (HITL перед публичной коммуникацией).
- Каждое письмо прошло автопроверку: без длинного тире, без запрещённых слов, тема до 60 знаков, тело 80-128 слов, без имён клиентов, без «гарантия 12 месяцев».
- Флаги в письмах - не мусор: «факт не перепроверен» означает, что факт взят из сигнала базы без повторной проверки. Такие письма перед отправкой открыть по ссылке из колонки K.
