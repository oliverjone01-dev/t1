## Живые fetch в браузере (инвентаризация для Этапа 3, G6)

6 точек в `build-katya.ts`:
- Маркетинг: `ADS_URL` (кампании за период), `PSK_URL` (комиссия), per-SKU отчёт (lazy, report-mode).
- Деньги: `PNL_URL`, `PSK_URL`.
- Командный центр: `CC_ADS_URL` (общий ДРР).
- Гуру: `GURU_URL` (ИИ-чат).

Живой запрос уточняет снимок под ТОЧНЫЙ период. Снимок есть только для фиксированных 7/30/90.
**Перед снятием live-fetch:** либо запечь все выбираемые периоды, либо урезать выбор до 7/30/90.
Иначе кастомный период покажет данные не за то окно (тихо). Гуру — отдельное решение (Protocol 6).
