# Мой отдельный проект

Изолированное рабочее пространство на ветке `claude/isolated-project-shared-access-26ucxn`.

## Как это устроено

- Ветка создана от актуального `main`, поэтому все общие файлы холдинга доступны как обычно: `CLAUDE.md`, `knowledge/`, `glossary.md`, `schemas/`, `.claude/agents/`, `.claude/skills/`, `analytics-mvp/` и остальное.
- Все файлы этого проекта живут только внутри папки `my-project/`. Общие файлы не трогаем, поэтому ветка не будет конфликтовать с `main`.
- Пока ветка не смержена, наработки проекта не попадают в `main` и не видны другим веткам.

## Структура

| Папка | Назначение |
|---|---|
| `docs/` | Документы, заметки, ТЗ проекта |
| `data/` | Данные и выгрузки проекта |
| `src/` | Код, скрипты, артефакты |

## Как подтянуть свежие общие файлы из main

```bash
git fetch origin main
git merge origin/main
```

Конфликтов не будет, пока изменения проекта остаются внутри `my-project/`.

## Правила

1. Новые файлы проекта кладём только внутрь `my-project/`.
2. Правки общих файлов (CLAUDE.md, knowledge/, схемы) делаем отдельным коммитом в `main` через обычный процесс, не в этой ветке.
3. Протоколы системы (P9 Reality Audit, Step 12.5 ФЕНИКС) действуют и здесь: ветка изолирует файлы, а не правила.
