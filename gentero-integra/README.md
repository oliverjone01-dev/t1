# ИНТЕГРА 2.0 - план GENTERO

Внутренний документ для обсуждения собственников (Богдан + Роман). Одностраничный
офлайн-лендинг: ноль внешних запросов, все стили и скрипты внутри файла.

## Что где

| Путь | Что это |
|---|---|
| `public/index.html` | Единственный артефакт. Самодостаточная HTML-страница |

## Где опубликовано

https://oliverjone01-dev.github.io/t1/integra/

Схема как у дашбордов `/rop/`, `/office/`, `/messages/`: в main лежит только блок
сборки в `.github/workflows/deploy-pages.yml` (PR #188), а содержимое тянется
отсюда, из ветки `claude/gentero-plan-03609o`. Сама ветка в main не вливается.

Окружение `github-pages` принимает деплой исключительно с main, поэтому запустить
публикацию с рабочей ветки нельзя: джоб отбивается protection rules за пару секунд,
без назначения раннера и без логов.

## Как править

Документ зашифрован: в `public/index.html` лежит не текст, а шифротекст под
паролем. Прямо в файле его редактировать нельзя.

Цикл правки:

```bash
cd gentero-integra
node build-gate.js unlock public/index.html /tmp/plain.html '<пароль>'
#   правим /tmp/plain.html
node build-gate.js lock /tmp/plain.html public/index.html '<пароль>'
```

Открытый текст в репозиторий не коммитится. Восстановить его можно только
паролем, из самого `public/index.html`.

Правка попадает на сайт очередным деплоем `deploy-pages.yml`. Он запускается при
push в main, после ночного синка снимков OZON и Директа, либо вручную через
workflow_dispatch на main. Повторно менять main под каждую правку не нужно.

## Что защищает пароль, а что нет

Защищает: опубликованную страницу и её исходный код. Без пароля из файла нельзя
достать ни строки, шифрование AES-GCM 256, ключ из пароля через PBKDF2-SHA256,
250 000 итераций, расшифровка в браузере через WebCrypto.

**Не защищает историю git.** Ветка публичная, и в её прошлых коммитах открытый
текст документа лежит как есть. Чтобы закрыть и это, нужна перезапись истории
ветки, она не сделана.

**Пароль короткий.** Шесть знаков известного вида перебираются офлайн, если у
кого-то есть файл. Против пересланной ссылки работает, против целенаправленного
подбора нет.


## Содержание документа

Семь блоков: hero, «Почему сейчас» (4 факта), пакет «Фурнитура под ключ» (5 частей),
«Сайт в столе» (3 проверки + 3 варианта сделки), механика продаж (4 ступени + 5 правил
безопасности), этапы и деньги (5 этапов + таблица), FAQ (6 вопросов), CTA «Три решения».

## Статус

Черновик к обсуждению. Цифры в разделе «Этапы и деньги» перед вынесением на встречу
собственников проходят Protocol 9 (Reality Audit) и адверсариальный гейт ФЕНИКСА -
Step 12.5. Пока такой аудит не проведён, суммы в таблице считаются гипотезами.
