# dealer-landing-gm

Адаптивный лендинг дилера GLASS-MEMORY. Источник — утверждённые рабочие Desktop1440 и Mobile390 в [Figma](https://www.figma.com/design/edstCkelj8saysC4i7V03K?node-id=18-156), итерация v7 от 11 ноября2026, включая комментарии №60–62.

Статический HTML/CSS/JavaScript без сборки и внешних зависимостей. Запуск: `python3 -m http.server 8080`, затем открыть `http://localhost:8080/`.

GitHub Pages: `/t1/dealer-landing-gm/`. Проект добавляется в существующую общую сборку `.github/workflows/deploy-pages.yml`.

Телефон и контакты мессенджеров — шаблоны. Форма проверяет телефон/email и согласие, подготавливает текст запроса и позволяет скачать его. Данные никуда не отправляются и не сохраняются на сервере. Для рабочего приёма заявок нужны реальные контакты дилера и подключённый обработчик.

Медиа перенесены из актуального макета, включая многослойный hero с неподвижным передним планом, горизонтальный стеклянный цветник и новую вертикальную схему триплекса. Интерфейс остаётся текстом и разметкой, а не скриншотом страницы.

`noindex,nofollow` сохранён для демонстрационной публикации. Аналитика и внешние шрифты не подключены; Manrope хранится локально.
