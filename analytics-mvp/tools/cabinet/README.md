# Штатные отчёты кабинета GENGLASS

Этот адаптер публикует отдельный оперативный блок на `katya-voronka.html`.
Он не заменяет ряды Seller/Performance API, `reakciya.json`, цены или денежные расчёты.

Контракт v1: один день отчёта, компания GENGLASS, Europe/Moscow; сегодняшний
день неполный. Ключ строки: SKU + схема, ключ снимка: день + фаза
(`утро`, `вечер`, `once`). Повтор идемпотентен; уменьшение измеренного набора
того же снимка запрещено. Отсутствующая строка не означает нулевое значение.

Источник: штатный XLSX «Отчёт по дням», группировка по товарам. Поля отчёта
Q/S/W/AA/AC/P: показы всего, показы поиска/каталога, посещения карточки,
добавления в корзину, заказано штук, позиция поиска. Это наблюдаемые поля
отчёта, без расчёта конверсии, выручки, прибыли или рекламной атрибуции.
Суммы пяти счётчиков должны совпадать с итоговой строкой XLSX.

Ожидаемый список: полный свежий каталог всех статусов (количество сверяется
с интерфейсом) + SKU из последних 14 дней старых выгрузок и предыдущих
снимков. Полученные, совпавшие, пропущенные и дополнительные SKU показываются
отдельно. Неполный отчёт можно опубликовать только с явным охватом.

`prepare.py` принимает два свежих XLSX, видимое количество каталога, день,
время формирования отчёта с зоной и предыдущий публичный JSON из main.
Снимок старше трёх часов, другая компания/дата, повторные ключи,
неполный каталог, несходящиеся итоги и нечисловые значения блокируют пакет.
`prepared/` устанавливается атомарно после всех проверок. `manifest.json`
и `READY.json` остаются локальными. Публикуется только
`analytics-mvp/data/cabinet_capture.json` после строгого TS-валидатора,
предварительной сборки и smoke. При конфликте main пакет собирают заново
из последнего файла, а не затирают чужие снимки.

Цены, цена по карте, соинвест, компоненты бустинга, фактические тарифы FBS,
CPO, группы карточек и список конкурентов этим адаптером не обновляются.
Выгрузки этих семейств можно архивировать, но нельзя выдавать их за
проверенную замену старых данных. Нулевые K–N в шаблоне цен не являются
воронкой, вторая цена интерфейса не является ценой по карте.

Проверки: `python3 -B -m unittest discover -s tools/cabinet -p 'test_*.py'`
и `vitest run src/scripts/ozon/cabinet-capture.test.ts`.
Доступ, навигация, скачивание и расписание исполняются агентом во встроенном
браузере по локальному RUNBOOK.md; этот модуль не хранит сессию или секреты.
