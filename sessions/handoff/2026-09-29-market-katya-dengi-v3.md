сходятся с закрывающими документами Маркета и ручной ведомостью доставки. Готово = Катя проверила
и дала «мерж».

## 2. Сделано
- PR #424 (смержен, 77af9ae): в ведомости доставки исключается только ОТМЕНЕН. Куда ложится
  перевозка, решает статус заказа у Маркета: доставлен - все отправки (и возвратные) на заказ;
  отменён/возвращён Маркетом - в ship_lost. 7 заказов (51 046 ₽) вернулись в строки, в т.ч.

  артикула, если его нет в таксономии: GGT - Столы, GGL/GGM - Зеркала, GGK - Консоли/тумбы,
  GGTP - Комплектующие. Только Маркет (IS_OZON -> null). Блок «Без категории» в своде пуст
  (было 11). Плюс две строки в knowledge/decisions.md и трейсы. Тесты ym 379/379, ym:build ок.

## 3. Решения и почему
- Ведомость: только ОТМЕНЕН исключается, возвраты учитываются (Катя 29.09). Правило «одна
  отправка в возврате - весь заказ в отменённые» было выдумано в коде (#372) - снято.
- Категории по префиксу - после таксономии, перед «Без категории»; названия как в таксономии
  («Консоли/тумбы», не «Консоли»), чтобы не плодить вторую строку.
- Из v2 в силе: блок «за выбранный период» только деньги; фиолетовым только оценки сборов по
  заказам в пути; «Товары» и OZON не трогать; только `npm run ym:build`; мерж только по слову Кати;
  по ФЕНИКСУ ничего не дорабатывать без её согласия.
- НЕ ДОДУМЫВАТЬ ПРАВИЛА ЗА КАТЮ: Катя резко отреагировала на выдуманное правило. Любое новое
  правило расчёта - только её словами; её формулировку не пересказывать своими.
