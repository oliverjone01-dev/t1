# Выгрузки OZON по заказам в Excel (Иван 30.09)

Числа снимаются с собранной страницы `public/katya-money.html` (как на экране), поэтому сначала `npm run katya`.

1. `playwright-core` в проекте нет: поставить во временную папку (`npm i playwright-core` там), браузер `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
2. `OUT=<папка>/ordan.json node ozon_orders_extract.cjs 2026-07 2026-08` (запускать из папки, где стоит playwright-core; путь к странице в скрипте абсолютный). Период применяется кнопкой `range-apply`.
3. `python3 ozon_orders_xlsx.py <папка>` - два файла: `ozon_analitika_po_zakazam_*.xlsx` и `ozon_logistika_po_zakazam_*.xlsx`, месяц на лист.

Формат: шапка аналитики - Заказ, Дата, Тип доставки, Город (ведомость), Категория, Артикул, далее колонки страницы «Заказано»...«Рентаб.»; статус в скобках в колонке «Заказ»; расчётные ячейки фиолетовым курсивом; внизу «Общие расходы» и ИТОГО. Логистика - колонки как в выгрузке 22.09 (Заказ (постинг) ... Нетто нашей доставки). Отправления одного заказа - отдельными строками (Иван 30.09: не объединять).
Проверка: строки + «Общие расходы» = ИТОГО страницы по каждой колонке. Файлы в git не класть (адреса).
