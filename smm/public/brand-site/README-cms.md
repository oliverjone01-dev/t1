# Контент-система GENGROUP - связка с Google-таблицей

Рубрикатор и контент-план на сайте (`content.html`, `plan.html`) тянутся из
Google-таблицы, которую ведёт SMM. Меняете в таблице → на сайте обновляется при
следующей загрузке. Пока таблица не подключена, сайт работает на резервных данных
(`cms-seed.js`) и честно показывает плашку «резервные данные».

## Как это работает

- Сайт читает таблицу через публичный gviz-эндпоинт Google (без бэкенда, без
  ключей). Нужен только доступ «у кого есть ссылка - Читатель».
- Каждая вкладка тянется отдельно: если одну переименовали или закрыли - резерв
  подменит только её, остальное останется живым.
- Кэш Google ~ минуты: правка появляется на сайте через короткое время / на
  следующей загрузке, не мгновенно. Это нормально для рабочего инструмента.

## Подключение (один раз)

1. Создать Google-таблицу с двумя вкладками: **`Рубрикатор`** и **`Контент-план`**
   (имена вкладок важны: регистр и дефис как здесь. Все колонки держите в
   **текстовом** формате, иначе число/дата исказятся при чтении).
2. Доступ: «Настройки доступа» → «Все, у кого есть ссылка» → **Читатель**.
3. Скопировать ID из URL таблицы:
   `docs.google.com/spreadsheets/d/`**`<ЭТОТ_ID>`**`/edit`
4. Вставить ID в `cms-config.js` → `sheetId`. Шаг с push в репозиторий делает
   технический человек один раз (SMM сам git не трогает). Готово.

### ⚠️ Приватность - прочитать перед заполнением

Этот сайт хостится открыто на GitHub Pages, и `sheetId` лежит в его исходнике.
То есть **любой, кто откроет страницу, может прочитать весь контент-план** через
тот же gviz: неопубликованные идеи, хуки, ответственных, ссылки. Это нормально
для рабочего плана, но **не кладите в таблицу чувствительное**: цены, перс.
данные, коммерческие даты запусков. Если план должен быть закрытым - gviz не
подходит, нужен приватный бэкенд с авторизацией (отдельная задача под Ивана).

## Вкладка «Рубрикатор» - колонки (первая строка = заголовки)

| бренд | рубрика | формат | канал | задача | частота | kpi | активна |
|-------|---------|--------|-------|--------|---------|-----|---------|

- **бренд**: `G` (или GENGLASS) / `V` (или VALONTI).
- **активна**: `да` / `нет` (нет = рубрика на паузе, видна приглушённой).

## Вкладка «Контент-план» - колонки

Базовые:

| id | неделя | слот | бренд | канал | формат | рубрика | идея | хук | цель | статус | ссылка | ответственный | ситуатив |
|----|--------|------|-------|-------|--------|---------|------|-----|------|--------|--------|---------------|----------|

Тело поста (для модалки по клику на карточку), добавить в те же строки справа:

| картинка | текст | тип медиа | alt | дата публикации | доп ссылка |
|----------|-------|-----------|-----|-----------------|------------|

- **id**: уникальный и **стабильный** (например `w1-mon-g`). К нему привязаны
  комментарии и статистика - не переиспользуйте id между разными постами.
- **статус**: `в плане` / `на согл` / `опубликовано`. Пайплайн слева направо.
  Поставьте на колонку выпадающий список (Данные -> Проверка данных), чтобы не
  было опечаток. Синонимы `готово` тоже читаются как «на согл».
- **ссылка**: URL поста. Если статус «опубликовано» и есть ссылка - на карточке
  появляется кнопка «Открыть пост».
- **ситуатив**: `да` - слот-резерв, не считается в «выполнение плана».
- **картинка**: публичная ссылка или Google Drive (Доступ -> «Все со ссылкой» ->
  Просмотр). Сжимается автоматически, показывается обложкой.
- **текст**: текст поста как в соцсети - эмодзи, #хэштеги в конце, перенос строки
  `Alt+Enter`. В карточке показываем «как в ленте».
- **тип медиа**: `image` / `video` / `carousel`. **alt**: описание картинки (a11y).
- **дата публикации**: дата факта публикации. **доп ссылка**: вторая ссылка.

## Вкладка «Статистика» (имя ровно так) - для KPI

Одна строка = один снэпшот метрик поста. Джойн с планом по `id`.

| id | охват | сохранения | переходы | контакты | снэпшот тип | снэпшот дата |
|----|-------|------------|----------|----------|-------------|--------------|

- **снэпшот тип**: `7d` (основной, по нему считается KPI) или `48h` (опционально).
- Снимаем **через 7 дней** после публикации (48ч ловит первый всплеск, 7д - хвост).
- **контакты** - главная метрика VALONTI (переход в личку / заявка / запрос прайса),
  не сохранения и не подписки. Для GENGLASS главное - **охват** и **сохранения**.
- В дашборде Ромы агрегаты: VALONTI контактов, контактов/пост, GENGLASS охват, ER.
- Назначьте ответственного за занос + напоминание на +7 дней, иначе снэпшот
  деградирует. Позже автоматизируется через n8n (метрики из API в эту же вкладку).

## Что видно на сайте

- **content.html** - рубрикатор карточками (GENGLASS серо-голубой, VALONTI золото).
- **plan.html** / **plan-hybrid.html** - сводка для контроля (РОМА): сколько в плане /
  на согл / опубликовано, процент выполнения, по брендам, результаты 7д. Ниже - посты
  таблицей или плитками, по клику открывается тело поста с превью и комментами.
- На карточку поста можно оставить комментарий (открыть -> «Комментировать»).
  Комментарий держится за `id` поста.
