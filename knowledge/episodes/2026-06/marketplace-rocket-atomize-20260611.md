## БЛОК 1. Что OZON API даёт и что мы НЕ реализовали

### Что тянем сейчас [ДАННЫЕ, проверено по снимкам data/]
- **Товары/воронка** (`/v1/analytics/data`): выручка, заказы, показы, в корзину, доставлено, возвраты, отмены, по дням и SKU.
- **Реклама** (Performance API): расход, показы, клики, заказы, выручка с рекламы → ДРР/CPO/ROAS по кампаниям и линиям.
- **Финансы** (`/v3/finance/transaction`): комиссия, логистика, услуги, к выплате.
- **Карточка-снимок**: остаток, индекс цены (pidx), флаг OOS, конверсии, средний чек.

### Критично НЕ реализовано - КАНДИДАТЫ, доступность через API НЕ проверена

> Важно: ниже все endpoint'ы помечены [ГИПОТЕЗА: доступность не проверена]. Часть данных OZON отдаёт только в кабинете (Premium-аналитика) и НЕ через Seller API, либо с ограничениями. Поэтому первый шаг по каждому пункту - PoC проверки доступности, и только потом обещание эффекта.

**P1 - Видимость в поиске [ГИПОТЕЗА: доступность не проверена].**
Гипотеза: OZON даёт поисковые запросы и позиции (Premium «Что ищут покупатели» / возможно `analytics` с измерением фраз). Мы не тянем ничего про запросы. Если доступно - увидим, по каким словам нас находят и на какой позиции. Сейчас «показы упали на 16%» в Гуру - симптом без диагноза. **Задача: PoC доступности данных по запросам, потом оценка эффекта.**

**P1 - Конкуренты и доля рынка [ГИПОТЕЗА: доступность не проверена] (проигнорировано полностью).**
Сейчас используем только pidx (дешевле/дороже рынка) как счётчик. Гипотеза: OZON в кабинете/Premium даёт среднюю цену категории, число продавцов на SKU, топ-выдачу по запросу, долю бренда. ВАЖНО: «доля бренда в категории» и «цена конкретного конкурента во времени» через открытый Seller API, скорее всего, НЕ отдаются - это Premium-аналитика с ограничениями. **Задача: PoC - что реально достаётся через API vs только парсером выдачи. Без подтверждения доступности - эффект не обещаем.**

**P1 - Оборачиваемость / days-of-supply [ГИПОТЕЗА: доступность не проверена].**
Гипотеза: `/v1/analytics/stock_on_warehouses` даёт остатки по складам. Сейчас только статичный stock и флаг OOS, нет «дней до OOS». Если доступно - упреждающий алёрт до ухода локомотива в ноль.

**P2 - Возвраты с причинами и отзывы/рейтинг [ГИПОТЕЗА: доступность не проверена].**
Гипотеза: `/v1/returns` с причиной, `/v1/review` + контент-рейтинг. Сейчас тянем только count возвратов. Причина «брак» (производство) vs «не подошло» (карточка) - разным людям разные задачи.

**P3 - Акции/контент-рейтинг** (`/v1/actions`, `/v1/product/rating`) [ГИПОТЕЗА: доступность не проверена].

### Вывод блока 1
Дашборд силён в «что уже продали», слеп в «почему нас находят/не находят» и «что делают конкуренты». Это две слепые зоны. НО прежде чем строить страницы - PoC доступности каждого источника через API: часть данных OZON через Seller API не отдаёт, и обещать эффект до проверки нельзя.

## БЛОК 2. Импорт из v57: матрица ABC×XYZ (исправлено по аудиту)

**Контекст бага в нашей версии [ДАННЫЕ, метод воспроизводим].**
- XYZ классифицировался по абсолютным порогам cv<0.10/0.25. На разреженных данных МП почти все модели с реальной вариативностью имеют cv>0.25 → валятся в Z, колонки X/Y пустые.
- Точный срез для воспроизведения: модели с продажами, у которых >=2 ненулевых месяца (cv считается только тогда). Команда расчёта - в коде генератора (`build-katya.ts`, функция `cv`).

**Первая попытка фикса была неверной (это поймал ФЕНИКС, исправлено).**
- Наивный порт v57 (перцентили по ВСЕМ моделям) дал X=113 - но 108 из них это модели с ОДНИМ месяцем продаж (cv=0). Болезнь переехала из Z в X: X наполнился не «стабильными», а «разовыми/новыми». Это была ложная победа.

**Правильный фикс [ДАННЫЕ, воспроизведено в jsdom на боевой сборке].**
- Модели с cv=0 (меньше 2 месяцев данных - о стабильности судить нельзя) ИСКЛЮЧАЕМ из матрицы.
- Перцентили p33/p67 считаем только по моделям с реальной вариативностью (cv>0).
- Результат: из 244 моделей **113 исключено** (cv=0, нет 2 месяцев), в матрице **131 модель → X=46 / Y=43 / Z=42**. Это честная треть/треть/треть по тем, кого вообще можно классифицировать.
- Наше преимущество над v57: у Кати cv из синтетического шума, у нас - из реальных помесячных продаж.

**Открытая честность:** 113 исключённых моделей - это «новинки/разовые», им нужен отдельный сегмент в UI (сейчас просто не попадают в матрицу). Кандидат на следующую итерацию.
