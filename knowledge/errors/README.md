# Реестр ошибок работы с цифрами

`registry.jsonl`: одна строка = один класс ошибки (К1-К14) с симптомом, корнем, правилом, автоматической проверкой и доказательствами (коммиты, файлы). Обезличено: без фамилий, телефонов, email, номеров заказов.

Создан 29.09.2026 из ретро 337 переделок в 9 чатах аналитики (ОЗОН v1-v3, ЯМ v1-v2, РОП ГГ, Я.Директ, Дашборды GENGROUP). Пополняется на шаге 8 скилла `data-guard` в конце задачи; лестница эскалации и формат: `.claude/skills/data-guard/references/retro.md`.

Использование:
- `python3 .claude/skills/data-guard/scripts/registry_match.py "<задача>"` - похожие прошлые ошибки (pre-mortem);
- `python3 .claude/skills/data-guard/scripts/registry_match.py --validate` - проверка формата и отсутствия персональных данных;
- хук `data-guard` сам показывает 3 похожие ошибки, когда сообщение похоже на работу с цифрами.

Разбор реестра раз в месяц в `/reflexion`: записи без срабатываний 3 месяца объединяются или удаляются.
