# Приёмник для новой версии из Claude Design

Сюда кладётся то, что вернулось из Claude Design. Ничего отсюда не
публикуется автоматически: я забираю файлы, разбираю, собираю обратно в
`public/index.html` и шифрую. Прямой заливки в прод из этой папки нет.

## Что и куда

| Что | Куда | Имя |
|---|---|---|
| Шаблон целиком, один HTML | `inbox/` | `new-template.html` |
| Только CSS, если отдали отдельно | `inbox/` | `new-styles.css` |
| Только разметка тела, если отдали отдельно | `inbox/` | `new-body.html` |
| Фрагмент для `initDoc()`, если он есть | `inbox/` | `new-init.js` |
| Новые или пересобранные картинки | `inbox/img/` | имя из списка ниже |
| Ответ модели целиком (таблицы брейкпоинтов, движений, что не влезло) | `inbox/` | `design-notes.md` |

Если Claude Design отдал всё одним куском - клади одним файлом
`new-template.html`, я разберу сам. Разбирать вручную не нужно.

## Картинки

Девять уже лежат в `public/img/` и подключены. Перезаливать их не нужно.
Класть в `inbox/img/` только если нужна замена, имена ровно эти:

```
hero-bg.webp
cat-01-railing.webp
cat-02-door-frame.webp
cat-03-shower.webp
cat-04-swing.webp
cat-05-sliding.webp
cat-06-partition.webp
warehouse-parts.webp
glass-processing.webp
```

PNG из GPT Image кладутся в `inbox/img/` под теми же именами с
расширением `.png`, конвертацию в WebP и кроп делает `prepare-images.py`.
Апскейла в нём нет: если исходник меньше целевого размера, файл останется
как есть и в лог упадёт предупреждение.

## Чего сюда класть не надо

Расшифрованный `index.html` с открытым текстом. Репозиторий публичный,
и весь смысл шифрования в том, что открытого текста в нём нет.
