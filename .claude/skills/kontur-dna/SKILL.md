# Контур DNA: дашборд в айдентике «Детализации» с первой команды

Скилл переносит на любой новый дашборд три вещи:

1. **Файлы** Контур DS 1.3 и расширение 1.4 (`assets/ds/`).
2. **Каркас** со стартовым шаблоном (`assets/starter.html`).
3. **Правила**, из-за которых страница выглядит «как часы» (этот файл, раздел «ДНК»).

Живой эталон: раздел «Детализация» в `sales-detalizaciya/package/`.

## Порядок работы

1. **Развернуть каркас.** Файлы DS не переписывать и стили с нуля не придумывать:
   ```bash
   python3 .claude/skills/kontur-dna/scripts/scaffold.py <папка-проекта> [--title "Название"]
   ```
   Команда копирует `ds/` и `index.html` (стартовый шаблон).
2. **Разложить данные** в `DATA` / `METRICS` шаблона. Для каждого показателя нужны три вещи: норма, направление («больше = лучше») и источник.
3. **Собрать разделы по анатомии** (ниже). Детали брать только из `references/components.md`.
4. **Пройти проверку перед сдачей** (ниже). Снять скриншоты в тёмной и светлой теме, на ширине 1440 и 390.
5. **Числа и выводы.** Каждую цифру пометить «данные» или «гипотеза» (Protocol 9). Критичный артефакт до сдачи проходит ФЕНИКСА (Step 12.5).

## ДНК: правила, которые нельзя менять

### Сетка и ритм

- Шаг отступов: **4 · 8 · 12 · 16 · 20 · 24 · 32 · 56**. Других значений нет.
- Сетка 12 колонок, зазор **12** (`.grid12`, `.c4 .c6 .c8`). Поле карточки **20**. Между разделами **56**.
- Радиусы: клавиша **4** · кнопка **8** · плитка внутри карточки **12** · карточка **16**.
- Ширина контента до 1200. На телефоне поля 16, графики прокручиваются по горизонтали внутри `.scx`.

### Анатомия раздела (одинакова везде)

```
номер (01)  →  заголовок  →  вывод одной фразой  →  метка «данные / гипотеза»
          →  визуал (карточка c8 + боковая c4, или карточка на всю ширину)
          →  действие (одна основная кнопка + вторичные)
```

- Шапка раздела `SH(idx, title, say, tag)`.
- Шапка карточки `.hd`: подпись капсом слева, служебная строка справа.
- **Первый экран всегда** такой: заголовок-вывод, где вторая фраза выделена красным; число-герой «N из M»; полоса долей с легендой в том же порядке; 3 решения на неделю; ряд из 4 показателей против нормы. Руководитель должен понять ситуацию с первых двух экранов.

### Типографика

Шрифт Golos Text, цифры табличные.

| Роль | Кегль / начертание | Класс |
|---|---|---|
| Число-герой | 56-96 / 600, трекинг -0.045em | `.hero-n .big` |
| Заголовок экрана | 30-44 / 600, -0.035em | `.hero h1` |
| Заголовок раздела | 24 / 600 | `.sh h2` |
| Вывод | 15,5 / 500, выделение 600 | `.sh .say` |
| Показатель | 30 / 600 | `.stat .v`, `.kpi` |
| Текст | 14 / 400 | `.p` |
| Служебный | 12 / 400, приглушённый | `.hd .m`, `.meta` |
| Подпись | 11 / 600, капс, трекинг .06em | `.cap` |

Три размера чисел: герой, показатель, строчное. Четвёртого нет.

### Цвет только как сигнал

| Цвет | Смысл | Где |
|---|---|---|
| `--crit` красный | теряем, проблема | вторая фраза заголовка, главный поток потерь, «проблема» |
| `--warn` жёлтый | близко к норме, «подумаем» | |
| `--ok` зелёный | норма, успех, зона нормы на графике | |
| `--cat-3` синий | поток, второй показатель | |
| `--neutral-bar` серый | прочее, неважное | |

- Один цвет значит одно и то же на всей странице.
- Основная кнопка почти чёрная в светлой теме и светлая в тёмной (`--action`). Акцент не используется как декор.
- Тёмная тема по умолчанию: `KS.theme.set('dark', {persist:false})`, если человек сам не выбрал тему. Светлая тема обязана работать.

### Движение

- Анимируются только transform, opacity, clip-path, stroke-dashoffset, grid-template-rows. Без пружин.
- Кривые: вход `--e-in`, выход `--e-out`, стандарт `--e-std`.
- Вход блоков `.rise` + `--i`: 420 мс, шаг 35 мс, не больше 175 мс.
- Число меняется плавно (`N()` + `tick()`), 450 мс, только когда меняются данные.
- Плашка переключателя едет 250 мс. Панель выезжает 300 мс. Линии прорисовываются через `.draw`.
- Отлив под курсором `.spot`: 7% акцента, только мышь.
- «Меньше движения» выключает всё, «меньше прозрачности» выключает стекло.

### Глубина и стекло

- Карточки лежат на `--lift`, при наведении поднимаются до `--lift-hi` (`.lift`). Рамок почти нет.
- Стекло (размытие 20, насыщенность 160%) **только** на слоях поверх: подсказка `data-tip`, уведомление, панель деталей, палитра ⌘K, липкая шапка.

### Отзывчивость: каждый элемент что-то отвечает

- Кликабельные показатели (`data-drill`) открывают панель: график за 8 недель и «что делать».
- Строки списков открывают диалоги или записи с ID и кнопкой копирования (`data-copy`).
- У графиков при наведении появляются вертикальная линия, точки и стеклянная подсказка. Сетка только горизонтальная.
- Поток или воронка: клик по потере переносит на неё красный цвет и открывает разбор шага сбоку.
- Клавиши: ⌘K палитра, 1/2/3 решения, T тема, Esc закрыть.

### Текст

- Нет длинных тире: только дефис или другая конструкция. Соблюдать Anti-Slop из CLAUDE.md.
- Вывод раздела называет число и следствие («73% теряем на шаге…»). Пересказывать заголовок нельзя.
- Пустые состояния различаются: «загрузка», «список пуст», «нет данных (прочерк, не ноль)».

## Проверка перед сдачей

- [ ] Первые 2 экрана отвечают: что происходит, насколько плохо, что делать на неделе.
- [ ] У каждого раздела полная анатомия и метка «данные / гипотеза».
- [ ] Отступы и радиусы только из шкалы, все числа табличные.
- [ ] Цвет несёт один смысл по всей странице, декоративного цвета нет.
- [ ] Всё кликабельное реагирует; у всех графиков есть наведение.
- [ ] Тёмная и светлая темы, ширина 1440 и 390, ошибок в консоли нет.
- [ ] В тексте нет длинных тире и слопа.
- [ ] Данные с персональными сведениями не уходят в открытый доступ (шифрование, как в `sales-detalizaciya/build_page.py`).

## Файлы

- `assets/ds/`: `tokens.css`, `kit.css`, `brand.js`, `icons.js`, `kit.js`, `charts.js` (база 1.3) и `kx.css`, `kx.js`, `kx-showcase.js` (1.4). Обновляются сборкой `sales-detalizaciya/drafts/build_package.py`.
- `assets/starter.html`: стартовый дашборд из 3 разделов на примерных данных.
- `references/components.md`: разметка каждой детали.
- `DNA-prompt.md`: краткая ДНК для других инструментов (ChatGPT, Cursor, v0, Lovable). Прикладывается вместе с `kx.css`.
- `scripts/scaffold.py`: развернуть каркас в новую папку.
