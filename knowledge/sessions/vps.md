# Переезд VPS

Ветка `claude/friendly-brahmagupta-me4gk0` · PR #423 (draft) · план и контур в `infra/vps/` этой ветки
(README, INVENTORY, чек-листы). Сквозные правила по данным: [../semantic/data-privacy-migration.md](../semantic/data-privacy-migration.md).

**Цель.** Дашборды, сборы данных и расписания уходят с GitHub Actions/Pages на свой сервер в РФ.
Готово, когда 4 волны из `infra/vps/INVENTORY.md` переключены и Pages выключен.

**Порядок фаз.** 0 безопасность → подготовка (сервер, домен, S3, бот алертов) → 1 bootstrap.sh →
2 пилот РОП + Офис с параллельным прогоном 3-5 дней → 3 волны 1-4 → 4 закрытие Pages → 5 эксплуатация.

**Как работать с ЯДИ (30.09, его слова).** «Я ни разу не работал с серверами: все вопросы ты должен
предвидеть» - безопасность, нагрузку, оптимизацию и надёжность поднимать самому, до того как станут
проблемой, с готовыми командами и объяснением «почему». Цель: все дашборды с GitHub на свой сервер без потери
функционала, затем новый дизайн (Контур DS 1.5, `kontur-ds/`, демо `analytics-mvp/platform/`).

**Принцип: переезд и редизайн по очереди.** Сначала дашборд переезжает 1:1 и сверяется с GitHub, потом
переводится на Контур DS. Иначе расхождение цифры нельзя приписать одной причине (К5, К9).

**Риски, о которых напоминать по ходу.**
- Безопасность: копия SSH-ключа ЯДИ; 2FA в Timeweb и в GitHub `oliverjone01-dev`; личные логины и отзыв
  при увольнении; новые ключи API с минимальными правами; пароль restic вне сервера; шрифты и библиотеки
  Контур DS (Google Fonts, cdnjs, jsdelivr) положить на сервер; 152-ФЗ у Ивана с юристом.
- Нагрузка: сборка диалогов (dialog.json ~93 МБ) проверить на памяти в волне 2; страницы 17-90 МБ -
  сейчас gzip на лету, позже предсжатие при сборке (после относительных ссылок, конфликт с sub_filter);
  тариф пересмотреть через месяц по gg-status.
- Оптимизация: в редизайне данные отдельным JSON за паролем вместо запекания в HTML.
- Надёжность: баланс Timeweb (хватит примерно до середины ноября); восстановление с нуля bootstrap + restic,
  оценка 1-2 часа не проверена - проверить пробным восстановлением.
