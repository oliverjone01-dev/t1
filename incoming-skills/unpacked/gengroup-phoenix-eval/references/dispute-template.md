# Dispute Template - ФЕНИКС #35 vs Бойцы

Используй этот шаблон при ЛЮБОМ несогласии ФЕНИКСА с автором deliverable.

## Формат диспута

```
═══════════════════════════════════════
ДИСПУТ #[номер] | [дата]
ОБЪЕКТ: [название документа / deliverable]
АВТОР: [агент #] | ОППОНЕНТ: ФЕНИКС #35
═══════════════════════════════════════

ПОЗИЦИЯ ФЕНИКСА:
[Конкретная претензия с цифрами и ссылками на источники]

ПОЗИЦИЯ АВТОРА:
[Контраргумент автора с обоснованием]

РАУНД 1 — ФЕНИКС:
[аргумент]

РАУНД 1 — АВТОР:
[контраргумент]

РАУНД 2 — ФЕНИКС:
[аргумент]

РАУНД 2 — АВТОР:
[контраргумент]

[...до 5 раундов максимум...]

═══════════════════════════════════════
ВЕРДИКТ СПАРТАКА #21:
[Кто прав, почему, какое решение принято]

РЕЗУЛЬТАТ:
[ ] ФЕНИКС прав — документ на доработку по ТЗ ФЕНИКСА
[ ] Автор прав — документ утверждён, замечание ФЕНИКСА отклонено
[ ] Компромисс — частичная доработка: [описание]

IMPACT НА СИСТЕМУ:
[Если паттерн повторяется 3+ раза — обновить соответствующий skill]
═══════════════════════════════════════
```

## Правила диспута

1. Максимум 5 раундов. Если за 5 раундов не решено - эскалация Ивану.
2. Каждый аргумент подкреплён данными, не мнениями.
3. ФЕНИКС НЕ подчиняется СПАРТАКУ в диспуте - только Ивану.
4. Все диспуты логируются. Паттерны анализируются ежемесячно.
5. Если один тип ошибки найден 3+ раза - обязательное обновление скилла.
