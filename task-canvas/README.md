# GENGROUP · Холст задач

Персональная доска задач: карточки на перемещаемом холсте с зумом 8–200% и сеткой 24 px. Статическое приложение на ES modules, без сборки, backend и ключей API.

## Запуск

Из папки `task-canvas`: `npm start`, затем открыть http://127.0.0.1:4173. Требуются Python 3 и современный браузер. Для работы самого приложения Node не нужен; `npm test` запускает проверки модели на Node 22+.

Общий Pages workflow копирует `public/` в `/tasks/` при публикации из main. Из рабочей ветки этот workflow не публикует новую доску. Уже существующие проекты не изменяются.

## Три представления одной доски

- **Приоритеты:** входящие и четыре квадрата «важно × срочно». Перенос меняет только приоритет и позицию.
- **Команда:** дорожки по одному назначенному ответственному. Перенос меняет ответственного. Новые дорожки добавляются кнопкой. Формулировка из исходной таблицы остаётся в контексте карточки.
- **Сроки:** просрочено, сегодня, до конца недели, следующая неделя, позже, без срока. Перенос в другую дорожку назначает указанную в ней дату (для «Позже» — понедельник после следующей недели). Перемещение внутри своей дорожки сохраняет точную дату. В просроченную дорожку нельзя назначить задачу переносом: прошедшую дату можно указать явно в редакторе.

Позиции сохраняются отдельно для каждого вида. Колесо/трекпад перемещают холст, Ctrl/Cmd+колесо масштабирует под курсором, пробел+перетаскивание включает руку, F показывает все отфильтрованные карточки. Список «К дорожке…» переводит обзор к нужному человеку или периоду. Двойной клик или Enter открывает карточку; формы доступны с клавиатуры. Кнопки +/− и 100% управляют зумом.

## Данные

Импорт: JSON-экспорт доски, CSV или вставка TSV из Google Sheets вместе с заголовками первой вкладки. Строки без задачи и направления пропускаются. Если текст задачи отсутствует, используется направление. Приоритеты не угадываются. Простой одиночный исполнитель переносится из источника; составные формулировки остаются в заметке и требуют явного назначения. Исходные сроки сохраняются текстом, однозначные даты распознаются; год для даты без года — текущий локальный год пользователя. При переносе доски между годами предпочтителен JSON с точными датами.

По умолчанию импорт добавляет новые ID и пропускает существующие, сохраняя пользовательские изменения. Опция «Заменить текущие задачи» восстанавливает импортированную копию; это можно отменить в текущей сессии. Пустые дорожки ответственных тоже сохраняются в JSON.

В репозиторий намеренно не включены рабочие задачи и переписка. Данные лежат только в localStorage текущего origin браузера; смена адреса/порта или очистка данных не переносит доску. **Экспорт JSON нужен как резервная копия и для другого устройства.** Нет синхронизации с Google Sheets, серверного хранения или совместной работы. Другая вкладка предупреждает о конфликте и блокирует перезапись; экспортируйте локальную копию перед обновлением.

История отмены/повтора содержит до 50 изменений и действует до перезагрузки. Сами задачи, дорожки и положения сохраняются после перезагрузки. При ошибке записи отображается предупреждение, данные можно экспортировать.

## Проверка

`npm test` проверяет переносы, границы недель и года, привязку к сетке, CSV с многострочными полями, пропуск пустых строк, сохранение формулировок, распознавание дат и валидацию JSON.

Кликами в локальном браузере проверены открытие/правка карточки, перенос между квадратами, назначение ответственного и срока переносом, отмена/повтор, импорт рабочего снимка и сохранение после обновления. Мобильная компоновка проверяется отдельно; совместная работа не поддерживается. Шрифт Golos Text загружается с Google Fonts с системным fallback.
