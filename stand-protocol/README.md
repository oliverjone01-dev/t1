# Протокол стенда MEBELIT × VALONTI

Визуальное саммари договорённостей встречи 19.08.2026 о совместном стенде на
дизайнерском мероприятии - для владельцев обеих компаний.

## Что это

- `public/index.html` - страница-протокол. Дизайн взят из проекта
  `genglass-plan-calculator` (тёмная тема, brass-акцент, Inter Tight).
- `public/liveedit/` - модуль правки тела страницы с историей версий
  (из проекта `gentero-integra`, ветка `claude/gentero-plan-03609o`).

## Разделы

Стенд · Сбор лидов · Призовой фонд · Продвижение · Открытые вопросы ·
Риски и точки внимания · Следующие шаги · Участники. Теги статуса:
согласовано / идея / уточнить.

## Редактирование и утверждение

Модуль LiveEdit включается добавлением `?edit=1` к адресу. Редактируется тело
внутри `#doc` (заголовки, абзацы, пункты, ячейки). Правки и версии хранятся в
общем бэкенде - владельцы правят протокол и утверждают финальную версию.
Обычная ссылка (без `?edit=1`) открывается в режиме чтения.

## Публикация

Статика `public/` раскладывается общим сборщиком `.github/workflows/deploy-pages.yml`
в подпапку `/stand-protocol/`. Боевой адрес после деплоя из `main`:

- Чтение: `https://oliverjone01-dev.github.io/t1/stand-protocol/`
- Правка: `https://oliverjone01-dev.github.io/t1/stand-protocol/?edit=1`

Адаптивная страница - одна ссылка работает и на телефоне, и на десктопе.

## Дисциплина данных

Размеры стенда взяты из стенограммы (распознавание речи) и помечены «уточнить».
Часть пунктов - идеи и требуют согласования (отмечены тегами). Числовые оценки
охвата - без гарантий, замер по факту.
