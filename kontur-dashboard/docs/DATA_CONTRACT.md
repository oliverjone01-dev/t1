# Контракт данных

## Конверт одной цифры

Любое значение в `data/kontur.json` завёрнуто в пять полей. Четыре обязательны.

```json
{ "v": 444,
  "k": "ДАННЫЕ",
  "s": "keys.so через gg-seo-geo-monster/data/genglass/keysso.json",
  "at": "2026-09-07",
  "n": "" }
```

| Поле | Что значит |
|---|---|
| `v` | значение. Число или `null`, если выгрузки нет |
| `k` | класс: `ДАННЫЕ`, `ГИПОТЕЗА` или `ДЕМО` |
| `s` | источник: метод API или путь к файлу выгрузки |
| `at` | дата съёма, `ГГГГ-ММ-ДД` |
| `n` | примечание, может быть пустым |

Правила, которые проверяет сторож:

- класс только из трёх допустимых;
- у класса `ДАННЫЕ` обязателен непустой источник и дата в правильном формате;
- `v: null` с классом `ДАННЫЕ` запрещено: пустое значение это не данные.

## Классы

**ДАННЫЕ** - есть выгрузка, источник и дата. Можно нести собственнику.

**ГИПОТЕЗА** - бенчмарк, оценка или цифра, чей источник под сомнением. В план идёт
только пессимистичный сценарий. Пример: коэффициенты моста до денег, выгрузка
Директа, совпавшая у двух проектов.

**ДЕМО** - заглушка. Кабинет не подключён, выгрузки нет. Значение `null`.
Правдоподобное число вместо `null` запрещено: рядом с настоящими цифрами
заглушка перестаёт читаться как заглушка.

## Ряд позиций

`data/history/positions.ndjson`, по строке на проект и дату:

```json
{"ai_answers":84,"date":"2026-09-07","project":"gg","source":"keys.so",
 "top1":16,"top10":444,"top3":80,"top50":2145,"visibility":17}
```

Файл только дописывается. Повтор за тот же день перезаписывает строку, порядок
по дате. Пропущенный день не восстанавливается: у сводки домена в keys.so нет
ретроспективы, и это единственная причина, по которой файл вообще существует.

Имена полей в ряду и в интерфейсе различаются: `visibility` в ряду это `vis`
в сериях, `ai_answers` это `ai`. Карта соответствий одна, в `core.py`, константа `SF`.

## Откуда что берётся

| Раздел | Источник | Обновляет |
|---|---|---|
| Позиции, органика, семантика | `gg-seo-geo-monster/data/*/keysso.json` | `keyso-collect.yml` |
| Конкуренты в органике | `gg-seo-geo-monster/data/keyso/<домен>/competitors.json` | `keyso-collect.yml` |
| Видимость в ИИ | `keysso.json`, поля `visibility` и `ai_answers` | `keyso-collect.yml` |
| Визиты и поведение | `gg-seo-geo-monster/data/*/metrika.json` | сборщик Метрики |
| Реклама | `gg-seo-geo-monster/data/*/direct.json` | `direct-snapshots.yml` |
| Ряд по дням | `data/history/positions.ndjson` | `kontur-snapshot.yml` |
| Пороги и планы | зашиты в `tools/build_data.py` | правкой файла |

## Добавить проект

Одна запись в `PROJECTS` в `tools/build_data.py`: код, папка выгрузки, имя,
домен и план выручки. Если для проекта есть свои внутренние факты, добавить их
в `FACTS`. Дальше пересборка данных и страницы. Ни строки в интерфейсе.
